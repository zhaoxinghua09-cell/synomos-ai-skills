## 一句话定位

把乐享 MedXpert 知识库（官网内容源）的最新内容，按**受控、可审计**流程同步到本地并重新生成官网 HTML。它是 MedXpert「注册老炮」AI 防线中的一条**内容溯源与一致性防线**：只做「已授权源 → 本地 → 官网」的单向同步，不做内容创作、不做越权写入。

**何时用**：需要把乐享知识库最新内容发布/更新到官网，或做内容归档同步时。
**何时不用**：非乐享源内容、需要改写/生成新内容、需要写入乐享或第三方系统、超出已授权范围——本技能一律不接管，交由对应技能或人工处理。

---

## 一、能力边界（本技能不做 N 条）

本技能明确**只做**已授权乐享源 → 本地 → 官网 HTML 的受控同步。以下为硬性不做项（边界即防线）：

1. 不创作、不改写、不翻译生成官网内容（仅搬运已存在源内容）。
2. 不向乐享知识库反向写入或删除任何内容。
3. 不接入非 MedXpert / 非乐享授权的第三方内容源。
4. 不处理需登录权限以外的私密/受限文档（无权限即中止，不降级绕过）。
5. 不自动定时推送生产官网（默认需人工确认触发，防误发）。
6. 不对官网 HTML 注入脚本、外链或追踪器（防投毒）。
7. 不缓存或打印任何凭据/Token（凭据只从保险库读取，见第八章）。
8. 不替代人工内容合规审核——同步后发布前须人工复核。

## 二、输入约束与输出承诺

**输入约束**
- 必须指定：乐享源空间标识、目标本地路径、官网输出目录。
- 凭据：乐享 API Token 仅从保险库读取，禁止出现在对话/日志/输出中。
- 语言：源内容语种须 ∈ {zh-CN, en, ja, ko, es, fr, de, ar}；超出时标注「待核验」并原样搬运，不臆造译文。
- 格式：仅接受乐享知识库标准文档/富文本；非标准格式拒绝并提示。

**输出承诺**
- 输出：本地镜像副本 + 重新生成的官网 HTML（结构一致、带可溯源指纹）。
- 必带溯源：每条同步记录含源 URL、同步时间、指纹 FP-MX-F9231567C95B 体系标识。
- 失败可观测：任何阶段失败返回明确错误码与修复建议，不静默成功。
- 不泄漏：输出物不包含任何凭据。

## 四、常见错误与反模式（结构化 FAQ + 高频 Q&A）

**反模式**
- ❌ 把本技能当「官网内容生成器」——它只搬运不创作。
- ❌ 在对话里粘贴乐享 Token 以便「调试」——凭据只能从保险库读。
- ❌ 同步后跳过人工复核直接上线——绕过合规防线。
- ❌ 为「省事」开自动定时推送生产——误发风险，默认关闭。

**高频 Q&A**
Q1：需要什么前提？
A：已授权乐享源空间 + 保险库中的乐享 API Token + 目标本地/官网目录。无 Token 不降级绕过，直接中止。

Q2：支持哪些语言？
A：核心 8 种（zh-CN/en/ja/ko/es/fr/de/ar）；其他语种原样搬运并标「待核验」。

Q3：同步会改乐享内容吗？
A：不会。严格单向，任何反向写入被铁律禁止（第七章）。

Q4：失败了怎么办？
A：返回错误码（见第十章），按建议修复后重试；不静默成功。
