# Ardot 移动端 App 多屏产出

## 定位 + 何时用 / 何时不用

**一句话定位**：在 Ardot 画布上，用同一套视觉系统一次性绘制 4–5 个移动端 App 屏幕（PhoneFrame），保证尺寸、状态栏、底部标签栏、配色完全一致。

**何时用**
- 用户要在 Ardot 里做「手机 App / 移动端 App」且需要同时呈现多个页面或一条流程。
- 需要统一视觉系统：状态栏、底部标签栏、卡片、列表、浮层按钮、编辑页等。
- 涉及微信生态（微信导入 / 分享到微信）时，用 WeChat 绿作单一点缀色。

**何时不用**
- 单屏海报 / 落地页 / Web 端设计 → 用 `ardot-ui-design` 或其它单屏技能。
- 纯品牌 LOGO / 插画 → 不属于本技能范围。
- 需要后端逻辑、接口联调、真机编译 → 本技能只产出画布视觉，不写代码。

## 一、能力边界

| 维度 | 支持 | 不支持 |
|---|---|---|
| 屏幕数量 | 一次 4–5 个 PhoneFrame | 超过 6 个建议分批 |
| 设备尺寸 | 默认 iPhone 390×844 | 折叠屏 / 平板 / Watch 需另行指定 |
| 配色 | 单一点缀色（默认微信绿 `#07C160`） | 多主色混搭、渐变主题 |
| 内容语言 | 中文优先（Noto Sans SC） | 复杂 RTL 阿拉伯文排版需人工复核 |
| 微信打通 | 视觉层 CTA、导入/分享入口 | 真实微信 SDK 调用、OAuth 授权 |
| 交付物 | `.ardot` 画布 + 截图 | 可运行 APK / 前端工程 |

## 二、输入约束与输出承诺

**输入约束**
- 前置技能必须已加载：`ardot-design-core`、`ardot-ui-design`。
- 画布：新建空白 `.ardot`，根页面 PageID 为 `0:1`。
- 必须提供：屏幕清单（如「首页 / 待办 / 笔记 / 微信 / 我的」）与核心内容要点。
- 中文字体须可用，推荐 `Noto Sans SC`；不可用则按 §六 回退。
- 任何 Ardot API Key / 凭据从保险库读取，**绝不**进入对话或写回文件（见 §八）。

**输出承诺**
- 在 `0:1` 上横向排布 4–5 个 390×844 PhoneFrame，间距 60px，每帧上方有 `01 · 首页 Home` 文字标签。
- 每屏共享同一设计系统（§六 速查表），底部标签栏 5 个 tab 一致。
- 每屏完成 `capture_screenshot` 一次；全画布最后再截一次 `0:1`。
- 单屏内容不超出一屏可展示范围，关键入口（微信同步条）留在首屏。

## 四、常见错误与反模式（FAQ + 高频 Q&A）

**反模式（禁止做法）**
- ❌ 用 emoji 或文字代替底部 tab 图标 → 必须用 SVG frame。
- ❌ 每屏重建状态栏 → 第一个建好后用 `C("firstStatusBarId", ...)` 复制。
- ❌ 多色混用（红+蓝+绿） → 仅保留单一点缀色。
- ❌ 单屏塞满超一屏 → 删减内容或标「可滚动」，关键入口留首屏。
- ❌ 一次发 >25 个 operation → 分批，每批 ≤25。
- ❌ 微信绿写成 `#07c160` 之外的值或用于非强调处 → 仅 `#07C160` 作强调。

**高频 Q&A**
- Q：字体不可用怎么办？A：回退到系统支持的中文字体，并在截图备注中标注「字体已回退」。
- Q：屏幕超过 5 个？A：先画 4–5 个，其余在根页面下方另起一行或分画布。
- Q：要不要真连微信？A：只做视觉层入口，不调用 SDK / OAuth。
- Q：截图发现重叠？A：优先删减内容或调卡片高度，避免逐像素微调。

## 五、标准 SOP（步骤表）

| 步骤 | 动作 | 关键操作 | 注意 |
|---|---|---|---|
| 1 | 画布排布 | 在 `0:1` 横排 4–5 个 PhoneFrame，间距 60px，每帧上方加 `01 · 首页 Home` 标签 | 确认 PageID `0:1` |
| 2 | 状态栏复用 | 先完整建好首屏状态栏，后续用 `C("firstStatusBarId", phoneFrameId, {...})` 复制 | 禁止逐屏重建 |
| 3 | 内容区分块 | 按屏幕分批，每批 ≤25 个 operation；先结构（layout+主容器）再填内容样式 | flexbox / `layout:"wrap"`+`height:"hug_contents"` |
| 4 | 底部标签栏 | 每屏单独构建，当前页 `#07C160` 实心+白字，其余透明+`#9AA0A6` | 图标用 SVG frame |
| 5 | 微信打通 | 主按钮/进度/同步提示用 `#07C160`，加「微信聊天变笔记/待办」CTA 与「一键分享到微信」入口 | 仅视觉层 |
| 6 | 验证 | 每屏 `capture_screenshot` 一次，最后 `capture_screenshot(nodeIds:["0:1"])` | 溢出/重叠先删减 |

## 六、关键事实速查

**设计系统（默认）**

| Token | 值 | 说明 |
|---|---|---|
| 屏幕尺寸 | 390 × 844 | iPhone 14/15 标准 |
| 状态栏高度 | 62 px | 时间 + 信号 / WiFi / 电池图标 |
| 底部栏高度 | 85 px | 胶囊容器 62 px + 上下安全边距 |
| 主色调 | `#07C160` | WeChat 绿 / 品牌强调色 |
| 深色文本 | `#1A1B1E` | 标题 / 正文 |
| 次级文本 | `#6B7280` | 辅助说明 |
| 边框 / 分割线 | `#ECECEF` | 卡片描边、分隔 |
| 浅灰背景 | `#F5F6F8` | 搜索栏、未激活项 |
| 卡片圆角 | 14–16 px | 任务行、笔记卡片 |
| 胶囊标签栏圆角 | 36 px | 底部导航 |
| 字体 | `Noto Sans SC` | 中文优先；回退：系统中文 → 标注 |

**标准结构（每屏共享）**
```
PhoneFrame (390×844, 圆角 44, 描边 1px, clipsContent)
├── 状态栏 (复制复用)
├── 内容区 (vertical, padding 20, gap 24, fill_container)
│   ├── 头部（标题 + 操作按钮）
│   ├── 核心内容（卡片 / 列表 / 网格）
│   └── 辅助信息 / 状态提示
└── 底部标签栏（pill, 5 tab: 首页 / 待办 / 笔记 / 微信 / 我的）
```

## 七、铁律（PROHIBITED）

1. 禁止用 emoji / 纯文字充当底部 tab 或功能图标（必须用 SVG frame）。
2. 禁止在多个屏幕重复重建状态栏、底部栏等可复用组件。
3. 禁止引入第二主色；点缀色仅 `#07C160`（非微信场景可换单一品牌色，但仍限一种）。
4. 禁止单批 operation 超过 25 个，导致画布不稳定。
5. 禁止把凭据 / API Key 写入对话或回显到文件。
6. 禁止声称已实现真实微信登录、支付或数据同步。
7. 禁止交付超出「画布视觉」范围的可运行工程。

## 十、错误处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 字体缺失 | `Noto Sans SC` 不可用 | 回退系统中文，截图备注标注 |
| 画布溢出 / 重叠 | 单屏内容过多 | 删减内容或调卡片高度，不逐像素微调 |
| 截图验证失败 | 节点 ID 错误 / 未建成 | 复核 PageID `0:1` 与帧 ID，重绘后重截 |
| 状态栏错位 | 复制时坐标偏移 | 用 `C()` 复制并显式传目标 frame 坐标 |
| 底栏高亮错误 | 当前页判断错 | 当前页 `#07C160` 实心，其余透明 |
| 配色偏离 | 误用多色 | 回退单一 `#07C160` |
| 凭据缺失 | 未从保险库读取 | 报错并提示走保险库，不把密钥写入对话 |

若连续两次同屏验证失败，停止该屏并报告用户具体失败项，不静默产出半成品。
