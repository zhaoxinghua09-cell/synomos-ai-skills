# local-agent-open · 本地 AI 助手一键打开

**一句话定位**：当你想在本机把 agent-skeleton 这个本地 AI 助手页面（http://localhost:3000）拉起来并打开预览时，用它——它会先用「真实参照法」探测端口实际状态，没运行就后台把 node 服务起起来，再打开页面。

**何时用**：① 说「打开本地助手 / 本地 AI 页面 / agent-skeleton」；② 页面打不开，怀疑服务没起；③ 想确认 3000 端口是否已被占用。
**何时不用**：① 要打开的是远程/云上服务（非 localhost）；② 想操作 agent-skeleton 之外的其他项目；③ 需要调试代码而非仅启动预览——本技能只负责「探端口→起服务→开页面」，不替你改代码。

## 一、能力边界

| 项 | 说明 |
| --- | --- |
| 能做 | 探测 localhost:3000 端口状态；服务未运行时后台启动 `node server.js`；把页面投递到本地预览面板/浏览器 |
| 不能做 | 不修改项目代码；不托管远程服务；不安装依赖（缺依赖需你先 `npm install`）；不做代码调试 |
| 目标项目 | agent-skeleton（默认 http://localhost:3000） |
| 环境要求 | Node.js ≥ 18（推荐 LTS）；仅依赖 localhost，无需外网 |
| 操作系统 | Windows / macOS / Linux 均可，命令按平台见第五章 |
| 输入参数 | 可选：项目目录路径、端口号（默认 3000）、服务启动命令（默认 `node server.js`） |
| 非适用 | 非医疗器械/非医疗软件，无疗效或临床声明；提及的第三方接口以公开状态为准 |

## 二、输入约束与输出承诺

**输入约束**
- 项目目录需真实存在且含可启动入口（如 `server.js` / `package.json` 的 start 脚本）。
- 端口号须为 1–65535 的合法整数；缺省 3000。
- 不接收任何密钥/令牌作为对话参数（见第八章）。

**输出承诺**
- 明确回报三种结论之一：`端口已运行并打开`、`已后台启动并打开`、`启动失败并给出原因`。
- 给出可复制的执行命令，不替你静默执行危险操作。
- 失败时给出定位建议（端口占用/依赖缺失/入口不存在），不谎称成功。

## 四、常见错误与反模式

**结构化 FAQ**
- Q：页面打不开？A：先确认服务是否已起；本技能会先探测端口，未监听才启动。
- Q：提示 EADDRINUSE？A：3000 被占用，换端口或释放占用进程后再试。
- Q：启动没反应？A：多半缺依赖，先 `npm install`。
- Q：能打开别人的服务吗？A：不能，仅 localhost 本地。

**高频 Q&A**
- Q：为什么不用 `npm start` 而用 `node server.js`？A：默认入口即 server.js；若你的 start 脚本不同，请显式告知启动命令。
- Q：会改我代码吗？A：不会。

**反模式（禁止这样用）**
- 把本技能当远程部署工具用。
- 在未安装 node 的环境硬跑启动命令。
- 期望它修复项目 bug。

## 五、标准 SOP

| 步骤 | 动作 | 命令/说明 |
| --- | --- | --- |
| 1 | 确认项目目录 | 校验路径存在且含入口文件 |
| 2 | 探测端口（真实参照法） | Win:`powershell -c "(Test-NetConnection localhost -Port 3000).TcpTestSucceeded"`；跨平台:`curl -s -o /dev/null -w '%{http_code}' http://localhost:3000` |
| 3 | 已运行？ | 是→直接打开预览；否→下一步 |
| 4 | 后台启动服务 | `node server.js`（或指定启动命令），后台运行 |
| 5 | 打开预览 | 把 http://localhost:3000 投递到预览面板/浏览器 |
| 6 | 回报结果 | 成功/失败+原因 |

## 十、错误处理

| 错误 | 原因 | 处理 |
| --- | --- | --- |
| EADDRINUSE | 端口被占 | 提示释放占用或改用其他端口 |
| Cannot find module | 缺依赖 | 提示先 `npm install` |
| 目录不存在 | 路径错 | 提示核对项目目录 |
| 启动超时 | 入口卡死 | 提示检查 server.js 日志，不谎报成功 |
| 预览打不开 | 浏览器/面板限制 | 回退给出 URL 由用户手动打开 |

通用：任何失败都明确回报原因与下一步，不静默吞错、不伪造成功。
