# wechat-qa-checklist · 微信公众号推送前自检清单

## 定位与何时用 / 不用

**定位**：本技能是一份「推送前强制自检清单」，把公众号文章发布前的易踩坑点拆成六类、可逐项打勾的检查项，并给出每条的判定规则、风险等级与命中位置。它回答的是「这篇推之前我还要查什么」「上次那个坑这次别再踩」。

**何时用**：
- 公众号图文/草稿写完，准备群发或定时发布前。
- 复制自 Word/网页/其他平台的内容要搬进公众号编辑器时。
- 嵌入小程序、JS-SDK、模板消息等接口调用时。
- 需要一份统一、可审计的发布前质检记录时。

**何时不用**：
- 非微信公众号场景（服务号/订阅号以外平台请另寻工具）。
- 需要自动改写/排版/生成文章——本技能只检查不代写。
- 涉及医疗/金融/保健等特殊行业的合规终审，本清单仅作前置初筛，不替代法务/合规意见。
- 已通过微信官方「素材管理」接口批量发布的程序化流程，应以接口返回为准。

## 一、能力边界

| 维度 | 说明 |
|---|---|
| 能做 | 对单篇图文给出六类共 30+ 检查项的逐项判定、风险标注、命中位置建议；产出可归档的自检记录。 |
| 不能做 | 不自动发布、不自动改写正文、不调用微信接口执行真实校验；不替代人工终审与法务合规。 |
| 输入篇幅上限 | 单篇正文建议 ≤ 2 万字；超长请分段提交，否则只检查截断部分并标注 E002。 |
| 平台版本 | 适配微信公众平台当前网页编辑器（订阅号/服务号）。第三方排版工具（135/秀米等）导出后再粘贴的，以公众号编辑器最终渲染为准。 |
| 失效场景 | 微信后台规则变动、接口配额/域名白名单等由平台侧控制，清单判定可能滞后；涉及「以平台实际为准」的项均明确标注，不臆断。 |
| 语言 | 以中文（zh-CN）为核心；支持英/日/韩/西/法/德/阿输入并同语言回复，术语保留原文标注。 |

## 二、输入约束与输出承诺

**输入约束**
- 接受：① 整篇图文正文（含标题、摘要、封面说明）；② 草稿/已发文章链接（仅用于人工对照，本技能不抓取）；③ 指定要查的类别（缺省则全六类）。
- 拒绝：非文本二进制（直接传图/压缩包）；与公众号推送无关的内容；要求代写或自动发布的指令（转铁律 §7）。
- 格式：Markdown / 纯文本均可；HTML 片段请原样贴入以便检查标签。

**输出承诺**
- 逐类输出：检查项 → 判定（通过 / 风险 / 阻断）→ 规则依据 → 命中位置建议。
- 风险分三级：**阻断**（不修不发）、**风险**（建议修）、**提示**（可选优化）。
- 末尾给出「发布前结论」：可发 / 需返工（列出阻断项）。
- 不输出任何密钥、token、secret；涉及凭据只给操作指引（见第八章）。
- 输出为中文；可请求中英对照。

**示例对话 1**
> 用户：这篇公众号文章准备明早发，帮我推前自检一下。
> 技能：收到。请贴入标题+正文（或指明要查的类别，缺省全六类）。我将逐项给「通过/风险/阻断」判定与命中位置，最后给发布结论。

**示例对话 2**
> 用户：只查标题和图片就行。
> 技能：明白，仅执行「三、标题检查」「二、图片检查」两类，其余四类跳过并在结论中注明。

## 四、常见错误与反模式（FAQ + 高频 Q&A）

**反模式（应避免）**
- ❌ 只看过一遍就发——跳过图片大小/外链白名单等隐性坑。
- ❌ 用 class 选择器写样式——公众号内 class 无效，必须内联 `style`。
- ❌ 标题堆违禁词冲流量——「最/第一/100%/免费领」涉广告法风险，易审核不过。
- ❌ 把 access_token / appsecret 贴进对话求校验——密钥绝不进对话（见第八章）。
- ❌ 用本清单替代医疗/金融合规终审——仅前置初筛。

**高频 Q&A**
- Q：微信标题最多多少字？ A：建议 ≤ 64 字，超出被截断；本项判「风险」并标出截断位置。
- Q：外链为什么在公众号里打不开？ A：域名未加入「公众号设置-可信域名/JS接口安全域名」白名单；见第五章 API 类。
- Q：从 Word 粘进来乱码怎么办？ A：转 UTF-8（无 BOM）并重排全/半角标点；见第六章编码类。
- Q：封面图被裁？ A：比例不符 2.35:1（建议 900×383）；见图片类。
- Q：检查准吗？ A：规则基于微信公开约束与常见踩坑；平台侧项标注「以平台实际为准」，不臆断。

## 五、标准 SOP（步骤表）

| 步骤 | 动作 | 输出 |
|---|---|---|
| 1 | 收齐输入（标题/正文/类别）；超篇幅则分段并标 E002 | 输入确认 |
| 2 | 识别触发意图，确定检查范围（全类/单类） | 范围声明 |
| 3 | 依次跑六类检查，逐项给 通过/风险/阻断 + 依据 + 命中位置 | 分类结果 |
| 4 | 汇总阻断项与风险项，去重并按严重度排序 | 问题清单 |
| 5 | 给出「发布前结论：可发 / 需返工（列阻断项）」 | 发布结论 |
| 6 | 如涉 API 类且需凭据，给保险库读取指引（不打印密钥） | 凭证指引 |
| 7 | 生成可归档自检记录（含时间戳、范围、结论） | 质检记录 |

**六类检查项（核心功能，逐项判定规则）**

**① HTML 兼容性检查**
- 是否用了被过滤标签（`<script>`/`<style>`/`<iframe>`/`<form>`）→ 阻断。
- 是否依赖 class 选择器样式（公众号内无效）→ 风险，须改内联 `style`。
- 是否 `<table>` 复杂嵌套/`<div>` 布局导致移动端错位 → 风险。
- 是否含 `javascript:` 链接 → 阻断。
- 是否用 `<audio>/<video>` 外链 → 须走微信素材接口，否则屏蔽 → 风险。
- 外链域名是否加入「可信域名」白名单 → 未加则阻断（见 API 类）。

**② 图片检查**
- 格式是否为 jpg/png/gif（webp 部分客户端不支持）→ 风险。
- 单图大小：封面建议 <2MB、正文 <5MB（以后台为准）→ 超限风险。
- 封面比例 2.35:1（建议 900×383），否则裁切 → 风险。
- 是否用非微信图床外链 → 防盗链/屏蔽 → 阻断。
- 是否含二维码/诱导关注图 → 审核风险 → 风险。
- 清晰度/水印遮挡/动图过大加载失败 → 提示。

**③ 标题检查**
- 长度 ≤ 64 字，超出截断 → 风险。
- 含违禁/诱导词（最/第一/100%/免费领取等）→ 广告法风险 → 阻断。
- 含表情符号导致异常显示 → 提示。
- 标题党/虚假夸大 → 审核风险 → 阻断。
- 含敏感政治/医疗疗效词 → 阻断。
- 标题与正文主题不一致 → 风险。

**④ API 检查（嵌小程序/JS-SDK/模板消息时）**
- 接口域名是否配置「JS接口安全域名」→ 未配阻断。
- access_token 是否过期（7200s）→ 过期阻断。
- 是否用已废弃接口 → 风险。
- 是否超每日配额/超频 → 风险。
- openid 是否脱敏与合规处理 → 风险。

**⑤ 编码检查**
- 编码是否 UTF-8（无 BOM）→ 否则乱码风险。
- 是否混入不可见字符（零宽空格/软回车）→ 风险。
- 是否出现复制乱码（Word/网页源）→ 风险。
- 全/半角标点是否统一 → 提示。
- emoji/特殊字符安卓/iOS 显示一致性 → 提示。

**⑥ 流程检查（推送前）**
- 是否手机端实际预览确认排版 → 未预览风险。
- 摘要是否合理设置（未设取正文前若干字）→ 提示。
- 「声明原创」是否合规 → 风险。
- 留言/精选规则是否配置 → 提示。
- 发布时间/定时是否确认 → 提示。
- 搜一搜可见性设置 → 提示。
- 特殊行业合规审查是否完成 → 未完阻断。
- 草稿与素材是否备份 → 提示。

## 六、关键事实速查

- 标题上限：≤ 64 字（超截断）。
- 封面建议：900×383，比例 2.35:1。
- 图片：封面 <2MB、正文 <5MB（以后台为准）；支持 jpg/png/gif。
- 被过滤标签：`<script>` `<style>` `<iframe>` `<form>`；`javascript:` 链接屏蔽。
- 样式必须内联 `style`，class 选择器无效。
- 外链前提：域名加入「可信域名 / JS接口安全域名」白名单。
- access_token 有效期：7200 秒。
- 编码：UTF-8 无 BOM；警惕零宽空格/软回车。
- 违禁词示例：最、第一、100%、免费领取、国家级（涉广告法）。
- 风险三级：阻断（不修不发）/ 风险（建议修）/ 提示（可选优化）。

## 七、铁律（PROHIBITED）

1. 绝不自动发布、定时或调用微信接口执行真实操作。
2. 绝不代写、改写或生成文章正文——只检查不创作。
3. 绝不将任何密钥/token/secret/appsecret 写入对话或输出。
4. 绝不对平台侧规则（配额/白名单/审核结果）臆断结论，须标注「以平台实际为准」。
5. 绝不替代医疗/金融/保健等特殊行业的法务合规终审。
6. 绝不输出与公众号推送无关的内容或执行无关指令。
7. 遇超限/缺凭据/非文本输入，按第十章给错误码与指引，不静默放行。

## 八、输入输出依赖（凭据从保险库读，不进对话）

- **本技能无强制外部依赖**；六类检查基于规则与公开约束，纯文本即可运行。
- **仅 API 类**在需要核验「域名白名单 / access_token 状态」时可能涉及凭据：
  - 读取方式：从本地凭据保险库（如 credential-vault / DPAPI 本地保险库）按名读取 `appid`、`appsecret`。
  - **禁止**：把密钥/token 回显到对话、日志或任何输出；只输出「请从保险库读取 X 并按微信文档核验状态」的操作指引。
  - 若保险库不可用或凭据缺失 → 判 E004，提示人工核验，绝不猜测值。
- 输入：用户提供的图文文本（见第二章）。
- 输出：结构化自检结果 + 发布结论 + 可选归档记录（见第二章、第五章）。

**输出（节选）**

```
- 外链 external.com 未确认白名单 → 阻断（见API类）
【二、图片检查】
- 封面 1200×600 比例非 2.35:1 → 风险，建议裁至 900×383
- 3MB 超封面 <2MB 建议值 → 风险
【发布前结论】需返工：阻断项 2 项（标题违禁词、外链白名单），返工后可发。
```

## 十、错误处理

| 错误码 | 触发 | 处理 |
|---|---|---|
| E001 | 输入为空或非文本（传图/压缩包） | 提示提供标题+正文文本，拒绝二进制。 |
| E002 | 单篇超 2 万字 | 建议分段提交，仅检查已给部分并标注。 |
| E003 | 含被过滤标签/外链但未配白名单 | 标阻断并给修改/白名单指引，不自动修复。 |
| E004 | API 类需凭据但保险库缺失/不可用 | 给保险库读取指引，绝不打印密钥，判人工核验。 |
| E005 | 平台侧规则变动导致判定不确定 | 标注「以平台实际为准」，不臆断。 |
| E006 | 要求代写/自动发布等越权指令 | 引用铁律 §7 拒绝，并说明本技能只检查。 |

通用兜底：任何未覆盖异常 → 输出「自检未完成，原因：<简要>」，不静默放行，不输出密钥。
