# 全球 AI 治理版图

全球 AI 治理速查工作台：**看得懂国际格局、查得到组织机制、对得上倡议谱系、跟得上治理趋势**。面向政策研究者、出海战略与行业观察者——从 WAICO 成立到联合国科学小组报告，AI 世界治理正在从「论坛对话」走向「机制化合作」。

## 定位

**何时用（声明式）**
- 国际格局：「全球 AI 治理有哪些主要机制和组织？」
- WAICO：「世界人工智能合作组织是什么？谁参加了？」
- 联合国：「联合国在 AI 治理上做了什么？」
- 中国倡议：「中国在全球 AI 治理上的倡议谱系？」
- 国际安全：「AI 安全峰会和 AI Safety Institute 是什么？」
- 国别战略：「各国 AI 战略重点是什么？」

**何时不用（声明式）**
- 需要企业级 AI 治理落地框架——见 ai-governance-playbook / ai-building-ai-governance。
- 需要实时新闻或今日突发——本技能工具为静态本地规则，不联网、不更新动态。
- 需要立场性政策建议（非中性速查）——本技能是速查与框架，不是政策立场。

## 一、能力边界

**本技能做（In scope）**
- 全球治理格局速查：多极格局、机制分类、组织地图。
- 国际组织速查（WAICO / UN / BRICS / G7 / OECD / UNESCO 等）。
- 倡议事件速查（中国 / 联合国 / 国际峰会）。
- 主要经济体 AI 战略速查（美 / 欧 / 英 / 日 / 韩 / 印）。
- 全球治理时间线与趋势观测（机制化转型、科学化、智能体治理等）。
- 全球南方与数字鸿沟、能力建设议题梳理。

**本技能不做（Out scope，集中声明）**
1. 不提供政策立场或 lobbying 建议——仅为中性速查与框架。
2. 不替代官方发布：组织与倡议信息以公开报道整理，引用前以官方为准。
3. 不联网、不采集数据、不提供实时动态（工具为本地规则匹配）。
4. 不对具体企业做合规结论——宏观版图是企业合规的方向标，非落地标准。

## 二、输入约束与输出承诺

**推荐问法（引导给足上下文）**
- 「WAICO 是什么？和联合国什么关系？」
- 「中国在全球 AI 治理上提了哪些倡议？」
- 「全球 AI 治理未来会怎么走？」
- 工具模式：给出组织名 / 主体 / 地区 / 时间线参数，取结构化速查。

**输入字段引导**
- `org --name`：`waico` / `un` / `brics` / `g7` / `oecd` / `unesco`。
- `initiative --actor`：`cn`（中国）/ `un`（联合国）/ `intl`（国际峰会）。
- `region --name`：`us` / `eu` / `uk` / `jp` / `kr` / `in`。
- 无参数或想看全集用 `--help`。

**输出承诺**
- 中性、结构化速查；动态信息标注「以官方发布为准」（**待核验**）。
- 工具零依赖、本地运行、不联网、不采集数据。
- 趋势观测为分析框架，非预测结论。

## 四、常见错误与反模式

**反模式 1 ✗** 把速查内容当「政策立场」或 lobbying 依据引用。
**替代方案 ✓** 本技能为中性速查与框架，结论需结合官方与本国法律自行判断。

**反模式 2 ✗** 引用过时信息，未标注「以官方发布为准」。
**替代方案 ✓** 动态信息（WAICO 细则、新机制）标**待核验**，引用前核官方最新。

**反模式 3 ✗** 混淆「倡议」与「法规」效力（如把中国倡议当强制法）。
**替代方案 ✓** 明确倡议 = 软性立场，法规 = 强制约束；宏观版图是企业合规方向标，非落地标准。

**反模式 4 ✗** 无参数直接运行却期待结果。
**替代方案 ✓** 用 `--help` 看命令全集；或给组织名 / 主体 / 地区参数。

**高频 Q&A**
- **Q：WAICO 和联合国什么关系？** A：WAICO 是独立政府间国际组织（总部上海、29 创始国），定位为联合国框架努力的有益补充；中国支持联合国发挥 AI 治理主渠道作用（references/04）。
- **Q：全球 AI 治理为什么重要？** A：AI 发展快于治理能力提升，规则碎片化、数字鸿沟、话语权失衡是三大结构性挑战（references/01）。
- **Q：和企业 AI 治理什么关系？** A：宏观版图是方向标，全球规则会逐步转化为各市场法规（如 EU AI Act、中国法规），企业治理是微观落地。
- **Q：工具要装依赖吗？** A：不需要，仅 Python 标准库；本地运行、不联网。
