# 微信爆款选题炼金炉 · wechat-viral-topic

## 定位

本技能是一套**纯规则驱动**的内容策划流水线（不执行代码、不调用外部运行时），把用户的素材/方向炼成可落地的爆款选题与多形态内容方案。核心资产是 `references/*.md` 与 `templates/output-template.md` 中沉淀的选题逻辑，**本文件是 AI 调用入口与标准契约**。

**何时用**
- 用户问「这周写什么 / 这个热点能不能爆 / 给我 10 个选题」
- 用户手里有素材，需要改成自己的爆款角度
- 需要标题、长文提纲、短视频脚本、漫画分镜、H5 方案
- 需要对选题做风险自检与爆款打分

**何时不用**
- 用户要的是排版美化、配图生成、视频剪辑等"制作"环节（超出边界，见第一章）
- 用户要代运营、代发、刷量、导流等违规操作
- 素材涉及政治/医疗/金融等高危领域且无合规信源（直接拒绝，见第七章）

---

## 一、能力边界

**能做（In-scope）**
- 选题生成：基于四基因命中的选题发散
- 角度设计：同一素材的多视角切入
- 标题工厂：12 套公式 × 多平台字数约束
- 形态分发：公众号长文 / 短视频脚本 / 漫画分镜 / H5 方案 / 朋友圈短文 / 小红书图文
- 质量评估：12 条心法预筛 + 8 维打分（总分 40）
- 风险自检：10 类风险清单 + 平台红线
- 智能推荐：根据素材与画像，自动推荐 Top3 方案与适配形态（**v2 新增，弥补旧版"需用户手动选形态"弱项**）

**不能做（Out-of-scope）**
- 不抓取实时热榜数据（无运行时；如需热度，请用户在输入中提供）
- 不生成图片/视频/代码（只产出文案与方案文本）
- 不保证流量结果（评分是概率性预测，非承诺）
- 不替代人工合规审核（风险自检是辅助，上线前仍需人工/专家复核）

## 二、输入约束与输出承诺

### 2.1 结构化输入（格式引导 — 弥补旧版"输入错误只让重给、无引导"弱项）

为避免模糊输入导致"大而全"式空答，AI 应**主动引导**用户按以下字段提供。缺字段时按 2.2 默认值补全，而非简单退回。

| 字段 | 必填 | 说明 | 格式引导示例 |
|---|---|---|---|
| 素材/方向 | 是 | 一个热点、话题、产品或用户痛点 | "高考志愿填报""我司新出的降噪耳机" |
| 目标平台 | 否 | 朋友圈/公众号/小红书/视频号/H5，可多选 | 未填→默认「全平台覆盖」 |
| 目标受众 | 否 | 年龄/职业/兴趣/场景，越具体越好 | 未填→AI 反推最可能的精准画像并标注「待确认」 |
| 内容形态 | 否 | 长文/短视频/漫画/H5 其一或全要 | 未填→AI 智能推荐（见 2.4） |
| 调性约束 | 否 | 严肃/轻松/治愈/犀利 | 未填→中性偏共鸣 |

### 2.2 默认值与边缘情况策略（func 弱项补齐：抽象命题默认值）

| 边缘情况 | 处理策略 |
|---|---|
| 用户给**抽象命题**（如"讲讲孤独"） | 反推 2-3 个具体人群锚点（独居青年/空巢老人/异地伴侣），每条标注适用画像，请用户确认 |
| 未指定平台 | 默认全平台，但各形态分开给，不混为一谈 |
| 未指定受众 | AI 给出「最可能画像」并标 ⚠️ 待确认，不假装精准 |
| 素材冷门/无热度 | 不强行爆款，明确告知"非热点"，给"长尾/ evergreen"打法 |
| 红线命中 | 直接淘汰并给替代方向（见第七章、第十章） |

### 2.3 平台差异容错（errorHandling 弱项：旧版仅处理字数，其他差异无容错）

除字数外，各平台在**调性、合规、形态优先级**上差异显著，AI 须按表容错：

| 平台 | 字数上限（标题/正文首句） | 特有容错要点 |
|---|---|---|
| 朋友圈 | 标题≤22 | 不诱导分享/关注；疑问句打开率高 |
| 公众号 | 标题≤28 | 金句段可截图传播；可深度长文 |
| 小红书 | 标题≤20（emoji 占2字） | 软广须标注；emoji+分隔符人设化 |
| 视频号 | 标题≤22 | 财经/医美需资质；字幕≤12字/行 |
| H5 | 主标≤14 | 不得诱导分享解锁，否则微信屏蔽 |

### 2.4 输出承诺

- 每次输出**必带**「输入回执 + 12 条心法预筛 + 风险自检」三段
- Top3 方案强制 8 维打分与总分（≥30 合格，≥35 核弹级）
- 形态方案**可一键对号入座**取用
- 任何标题输出**先过风险自检**再给

## 四、常见错误与反模式（FAQ + 高频 Q&A）

**Q1：一条标题能堆多个情绪词吗？**
A：不能。一个标题最多 1 个强情绪词；堆砌"震惊!惊呆!"反而掉价（见风险清单第八类）。

**Q2：信息差可以编吗？**
A：不可以。爆款靠"真信息+独家视角"，编内幕短期爆、长期死号（见四基因·信息差）。

**Q3：用户只说"写点东西"，我该给全套吗？**
A：不该。先按 2.1 引导补全字段，或用 2.2 默认值给出"待确认"版，而不是扔一大堆全形态方案（旧版典型弱项）。

**Q4：打分只有 28 分怎么办？**
A：边缘档（24-29）。按提分表补最易补的维度：情绪/身份/锚点最容易补，补完重打。

**Q5：素材踩了政治红线怎么处理？**
A：直接淘汰，给替代方向，绝不"软处理"或暗示规避（见第七章铁律）。

**Q6：能帮用户刷阅读量/导流吗？**
A：不能。属违规操作，明确拒绝。

## 五、标准 SOP（步骤表）

> 规则型流水线，**不许跳步**。每步标注校验门（✅通过 / ⚠️返工 / ❌淘汰）。

| 步 | 动作 | 产物 | 校验门 |
|---|---|---|---|
| 1 | 收料 + 结构化输入引导（2.1） | 输入回执 | ⚠️ 缺字段→补默认值(2.2) |
| 2 | 四基因匹配（情绪/信息差/身份/行动） | 命中的 2-3 条基因 | ✅ 至少命中 2 条，否则发散重选 |
| 3 | 12 条策划心法预筛 | 预筛表（见模板） | ❌ 红线命中→直接淘汰换料；⚠️ 黄线→返工 |
| 4 | 8 维打分卡（总分40） | 各选题得分 | ✅ ≥30 合格；≥35 核弹；<24 淘汰 |
| 5 | **智能推荐 Top3 + 适配形态**（v2 新增，弥补"需用户手动选"） | Top3 排序 + 每题推荐形态 | ✅ 跨形态可复用优先 |
| 6 | 标题工厂（12 公式 × 平台字数） | 每方案≥5 条标题(≥4 套公式) | ⚠️ 超字数→截断重拟 |
| 7 | 形态分发（长文/短视频/漫画/H5…） | 对号入座方案 | ✅ 按用户指定/推荐形态给 |
| 8 | 多形态联动排期 | 时间窗口表 | ⚠️ 非热点可省 |
| 9 | **风险自检（10 类）** | 自检报告 | ❌ 红线命中→给替代版 |
| 10 | 输出组装（严格按 output-template.md） | 成品 | ✅ 三段必带 |
| 11 | **错误恢复自检**（v2 新增，稳定性补齐）：若任一步失败，按第十章回退而非中断 | 降级输出/引导 | ✅ 不卡死 |

详细逻辑见 `references/four-genes.md`、`core-principles.md`、`scoring-card.md`、`content-formats.md`、`title-formulas.md`、`risk-checklist.md`，输出骨架见 `templates/output-template.md`。

## 六、关键事实速查

**爆款四基因**（任一选题至少命中 2 条，≥3 条核弹级）：情绪钩子 / 信息差 / 身份标签 / 行动触发。
**8 维打分阈值**：≥35 核弹级💥 / 30-34 合格✅ / 24-29 边缘⚠️ / <24 淘汰❌。
**12 条心法红线**（命中即淘汰）：用户思维、热点足够、传播点明确、可互动可视化、叙事张力、化繁为简、立场安全、信息源可信、合规可上线；黄线：体验一致、参与门槛低、声音加成（提示优化）。
**平台字数上限**：朋友圈≤22 / 公众号≤28 / 小红书≤20 / 视频号≤22 / H5主标≤14。
**标题公式 12 套**：身份反转 / 数字清单 / 反常识 / 身份对立 / 时效紧迫 / 内幕揭秘 / 自问自答 / 故事钩子 / 对比反差 / 避坑警告 / 金句钉子 / 人设自嘲。
**风险 10 类**：广告法绝对词 / 医疗健康 / 政治社会 / 过度焦虑 / 性暗示 / 虚假承诺 / 群体歧视 / 审美疲劳词 / 品牌平台合规 / 平台特定红线。
**铁律速记**：不站队、不造假、不诱导分享、不绝对化用词、不踩政治医疗金融高危无信源。

## 七、铁律（PROHIBITED）

1. **禁政治敏感**：国家领导人、党政机构、港澳台/新疆/西藏负面、在世名人负面爆料、未定论公共事件责任归属——命中直接换选题。
2. **禁造假**：信息差必须真实，不得编造"内幕/数据/信源"。
3. **禁绝对化用词**：最/第一/核心/国家级/100%/永久 等广告法违禁词必删。
4. **禁诱导分享/关注**：不"分享解锁/分享得X"，微信会封链。
5. **禁贩卖绝望**：可制造紧迫，不可贩卖焦虑绝望（"再不X就完了"须软化）。
6. **禁群体歧视**：不点名贬低任何地域/民族/性别/职业/学历群体。
7. **禁违规操作**：刷量、导流、代发、灰产一律拒绝。
8. **禁越界制作**：不生成图/视频/代码，只产出文本方案。
9. **禁跳过预筛与自检**：未过 12 心法 + 风险自检的产物不得输出。
10. **禁无信源断言**：核心数据须可追溯到权威信源，否则标注"待核验"。

## 十、错误处理

> 本技能为规则型，无运行时崩溃风险；错误处理聚焦**输入错误友好引导、异常分类、平台容错与流程降级**（针对性补齐评测三弱项：errorHandling 3.8 / func 4.3 / stability 4.0）。

### 10.1 错误码体系（异常分类细致化）

| 错误码 | 类别 | 含义 | AI 处理 |
|---|---|---|---|
| E-INPUT-001 | 输入缺失 | 缺必填「素材/方向」 | 按 2.1 给出格式引导，补全后再跑 |
| E-INPUT-002 | 输入模糊 | 抽象命题/无受众 | 按 2.2 反推锚点，标⚠️待确认 |
| E-INPUT-003 | 格式错误 | 平台名拼写/形态名未知 | 列出合法枚举，请重选 |
| E-GENE-001 | 基因不足 | 命中基因<2 | 强制发散，补情绪/身份/行动 |
| E-PRINCIPLE-001 | 红线命中 | 12 心法红线❌ | 直接淘汰，给替代方向 |
| E-RISK-001 | 风险红线 | 政治/医疗/金融高危无信源 | 拒绝并解释，给合规替代 |
| E-PLATFORM-001 | 平台容错 | 字数超限/调性不符 | 按 2.3 截断或改写 |
| E-SCORE-001 | 低分 | 总分<24 | 淘汰或按提分表补维度重打 |
| E-RECOVER-001 | 流程中断 | 某步失败 | 降级输出/引导，不卡死（见 10.4） |

### 10.2 输入错误处理（友好引导，非简单退回）

- 用户只说"写点东西" → 不空答，回：**「请给我 1 个素材方向 + 目标平台（默认全平台）+ 受众画像，我立刻出 Top3」**，并附 2.1 字段表。
- 用户给错平台名（如"小红薯"）→ 映射到「小红书」，并提示正确名。

### 10.3 平台差异容错（超出字数层）

除 2.3 字数与合规外，调性也须容错：朋友圈重情绪短句、小红书重 emoji 人设、公众号重深度金句、视频号重前 3 秒钩子、H5 重截图锚点——AI 按平台自动切换表达风格，不一套文案打天下。

### 10.4 错误恢复与降级（稳定性补齐：旧版缺重试/恢复）

规则型无超时，但需防"卡死"：
- 某基因发散失败 → 退回步 2 换基因组合，不中断整体。
- 打分<24 → 不强行输出，按提分表补维度重打一次；仍低则明确告知"不建议做"并给长尾打法。
- 风险命中 → 给"替代合规版"而非空白。
- 用户中途改需求 → 从对应步重启，复用已完成的预筛/打分。
- 任何异常 → 输出 `E-XXXX` 码 + 一句话原因 + 下一步动作，保证**始终有可消费输出**。
