## 一、中欧 IVD 法规轨道总览

| 维度 | 中国（NMPA） | 欧盟（EU） |
|---|---|---|
| 核心法规 | 《体外诊断试剂注册与备案管理办法》（市场监管总局令第 48 号，2021-10-01 实施） | **IVDR (EU) 2017/746**（2022-05-26 全面适用，取代 IVDD 98/79/EC） |
| 分类依据 | 《体外诊断试剂分类规则》（2021 年 129 号公告）+《体外诊断试剂分类目录》（2024 年 58 号公告） | IVDR 附录 VIII 分类规则（7 条，A/B/C/D 四级） |
| 管理类别 | 三类 / 二类 / 一类（备案） | Class D / C / B / A（无菌）需公告机构；A 非无菌自声明 |
| 临床/性能证据 | 临床评价（免临床目录/同品种/临床试验）；IVD 临床试验按 GCP + IVD 专项指导原则 | 性能评价 PER：科学有效性 + 分析性能 + 临床性能（Articles 56–58 + Annex XIII） |
| 证书 | 注册证 5 年，届满前 6 个月申请延续 | CE 证书最长 5 年，C/D 类需 PSUR |
| 标识 | 注册证号/备案号 | UDI（Basic UDI-DI）+ EUDAMED 注册 |

**一句话**：IVD ≠ 普通器械。中国有独立注册办法与分类目录；欧盟 IVD 走 IVDR（不是 MDR 的 Rule 6/11！），风险分类、性能评价、公告机构介入逻辑完全不同。

## 二、中国 IVD：分类体系（2024-58 号目录现行）

### 2.1 文件沿革（易混点，务必分清）
| 文件 | 状态 |
|---|---|
| 《6840 体外诊断试剂分类子目录（2013 版）》（食药监械管〔2013〕242 号） | ❌ 2025-01-01 起废止 |
| 2017 年 226 号通告（过敏原/流式/免疫组化/原位杂交类别调整） | ❌ 2025-01-01 起废止 |
| 2020 年 112 号公告（6840 部分内容调整） | ❌ 2025-01-01 起废止 |
| 《体外诊断试剂分类规则》（2021 年 129 号公告） | ✅ 现行（分类总规则） |
| **《体外诊断试剂分类目录》（2024 年 58 号公告，2024-05-10 发布，2025-01-01 实施）** | ✅ **现行分类目录** |
| 《关于实施〈体外诊断试剂分类目录〉有关事项的通告》（2024 年 17 号） | ✅ 实施衔接细则 |

### 2.2 现行分类目录结构
- **25 个一级产品类别 + 1852 个二级产品类别**；六要素：一级序号/一级产品类别/二级序号/二级产品类别/预期用途/管理类别
- **管理类别：一级类别 1–7 = 三类；8–19 = 二类；20–25 = 一类**
  - 三类（1-7）：致病性病原体抗原抗体核酸检测、血型组织配型、人类基因检测、遗传性疾病、麻醉/精神/毒性药品检测、治疗药物靶点与伴随诊断、肿瘤筛查诊断分期
  - 二类（8-19）：蛋白质、糖类、激素、酶类、酯类、维生素、无机离子、药物及代谢物、自身抗体、微生物鉴别药敏、变态反应、其他生理生化免疫指标
  - 一类（20-25，备案）：微生物培养基（无鉴别功能）、样本处理用产品、反应体系通用试剂、流式单一抗体及同型对照、免疫组化单一抗体、原位杂交单一探针
- 分类编码**沿用 6840**（避免存量产品因编码调整变更注册）
- 校准品/质控品：与二三类配合使用按同类别管理；与一类配合使用按二类管理；**非定值质控品不作为医疗器械管理**
- 组合产品：预期用途为单项组合 → 按最高管理类别；新增预期用途 → 申请分类界定

### 2.3 新旧衔接关键时间点（2024 年 17 号通告）
| 时间点 | 事项 |
|---|---|
| 2025-01-01 | 新目录实施；首次注册按新目录受理；原 242/226/112 号废止 |
| 2024-07-01 | 一类备案按新目录办理（2024-07-01 前已备案的自查） |
| **2027-01-01** | 类别调整的存量注册证**有效期不得超过此日**；此日起未依法取得注册证的不得生产/进口/销售 |

### 2.4 中国 IVD 注册与临床评价
- 注册：市场监管总局令第 48 号（2021-10-01 实施）——分类、注册、变更、延续全流程
- 临床评价三路径：免于临床试验目录 / 同品种对比 / 临床试验（IVD 临床试验设计 = 对比方法（金标准/已上市同类） + 临床样本性能验证，敏感度/特异度/符合率）
- 延续注册：届满前 6 个月申请；新强标（如 2026-10-01 GB 18279 等）实施导致实质变化须先变更注册

## 三、欧盟 IVDR：分类规则（附录 VIII，7 条规则）

> 分类看**预期用途**不看技术原理；多用途就高归类；自测器械普遍升类。

| 规则 | 归类 | 典型产品 |
|---|---|---|
| Rule 1 | **D** | 供体适用性评估的可传播病原体检测（血液/细胞/组织/器官捐献筛查）、高传播风险致命传染病检测、致命疾病感染载量监测——HIV/乙肝丙肝/HTLV/梅毒/疟疾（输血移植语境）、血型分型（供体评估） |
| Rule 2 | **C**（部分 D） | 性传播病原体、脑脊液/血液中感染因子、产前遗传筛查、血型/组织分型（非供体评估）、**伴随诊断 CDx**、癌症筛查诊断分期、人类基因检测、药物水平监测（错误结果危及生命）、危重疾病管理、胚胎/胎儿先天病筛查、新生儿筛查 |
| Rule 3 | **C** | 非致命感染载量/抗体检测（辅助诊断治疗）、POCT（未被更高规则覆盖） |
| Rule 4 | **C**（例外 B） | 自测器械默认 C；**B 类例外：妊娠、生育力、尿液（葡萄糖/红细胞/白细胞/细菌）、胆固醇、血糖自测** |
| Rule 5 | **A** | 通用实验室用品（缓冲液/洗涤液/通用培养基/组织染色剂）、IVD 仪器、标本容器 |
| Rule 6 | **B** | 兜底规则（未被 1-5/7 覆盖） |
| Rule 7 | **B** | 无定量/定性赋值的质控品 |

**分类影响**：约 80% IVD 产品需公告机构介入（IVDD 时代仅 10–20%）；D 类还需 **EU 参考实验室**验证；伴随诊断（一律 C 类）需与 **EMA/成员国药品主管当局磋商**。

## 四、欧盟 IVDR：过渡期时间表（EU 2024/1860 延长后）⚠️ 时效性强

> 仅 **legacy devices**（IVDD 98/79/EC 证书或 DoC 于 2022-05-26 前签发）可享受延长过渡期；须同时满足：①继续符合原要求且无不可接受风险 ②无重大设计/预期用途变更 ③2025-05-26 前建立 IVDR 合规 QMS ④按时向公告机构提交申请并签书面协议。**任一节点错过即失去过渡期保护。**

| 类别 | 提交 NB 申请截止 | 与 NB 签书面协议 | 过渡期结束（须获 IVDR 证书） |
|---|---|---|---|
| **D** | 2025-05-26 | 2025-09-26 | **2027-12-31** |
| **C** | 2026-05-26 | 2026-09-26 | **2028-12-31** |
| **B / A 无菌** | 2027-05-26 | 2027-09-26/27 | **2029-12-31** |
| A 非无菌 | — | — | 无过渡期（2022-05-26 起直接适用） |
| 新产品（无 IVDD 证书） | — | — | 无过渡期（2022-05-26 起直接适用） |

**中国企业提醒**：D 类（传染病/血型试剂）过渡期已进入最后冲刺（2027-12-31 前须获 IVDR 证书）；C 类（大部分临床化学/血液学试剂）2026-05-26 申请截止临近。公告机构产能仍是最大瓶颈（2025 年底 IVDR 指定 NB 约 17–18 家，平均排队 12–24 个月）——**尽早启动公告机构沟通**。

## 五、IVDR CE 认证路径与关键交付物

| 步骤 | 内容 | 关键交付物 |
|---|---|---|
| 1 | 分类与差距分析（1-2 个月） | 分类确认报告 |
| 2 | 指定欧盟授权代表（非欧盟制造商强制） | 授权代表协议（IVDR 第 11 条） |
| 3 | 建立/升级 QMS（3-6 个月） | ISO 13485 + IVDR 要求 |
| 4 | 编写技术文件（6-12 个月） | Annex II/III 完整技术文件 |
| 5 | 性能评价（6-18 个月） | PEP 计划 + PER 报告（科学有效性/分析性能/临床性能） |
| 6 | 公告机构申请与审核（排队 12-24 个月） | NB 证书（最长 5 年有效） |
| 7 | EUDAMED 注册 + UDI | 注册确认 + UDI-DI |
| 8 | 贴 CE 标志投放市场 | C/D 类 PSUR、PMPF 持续 |

符合性评估路径（IVDR 第 48 条）：A 非无菌自声明（Annex IV）；A 无菌仅评估无菌；B 类 QMS+技术文件抽样；C 类 QMS+每通用器械组代表技术文件；D 类 QMS+完整技术文件+EU 参考实验室。

## 六、常见误区清单（客户咨询高频纠错点）

1. ❌ **"IVD 在欧盟走 MDR"**——错！IVD 走 **IVDR (EU) 2017/746**，与器械 MDR (2017/745) 是两套法规、两套分类（A-D vs I-III）、两套公告机构指定范围
2. ❌ "IVD 中国分类还是 6840 子目录 2013 版"——2025-01-01 起已换 2024-58 号新目录（226/112 号废止）
3. ❌ "自测试剂都是低风险"——IVDR 下自测默认 **C 类**（仅妊娠/生育力/尿液/胆固醇/血糖 5 类例外为 B）
4. ❌ "伴随诊断是普通 III 类/Class D"——中国按一级类别 6（治疗药物靶点与伴随诊断）三类管理；欧盟**一律 C 类**且需与 EMA 磋商
5. ❌ "新证可以慢慢过渡"——新产品无过渡期；A 非无菌无过渡期；错过申请/协议节点失去过渡保护
6. ❌ "质控品都要注册"——**非定值质控品不作为医疗器械管理**（中国）
