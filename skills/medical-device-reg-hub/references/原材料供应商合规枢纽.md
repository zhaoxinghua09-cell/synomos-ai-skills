# 原材料 / 供应商合规枢纽

  骨科植入与手术器械的质量，始于原材料。本枢纽整理金属料（不锈钢 / 镍钛 / 钛）的取证清单、国际与国标材料标准、供应商审计要点及体系证书要求，所有标准官方页均可直达。

## 物料取证清单（按采购类型）

    每批关键物料到货须留存以下文件，构成技术文档与追溯链的一部分。

    
| 物料类型 | 必备文件 |
| --- | --- |
| 金属原材料（棒/管/丝/板） | 熔炼证 / Mill Test Report (MTR)、材质报告(CoA)、材料符合性声明、有限保证证书、批号追溯 |
| 外协加工件（机加工/喷砂/热处理） | 过程流转卡、关键工序确认记录、清洁/钝化记录（如适用） |
| 包装材料 | 供应商 ISO 资质、材质证明、与 ISO 11607 验证的匹配声明 |
| 无菌/灭菌服务 | 灭菌确认报告(ISO 11135/11137)、灭菌批记录 |
| 电子/软件部件 | IEC 60601 / 62304 合规证明（如适用） |

    核心原则：供应商提供的 CoA/MTR 必须可追溯到具体熔炼炉号(lot/heat)，并与成品批记录双向关联，方满足 MDR / NMPA 可追溯要求。

    ## 供应商体系证书要求

    
| 证书 | 适用 | 入口 |
| --- | --- | --- |
| ISO 13485 | 医疗器械 QMS（供应商应具备，尤其关键物料） | [iso.org/iso-13485-medical-devices](https://www.iso.org/iso-13485-medical-devices.html) |
| ISO 9001 | 通用 QMS（非医械专用料可参考） | [iso.org/iso-9001](https://www.iso.org/iso-9001-quality-management.html) |

    关键物料供应商应通过 ISO 13485 体系审核并纳入合格供应商名录；仅持 ISO 9001 的非医械料供应商，须额外评估其对医械法规的满足度。

  

  
    ## 供应商审计清单

    按风险分级：关键物料(A级)现场审计，一般物料(B级)文件/问卷审计。

    
| 审计项 | 核查要点 |
| --- | --- |
| 资质 | 营业执照、ISO 13485 证书、行业许可（如压力容器/特材） |
| 产能与设备 | 关键设备清单、校准状态、洁净/熔炼能力 |
| 追溯 | 炉号/批号管理、MTR 出具流程、不合格品控制 |
| 变更管理 | 材质/牌号/工艺变更的通报与重评机制 |
| 文件 | CoA 模板、符合性声明、有限保证格式 |

  

  
    ## 变更控制

    原材料牌号、供应商、关键工艺变更均须启动变更评估。

    

  
    ## 骨科关联提示

    结合你当前项目：
    • 630 不锈钢喷砂骨科件：重点核 ASTM F138/F139（或 GB 4234）材质报告 + 喷砂/清洁验证（内毒素检验）闭环；
    • 镍钛(NiTi)中空管/丝材：引用 ASTM F2063（相变温度、超弹性），并关注 134°C 湿热灭菌对 NiTi 力学性能影响的验证数据；
    • 所有金属料 CoA 须含炉号，方可支撑清洁验证与内毒素追溯。
