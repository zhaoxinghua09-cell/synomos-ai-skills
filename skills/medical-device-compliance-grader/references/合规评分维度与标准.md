# 合规评分维度与标准

医疗器械合规度量化评分：**8 大维度 × 0-5 分**。评分锚点统一（0=缺失，1=仅提及，2=部分成文，3=基本完整，4=完整可查证，5=标杆级），每维附法规依据。评分基于**现有证据**（文件路径/状态），证据缺失即低分。

> 制作日期：2026-08-27 ｜ 依据来源：复用注册枢纽已核验清单 + 各专题技能知识库（ISO 14971、MDR、121 号公告等）

---

## 一、评分锚点（通用）

| 分值 | 含义 | 判定标准 |
| --- | --- | --- |
| 0 | 缺失 | 完全无相关文件/活动 |
| 1 | 仅提及 | 只有口头/纪要提及，无成文文件 |
| 2 | 部分成文 | 有部分文件，但结构不完整/未覆盖全部要求 |
| 3 | 基本完整 | 文件齐全、结构符合要求，可支撑注册/审评 |
| 4 | 完整可查证 | 文件完整且互相引用闭环，证据可追溯 |
| 5 | 标杆级 | 完整 + 经审评/审核认可或按较佳实践持续维护 |

---

## 二、8 大维度

### D1 注册路径与分类（Regulatory Pathway & Classification）
- **考察点**：产品分类界定（中国 I/II/III、美国 Class I/II/III、欧盟 Rule 分类）、注册路径（备案/注册/510(k)/De Novo/PMA/MDR CE）、分类依据文件
- **依据**：NMPA 分类目录、《医疗器械分类规则》、FDA 21 CFR、MDR Annex VIII

### D2 技术文件完整性（Technical Documentation Completeness）
- **考察点**：技术文档结构是否按目标市场要求组织（STED 六章 / MDR Annex II / 121 号公告模块）、描述/设计制造/验证章节是否齐全
- **依据**：IMDRF STED、MDR Annex II/III、中国 2021 年第 121/122 号公告

### D3 风险管理（Risk Management）
- **考察点**：风险管理报告（ISO 14971 六步流程）、危害识别完整性、风险矩阵与可接受准则、控制措施验证、残余风险与获益-风险结论
- **依据**：ISO 14971:2019 / GB/T 42062-2022、MDR Annex I GSPR、21 CFR 820.30

### D4 临床评价（Clinical Evaluation）
- **考察点**：临床评价路径判定（免临床/同品种/试验）、CER 结构与内容（等同性论证、文献检索方案、数据评估）、获益-风险结论
- **依据**：免临床目录（2025 年版）、MDCG 2020-13、FDA 510(k) SE

### D5 标签与说明书（Labeling & IFU）
- **考察点**：标签要素完整性（UDI、灭菌信息、符号）、IFU 内容（含再处理程序）、语言与符号合规（ISO 15223-1）、版本管理
- **依据**：局令 6 号、MDR Annex I 23 条、MDCG 2019-15、21 CFR 801/809、ISO 15223-1:2021

### D6 软件与网络安全（Software & Cybersecurity，如适用）
- **考察点**：SaMD/嵌入式软件判定、风险分类（IMDRF N12 / 三级关注 / MDR 规则 11）、IEC 62304 文档、网络安全（威胁建模/SBOM/漏洞管理）、人因
- **依据**：IEC 62304、IMDRF N12、MDCG 2019-16、FDA 软件/网络安全指南、CMDE 软件注册指导原则

> 注：纯无源器械此项评 **N/A**（不参与总分分母），但人因（IFU 可用性）仍应在 D5/D3 中体现。

### D7 上市后监管（Post-Market Surveillance）
- **考察点**：PMS 计划、不良事件监测与报告（渠道/时限）、定期报告（PSUR/PMS Report）、FSCA/召回流程、PMCF（如适用）、生产后数据反馈
- **依据**：21 CFR 803、MDR 87-92 条 + MDCG 2022-21、中国 2018 年第 1 号令

### D8 质量体系（QMS / GMP）
- **考察点**：体系文件（ISO 13485/中国 GMP 规范）、设计控制（DHF）、供应商管理、CAPA、内审管理评审、体系核查状态
- **依据**：ISO 13485:2016、中国 GMP 规范、21 CFR 820（QMSR）

## 三、总分与等级

| 等级 | 总分（含 N/A 折算） | 判定 |
| --- | --- | --- |
| A（优） | 4.0 - 5.0 | 可支撑申报/持续合规，短板已可控 |
| B（良） | 3.0 - 3.9 | 基本可申报，存在待补项（建议整改后申报） |
| C（中） | 2.0 - 2.9 | 缺项较多，须系统补全后再申报 |
| D（差） | 0.0 - 1.9 | 证据严重不足，先建体系再谈申报 |

**总分算法**：适用维度平均分（N/A 维度不计入分母）。脚本自动计算。

## 四、改进建议（脚本按短板自动生成）

| 维度 ≤ 2 分 | 建议 |
| --- | --- |
| D1 | 先做分类界定/路径判定（官方分类目录或分类界定申请），明确产品类别再启动后续 |
| D2 | 以 STED 六章搭骨架，按目标市场官方模板补全章节 |
| D3 | 立即补风险管理报告（ISO 14971 六步流程），与验证/临床文件互相引用 |
| D4 | 先做路径判定（免临床/同品种/试验），再按官方模板写 CER |
| D5 | 按标签要素检查表 + IFU 框架逐项补全，符号用 ISO 15223-1 |
| D6 | 先判定软件身份与风险分类，再按 IEC 62304 搭文档 + 网络安全评估 |
| D7 | 建 PMS 计划 + 不良事件监测报告流程，明确各市场报告时限 |
| D8 | 建/完善质量体系文件与设计控制记录，安排内审与整改 |

## 五、评分输入 JSON 格式（脚本输入）

```json
{
  "product": "关节镜用复用外科器械",
  "market": "中国 II 类 / 欧盟 MDR IIa / 美国 510(k)",
  "date": "2026-08-27",
  "scores": {
    "D1": {"score": 4, "note": "分类已按目录确认 II 类，路径已定"},
    "D2": {"score": 3, "note": "STED 骨架已搭，验证章节待补"},
    "D3": {"score": 2, "note": "风险管理报告初稿，缺控制措施验证记录"},
    "D4": {"score": 1, "note": "尚未启动临床评价路径判定"},
    "D5": {"score": 3, "note": "标签草稿已有，缺 UDI 与符号核验"},
    "D6": {"score": "N/A", "note": "纯无源器械，无软件"},
    "D7": {"score": 2, "note": "PMS 计划未建，不良事件渠道已接入"},
    "D8": {"score": 3, "note": "ISO 13485 体系运行中，DHF 待完善"}
  }
}
```

- `score` 取 0-5 整数，或 `"N/A"`（不适用，不计入分母）
- `note` 为证据备注（文件路径/状态），供报告与复评对比
- 运行：`python scripts/grade_compliance.py --input scores.json --out report.html`

---

## 六、使用边界

- 本评分体系为**自评工具**，评分结论仅代表按维度锚点的自评状态，**不构成**监管机构/公告机构的正式裁定，不替代专业 RA 审查。
- 维度覆盖主流合规要求，创新器械、AI 软件、特殊材料等可能需按产品特性增补维度；评分基于提供的证据，证据缺失即低分。
