# 定位（Positioning）

`summarize-file` 是一个**文件摘要方法论技能**：接收用户给的本地文件路径，读取其中文本，按「真实参照法」产出结构化、可溯源的中文（或跟随输入语言）摘要。它提供**标准、约束与执行步骤**，由运行时（Agent + 文件读取工具）执行，本身不内嵌二进制实现代码。

## 何时用

- 用户说「总结一下这个文件 / 这篇文档讲了什么」
- 用户甩出一个本地路径，要几句话提炼要点
- 多页 PDF / DOCX / 长文需要快速速读
- 需要「要点能回原文、不瞎编」的可信摘要

## 何时不用

- 用户要的是**全文翻译 / 改写 / 扩写**，不是摘要 → 转翻译或写作技能
- 文件在**远程网盘且未下载**到本地 → 先落地为本地路径
- 内容是**图片型扫描件无文本层**且未做 OCR → 见「输入约束」降级方案
- 用户要**实时联网检索**最新信息 → 非本技能职责

## 一、能力边界（Capability Boundary）

**支持格式**：TXT、MD、DOCX、PDF、HTML（五种）。

**支持语言**：输入检测后跟随用户语言，覆盖核心 8 种（zh-CN / en / ja / ko / es / fr / de / ar），可要求中英对照等多语种输出。

**文件规模约定（新增）**：
- 单文件建议 **≤ 20 MB 且正文 ≤ 约 5 万字**；超出时按「分块摘要 → 合并」处理，并提示用户。
- 超大文件（>50 MB / >20 万字）默认只摘目录、标题、首尾段，主动说明已降级。

**内容类型处理（新增）**：
- **代码文件**（.py/.js/.sql 等）：可摘要其结构、入口、关键函数与依赖，不臆测运行结果。
- **含图片/图表的文档**：提取文本层；图片内文字若无法解析，标注「图内信息未提取」，建议用户附 OCR 结果。
- **扫描型 PDF（无文本层）**：读取失败 → 触发错误处理，提示用 OCR 工具先转文本。

**输出格式约定（新增）**：固定为「标题 + 一句话总览 + 分点要点（每条带原文定位如页码/段落）+ 待核验项 + 适用建议」，详见「二、输出承诺」。

## 二、输入约束与输出承诺（Input Contract & Output Promise）

### 输入约束
- 必填：一个**本地绝对路径**（或相对当前工作目录的路径）。
- 路径须真实存在且可读；无读权限 / 不存在 → 见「十、错误处理」。
- 不接收远程 URL、不直接读取私密保险库明文（见「八、依赖」）。
- 多文件：可一次给多个路径，逐文件摘要后汇总。

### 输出承诺（真实参照法）
1. **每个要点挂回原文**：标注来源位置（如 `p.3 第2段`、`## 章节名`），便于回查。
2. **不确定即标注，不补全**：信息缺失或存疑写「待核验」，禁止编造细节、数据、引文。
3. **忠实压缩**：保留原意与关键数字，不添加原文没有的判断。
4. **结构固定**：
   ```
   # 文件摘要：<文件名>
   > 一句话总览：<原文在讲什么>
   ## 核心要点
   1. <要点> —— 出处：<位置>
   2. <要点> —— 出处：<位置>
   ## 待核验 / 存疑
   - <不确定项>
   ## 建议
   - <下一步动作>
   ```
5. **语言跟随**：默认与输入同语言；用户指定则切换。
6. **长度自适应**：短文件全摘，长文件按 5–10 条要点收敛。

## 四、常见错误与反模式（FAQ + 高频 Q&A）

### 反模式（PROHIBITED 行为预览，详「七」）
- ❌ 凭印象补全原文没有的数据、引文、结论。
- ❌ 把「待核验」项当确凿事实写进要点。
- ❌ 忽略出处标注，写成无源摘要。
- ❌ 直接把保险库密钥/明文读进对话当文件处理。

### 高频 Q&A
**Q1：摘要不准确/漏了重点？**
A：长文件已分块；可要求「聚焦某章节」或「更详细」，并指明关注维度（结论/方法/数据）。

**Q2：PDF 是扫描件读不出字？**
A：属无文本层，本技能无法解析图像文字；请用 OCR 工具转文本后重试（见「十」）。

**Q3：文件太大卡住？**
A：超过 20 MB / 5 万字会自动降级为目录+首尾段摘要并提示；可分批给路径。

**Q4：能读网盘/远程链接吗？**
A：不能。先下载到本地得到路径；远程私密内容走对应连接器，不进对话明文。

**Q5：输出能换语言吗？**
A：能。说「用英语总结」即可；多语种术语标注原文+译名。

**Q6：会泄密吗？**
A：仅读取你给的本地路径；私密凭据从保险库读取，不进入对话（见「八」）。

## 五、标准 SOP（Standard Operating Procedure）

| 步骤 | 动作 | 产出 / 判断 |
|---|---|---|
| 1. 收路径 | 解析用户给出的本地路径（可多个） | 路径列表 |
| 2. 校验 | 存在？可读？格式在五类内？ | 否→转「十」 |
| 3. 读文本 | 按格式提取正文（PDF/DOCX 去版式） | 纯文本 |
| 4. 量分级 | ≤5万字符全摘；超出分块 | 块列表 |
| 5. 提炼 | 按真实参照法抽要点，挂出处 | 带源要点 |
| 6. 标注 | 不确定项写「待核验」 | 存疑清单 |
| 7. 成形 | 套「二」的固定结构输出 | 结构化摘要 |
| 8. 收尾 | 给一句话总览 + 建议 | 完成 |

## 七、铁律（PROHIBITED）

1. **禁止编造**：不得补全、臆测原文没有的数据、引文、结论。
2. **禁止无源**：每个要点必须带可回查的原文位置，不得写成无出处概述。
3. **禁止瞒疑**：存疑信息必须标「待核验」，不得伪装成确凿事实。
4. **禁止越权读**：不读取用户未明确给出的路径，不碰系统/私密目录。
5. **禁止泄密**：保险库密钥、令牌等明文不得进入对话或作为待处理文件。
6. **禁止替代**：不把摘要当翻译/扩写/实时联网检索交付。
7. **禁止声称疗效**：非医疗软件，不作临床/疗效声明。

## 八、输入输出依赖（Dependencies）

- **输入**：本地文件路径（绝对/相对）。运行时用文件读取工具取文本。
- **输出**：结构化摘要文本（Markdown）。
- **凭据/密钥**：如流程需访问私密存储（如网盘令牌），**一律从本地保险库（凭据库）读取，密钥明文不进入对话、不写入本技能、不回显给用户**。本技能自身不持有任何密钥。
- **外部能力**：PDF/DOCX 解析、OCR（扫描件）、多语种由运行时环境提供；缺失时按「十」降级提示。
- **无网络依赖**：纯本地文件速读，离线可用。

## 九、示例（Examples）

### 示例 A：普通 MD 文件
输入：`总结 D:/notes/plan.md`
输出：
```
# 文件摘要：plan.md
> 一句话总览：一份 Q3 上线路线图，含 3 个里程碑与负责人。
## 核心要点
1. 7 月完成鉴权模块 —— 出处：## 里程碑 1
2. 8 月灰度发布 —— 出处：## 里程碑 2
3. 负责人：张三/李四 —— 出处：## 分工
## 待核验
- 预算数字未在文中出现
## 建议
- 确认预算后再排期
```

### 示例 B：扫描件 PDF（降级）
输入：`读 scan.pdf`
输出：「⚠ 该 PDF 无文本层（疑似扫描件），无法提取文字。请用 OCR 工具转文本后重试，或提供含文本层的版本。」

### 示例 C：多文件
输入：`a.md 和 b.docx 各讲什么`
输出：分别给出两份「文件摘要」，末尾加一行对比异同。

## 十、错误处理（Error Handling）

| 错误场景 | 识别 | 用户引导（友好提示） |
|---|---|---|
| 文件不存在 | 路径无效 | 「找不到该文件，请核对路径或先下载到本地。」 |
| 无读权限 | 权限拒绝 | 「没有读取权限，请检查文件权限或换路径。」 |
| 格式不支持 | 非五类格式 | 「暂仅支持 TXT/MD/DOCX/PDF/HTML，请转换格式。」 |
| 扫描件/无文本层 | PDF 无文本 | 「疑似扫描件，请先用 OCR 转文本后重试。」 |
| 文件过大 | >50 MB/>20万字 | 「文件超大，已降级为目录+首尾段摘要；可分批处理。」 |
| 编码错误 | 读取乱码 | 「编码识别失败，请指定编码（如 UTF-8/GBK）后重试。」 |
| 解析超时/崩溃 | 运行时异常 | 「读取中断，请重试或拆分成更小文件。」 |

**原则**：任何异常都给用户**可读的原因 + 下一步动作**，不抛原始技术栈错误；不静默失败、不编造兜底内容。
