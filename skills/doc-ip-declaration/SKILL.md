# doc-ip-declaration · PDF 产权声明一键注入

## 定位

**何时用**：用户需要对**自有/有权处置**的 PDF 文档加「知识产权/版权保护」标识——著作权声明+免责、AI 生成披露+不可见密文追踪、付费许可/授权联系方式、写入 PDF 元数据。典型场景为医院/药企/器械公司等机构对自有文件做版权保护与合规披露。

**何时不用**：
1. 文件来历不明或无权处置（禁止擅自加声明）。
2. 需要真正加密/防泄露——本技能是溯源手段，**不是加密**。
3. 加密/密码保护 PDF、纯扫描图片 PDF（文本提取失败，密文追踪失效）。
4. 非 PDF 文件。

> 首次使用先装依赖：`pip install pypdf reportlab`

## 一、能力边界（In/Out scope）

**本技能做（In）**
1. 著作权声明 + 免责条款（独立声明页 + 每页页脚）。
2. AI 属性不可见密文追踪：每页嵌入 alpha=0 追踪码（肉眼不可见、文本提取可获取），并写入 PDF 元数据 `/TrackingID`。
3. 版权付费许可声明 + 授权/付费联系方式（写入声明页）。
4. 全部参数可改，支持对多份 PDF 批量调用。

**本技能不做（Out / 明确禁止）**
1. ❌ 不做加密：密文追踪是溯源标记，不是密码学加密；被整页截图、重排为图片、转 OCR 后可能失效。
2. ❌ 不处置无权文件：只处理用户自有/已授权文档。
3. ❌ 不处理加密/密码保护 PDF（无法解析页面）。
4. ❌ 不保证扫描图片版 PDF 的追踪生效（无文本层则无法嵌入/提取）。
5. ❌ 不自动联网核验机构真实性；机构名/联系方式/许可条款须由用户替换为真实信息。

## 二、输入约束与输出承诺

**推荐问法**
- 「给这份 PDF 加著作权声明和版权声明」
- 「加上 AI 生成披露 + 不可见水印追踪」
- 「标上付费许可和授权联系方式，写入元数据」

**字段引导（调用前必问/必填）**

| 字段 | 是否必填 | 说明 |
|---|---|---|
| `--input` | 必填 | 待处理 PDF 路径 |
| `--output` | 必填 | 输出 PDF 路径 |
| `--org` | 建议 | 权利方机构名（默认"某某医院"，**须替换为真实机构**） |
| `--contact` | 建议 | 授权/付费联系方式（**含占位符 `{授权邮箱}`/`{联系电话}` 时必须先替换**） |
| `--tracking-id` | 可选 | 不传自动生成 |
| `--license` | 可选 | 覆盖默认付费许可文案 |

**输出承诺**
- 输出 PDF 含：声明页（可选）+ 每页页脚（可选）+ 每页不可见密文（可选）+ PDF 元数据 TrackingID。
- 控制台回显：输出路径、追踪码、页数。
- 交付前提示：中文文案中的机构名/联系方式/许可条款须替换为用户真实信息。

## 四、常见错误与反模式

**FAQ · 反模式（先写✗再写✓）**
- ✗ 反模式：直接把默认 `--contact "授权联系：{授权邮箱} / {联系电话}"` 交付给用户。
  ✓ 替代：先提示用户替换占位符为真实授权邮箱/电话，再交付。
- ✗ 反模式：以为加了密文追踪就"加密防泄密"。
  ✓ 替代：明确告知这是溯源标记、非加密；截图/重排可能失效，须在声明页写清。
- ✗ 反模式：对来路不明的 PDF 直接加声明。
  ✓ 替代：仅处理用户自有/已授权文件；无权文件一律拒绝。

**高频 Q&A**
- Q：追踪码会被肉眼看到吗？A：不会。alpha=0 完全透明，但用 pypdf 提取文本能搜到 `TRACKING:` 串，PDF 元数据可见 TrackingID。
- Q：批量处理多份怎么办？A：对每份 PDF 各调用一次脚本，或用 shell 循环；每份生成独立 tracking-id（也可手动指定统一前缀）。
- Q：字体缺失会怎样？A：脚本自动回退 Helvetica；中文文案建议保持 STSong-Light，缺失时部分中文可能渲染异常（见错误处理 E004）。
- Q：密文追踪在扫描图片 PDF 生效吗？A：不生效（无文本层）。见能力边界 Out 4。

## 五、标准 SOP

| 步 | 动作 | 产物 | 易踩坑 |
|---|---|---|---|
| 1 | 确认文件为可解析 PDF 且用户有权处置 | 确认结论 | 加密/图片 PDF 直接报错（E003/E004） |
| 2 | 安装依赖 `pip install pypdf reportlab` | 依赖就绪 | 缺依赖报 ModuleNotFoundError（E002） |
| 3 | 准备参数：`--input/--output/--org/--contact`；替换占位符 | 参数集 | `{授权邮箱}` 未替换为真实信息（反模式） |
| 4 | 执行脚本（可开关 `--declaration-page/--watermark/--footer`） | 输出 PDF + 控制台回显追踪码 | 输出目录不可写（E005） |
| 5 | 验证：pypdf 提取文本搜 `TRACKING:`；读元数据看 TrackingID | 验证通过 | 未做验证就交付 |
| 6 | 交付前提示用户替换机构名/联系方式/许可为真实信息 | 最终交付 | 占位符残留 |

基础命令：
```bash
python "$SKILL_DIR/add_ip_declaration.py" \
  --input   待处理.pdf \
  --output  已加声明.pdf \
  --org     "某某医院" \
  --contact "授权联系：real@org.com / 010-xxxx" \
  --tracking-id "ORG-20260819-A1B2C3D4"   # 不传自动生成
```
可选开关：
- `--declaration-page yes|no`（默认 yes）是否追加独立声明页
- `--watermark yes|no`（默认 yes）是否嵌入不可见密文追踪
- `--footer yes|no`（默认 yes）是否加每页声明页脚
- `--license "自定义许可文案"` 覆盖默认付费许可声明

> `$SKILL_DIR` 即本 Skill 所在目录。

## 六、关键事实速查

- 默认许可文案：未经书面授权不得商用/转载/二次分发/抓取/训练/牟利（见脚本 `DEFAULT_LICENSE`）。
- 追踪码格式：`{机构前缀}-{YYYYMMDD}-{8位随机}`（如 `DOC-20260819-A1B2C3D4`）。
- 不可见密文文本：`TRACKING:{id} ©{org} CONFIDENTIAL-IP`，每页多处放置（提升提取概率）。
- 元数据键：`/TrackingID`、`/Subject=TrackingID=...`、`/Keywords=copyright,AI-tracking,license`。
- PDF 元数据读取方式（**待核验**：以你环境 pypdf 版本为准）：`reader.metadata.get('/TrackingID')`。
- 中文渲染依赖 Adobe CID 字体 `STSong-Light`（脚本内自动注册，缺失回退 Helvetica）。

## 七、铁律（PROHIBITED 绝对禁止）

1. 禁止对来历不明、无权处置的 PDF 加声明。
2. 禁止声称密文追踪=加密；必须如实说明其为溯源标记且可能失效。
3. 禁止在交付物中保留 `{授权邮箱}`/`{联系电话}` 等占位符——必须替换为真实信息。
4. 禁止处理加密/密码保护 PDF 或声称其有效（Out 3）。
5. 禁止把追踪码当保密凭证写入日志/对话传播。

## 十、错误处理

| 错误码 | 现象 | 原因 | 修正引导 |
|---|---|---|---|
| E001 | `[err] 输入文件不存在` | `--input` 路径错误/文件缺失 | 核对路径，确认文件存在 |
| E002 | `ModuleNotFoundError: pypdf/reportlab` | 未装依赖 | `pip install pypdf reportlab` 后重试 |
| E003 | 解析报错/页面为空 | PDF 损坏或加密保护 | 提供可解析 PDF；加密件按七·4 拒绝 |
| E004 | 中文渲染异常/字体告警 | STSong-Light 不可用 | 脚本已回退 Helvetica；如需中文请确保该字体可用 |
| E005 | 写入失败（PermissionError） | 输出目录不可写 | 换有权限的输出路径 |
| E006 | 用户无法证明文件权属 | 来路不明 | 按七·1 拒绝，要求提供权属证明 |
