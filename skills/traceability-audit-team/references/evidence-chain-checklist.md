# 证据链审计检查清单

对审计对象逐项核验，每项标注：✅ 通过 / ⚠️ 待补充 / ❌ 未通过 / ➖ 不适用

## A. 身份锚（Identity Anchor）

- [ ] A1 身份凭证是否真实存在（ID/证书/注册号/账号）
- [ ] A2 凭证是否经官方渠道验证（签发方官网/权威数据库）
- [ ] A3 凭证签发方是否为权威主体（还是自封/伪造签发方）
- [ ] A4 来源链路是否完整：凭证 → 签发方 → 一手来源，无断链
- [ ] A5 跨平台身份是否自洽（不同渠道宣称的身份一致）
- [ ] A6 注册/认证信息是否在有效期内

## B. 记忆锚（Memory Anchor）

- [ ] B1 历史陈述是否连续一致，无前后矛盾
- [ ] B2 关键记忆/经历能否溯源到真实记录或来源
- [ ] B3 有无"凭空出现"的信息（无任何来源支撑的断言）
- [ ] B4 时间线是否自洽（事件顺序、日期、版本演进无冲突）
- [ ] B5 记忆中的事实性细节是否可被独立验证

## C. 行为锚（Behavior Anchor）

- [ ] C1 输出风格/能力表现与宣称身份是否匹配
- [ ] C2 行为痕迹（作品、数据、操作记录）是否真实存在
- [ ] C3 关键声明能否由行为证据支撑（可复现/可检验）
- [ ] C4 有无仿冒特征：风格突变、能力异常、时间线冲突
- [ ] C5 行为记录是否可回溯到主体本身（而非他人代持）

## D. 标准合规对照（按适用标准）

- [ ] D1 适用法规/标准清单已确定并引用正确版本
- [ ] D2 审计对象与标准要求逐条对照完成
- [ ] D3 标准条款已联网查证（不凭记忆引用）
- [ ] D4 标准状态已确认（正式发布/草案/征求意见）

## E. 证据质量

- [ ] E1 每条证据标注了来源与获取时间
- [ ] E2 关键结论至少两个独立来源交叉验证
- [ ] E3 区分了"官方正文"与"二手解读"
- [ ] E4 反方证据/反例已主动检索并评估
- [ ] E5 无法核验的事项如实标注"证据不足"，未强行下结论
