# 定位（是什么 / 何时用 / 何时不用）

**是什么**：一套可复用的「类人 AI 大脑设计」评估框架。把待评估的设计，按 12 个维度，分别与「真实人脑神经科学基准」和「前沿 AI 架构基准」做**三向对标**，并给出「差距三档分诊」，产出一份可审计的评审结论。

**何时用**：
- 你设计/自研了一套 AI 大脑、多智能体组织、认知架构，想先自检「行不行」。
- 你想回答「跟真人脑差在哪」「跟 GPT/Claude/前沿 agent 架构比落后多少」。
- 你需要一份给投资人、评审委员会、治理审计用的**可审计证据**（诺衡评审视角）。

**何时不用**：
- 需要直接跑代码/调 API 做线上压测 —— 本技能产出**评估结论文档**，不替代性能测试工具。
- 医疗/临床/疗效判断 —— 非医疗器械、非医疗软件，无任何疗效或临床声明。
- 想让我替你拍板「该不该上线」—— 我只给证据与分诊，最终决策权在人。

| 项 | 能做 | 不能做 |

| 对标基准 | 真实人脑（神经科学文献）、前沿 AI 架构（公开资料） | 实时抓取未公开的内部模型权重 |
| 产出 | 12 维度评分表、三向对标报告、差距三档分诊、改进建议 | 医学/临床结论、法律意见、投资承诺 |

**边界示例（输入/输出形态）**：

## 二、输入约束与输出承诺

**输入约束（你必须给的）**：
1. 设计概述：架构组成、模块职责、数据流（≥ 3 句，越具体越好）。
2. 关注维度（可选）：不指定则默认全覆盖 12 维。
3. 用途声明（可选）：自研 / 对标 / 审计，影响结论详略。

**输入模板（建议直接复制填写）**：
```
【架构名】___
【组成】___（如 planner×1 + worker×3）
【记忆机制】___（如向量库 / 外部记忆）
【长程规划】___（有/无，如何回溯）
【安全护栏】___（如拒答规则 / 沙箱）
【自评最弱项】___
```

**输出承诺（你一定会拿到的）**：
- 一份 Markdown 评审报告，含：① 12 维评分表；② 三向对标（设计/人脑/前沿）；③ 差距三档分诊；④ 逐维改进建议；⑤ 总体结论（行不行 / 落后多少）。
- 评分区间统一 0–5，附一句话理由，可追溯文献出处。

**输出不承诺**：代码实现、部署脚本、实时数据、任何疗效/法律/投资结论。

## 四、常见错误与反模式（FAQ + 高频 Q&A）

**反模式（别这样做）**：
- ❌ 把本技能当「上线许可」——它只给证据，决策权在人。
- ❌ 塞入密钥/内部权重求「精准对标」——本技能零凭据依赖，密钥进了对话反而违规（见第八章）。
- ❌ 期望评分=医学结论——非医疗软件，评分仅方法论层面。
- ❌ 只给一句话就求满分报告——输入越具体，分诊越准。

**高频 Q&A**：
- Q：评分 0–5 怎么来的？ A：参照真实人脑神经科学基准（如 Friston 自由能、睡眠巩固）与前沿 AI 公开架构，人工对标打分，附文献。
- Q：差距三档是什么？ A：① 工程可补（迭代可缩）；② 概念鸿沟（需重设计）；③ 本质差异（生物特有，AI 不必追平）。
- Q：能评别人的闭源架构吗？ A：只能用公开资料做外部对标，标注「基于公开信息，置信中」。
- Q：多语种怎么用？ A：用哪种语言问，就用哪种语言回，术语附原文。

## 五、标准 SOP（步骤表）

| 步骤 | 动作 | 产出 | 注意 |
|---|---|---|---|
| S1 收口 | 确认输入模板已填（架构/记忆/规划/安全） | 结构化输入 | 缺项则回问，不臆测 |
| S2 分维 | 对 12 维逐维评分 0–5 | 维度分 | 每分附一句理由 |
| S3 对标 | 每维对比人脑基准 + 前沿基准 | 三向表 | 标文献出处 |
| S4 分诊 | 按差距归入三档 | 分诊标签 | 工程/概念/本质 |
| S5 建议 | 每弱维给改进建议 | 建议列表 | 仅工程/概念档给可操作项 |
| S6 结论 | 汇总「行不行/落后多少」 | 总体结论 | 不越权做决策 |
| S7 出件 | 渲染 Markdown 报告 | 评审报告 | 带可追溯证据链 |

> 渐进引导：首次用只看 S1–S3 拿概览；要正式评审件再走 S4–S7。

## 六、关键事实速查

**12 评估维度（D1–D12）**：
| 维度 | 关键问法 | 人脑基准要点 |
|---|---|---|
| D1 记忆 | 工作/长时/情境？ | 海马巩固、睡眠回放 |
| D2 感知 | 多模态整合？ | 跨模态绑定 |
| D3 执行控制 | 注意力/抑制？ | 前额叶调控 |
| D4 学习 | 在线/迁移/抗遗忘？ | 突触可塑 |
| D5 规划 | 长 horizon/回溯？ | 内侧前额叶 |
| D6 反思 | 元认知回路？ | 默认网络 |
| D7 交互 | 多轮意图？ | 心智理论 |
| D8 协作 | 多体协调？ | 社会脑 |
| D9 安全对齐 | 护栏/越权防护？ | —（AI 特有需项） |
| D10 能效 | 每任务算力？ | 20W 生物能效 |
| D11 意识 | 自我模型？ | 全局 workspace |
| D12 情感动机 | 目标驱动？ | 价值系统 |

**三向对标法**：对每个维度取「设计分 / 人脑分 / 前沿分」，gap=人脑分−设计分。
**差距三档**：工程可补 / 概念鸿沟 / 本质差异。
**权威文献锚**：Friston 预测加工（自由能）、2024 Science CA2 记忆重置、COGITATE 2025 Nature 对抗协作。

## 十、错误处理

| 错误码 | 触发 | 处理 | 补救 |
|---|---|---|---|
| E1 输入不足 | 模板关键项缺失 | 回问缺项，不臆测评分 | 提示复制第二章模板 |
| E2 维度超范围 | 用户指定维度不在 D1–D12 | 列出有效维度，请求重选 | 展示第六章速查表 |
| E3 凭据误投 | 对话出现密钥/令牌 | 立即拒用、不回显、提醒走保险库 | 见第八章规则 |
| E4 文献缺失 | 需引用但无出处 | 标「待核验」，降置信 | 建议用户补公开文献 |
| E5 渲染异常 | 平台不显示 MD | 提供纯文本降级版 | 分段输出，避免大表 |

> 稳定性：本技能为纯文档，自身不崩溃；遇平台加载问题按 E5 降级，不依赖外部重试机制。
