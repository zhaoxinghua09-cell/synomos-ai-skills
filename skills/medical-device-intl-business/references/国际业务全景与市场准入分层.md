# 国际业务全景与市场准入分层

> 本文件回答"全球盘子长什么样、每个市场怎么进去"。注册技术细节（分类/510(k)/MDR/UDI/STED）见 `medxpert-reg-hub`。

## 一、顶层协调框架（出海先懂这两张牌）

### IMDRF —— 监管趋同的总纲
- **International Medical Device Regulators Forum（国际医疗器械监管机构论坛）**，前身 GHTF，2011 年成立。
- 使命：加速国际医疗器械**监管趋同（convergence）**，降低多市场重复审评负担。
- 官方：https://www.imdrf.org/

### MDSAP —— "一次审核，五国通行"
- **Medical Device Single Audit Program**，由 IMDRF 发起，让一家认可的审核机构（AO）做**一次审核**，出标准报告，多国互认。
- **5 个正式成员（RAC）**：澳大利亚 TGA、巴西 ANVISA、加拿大 HC、日本 MHLW/PMDA、美国 FDA。
- **官方观察员**：欧盟、新加坡 HSA、英国 MHRA、WHO（IVD 预认证）。
- **附属成员**：韩国 MFDS、墨西哥 COFEPRIS、阿根廷 ANMAT、南非 SAHPRA、马来西亚 MDA、以色列、肯尼亚、TFDA。
- **底层**：ISO 13485 + 各国特定要求。
- **三年周期**：初审 → 第 2/3 年监督审核 → 第 3 年再认证。
- 官方：https://www.mdsap.global/ ｜ FDA 页：https://www.fda.gov/medical-devices/cdrh-international-programs/medical-device-single-audit-program-mdsap

> **经营杠杆**：想同时进北美（美/加）+ 日本 + 巴西 + 澳洲，一个 MDSAP 覆盖五国体系审核，比逐国做 ISO 13485 认证省大量重复审核成本。

## 二、市场准入分层（怎么排优先级）

按"监管成熟度 × 准入门槛 × 付费能力"分三档，供快速判断先后：

### 第一档 · 成熟市场（门槛高、单价高、长期价值大）
- **美国（FDA）**、**欧盟（MDR/CE）**、**日本（PMDA）**、**加拿大（HC）**、**澳大利亚（TGA）**。
- 特点：注册路径清晰但严格、周期长、费用高；准入后品牌溢价与订单稳定性最好。
- 打法：**先啃一个成熟市场拿"标杆注册证"**（如 FDA 510(k) 或 CE），后续许多新兴市场认可其证据、可走简化/依赖路径。

### 第二档 · 高增长新兴市场（门槛中等、增速快）
- **东南亚**（新加坡 HSA 为枢纽、马来西亚 MDA、泰国 Thai FDA、印尼、越南、菲律宾）、**韩国 MFDS**、**巴西 ANVISA**、**墨西哥 COFEPRIS**、**印度 CDSCO**、**中东**（沙特 SFDA、阿联酋）。
- 特点：增长快、竞争相对缓，但各国规则差异大、本地代表/翻译/文件要求繁琐。
- 打法：**借 MDSAP + 标杆注册证**降低体系审核负担；优先选有区域协调机制的市场（ASEAN AMDD、GCC）。

### 第三档 · 低资源市场（门槛低但合规风险与回款风险并存）
- 非洲（SAHPRA 南非为枢纽、AMDF）、部分拉美、中亚、东南亚边缘市场。
- 特点：准入门槛低，但**注册体系不健全、回款/信用/知识产权风险高**。
- 打法：谨慎进入，优先走 WHO 预认证（IVD 尤其）或依托当地强力经销商，控制账期与库存。

## 三、主要市场准入路径速览（经营视角）

> 下表只给"准入路径 + 经营要点"，**分类与申报细节一律查 `medxpert-reg-hub`**。

| 市场 | 核心路径 | 经营要点 |
|---|---|---|
| 美国 | Establishment Registration + Listing；Class II 多走 **510(k)**，Class III 走 **PMA** | 需美国代理人；注册≠获批，510(k) 周期约 3–6 个月 |
| 欧盟 | **MDR 2017/745** 下 CE 标志；分级自我声明或公告机构（NB） | 公告机构产能是瓶颈；需欧代（EU Authorized Rep）；EUDAMED 登记 |
| 中国 | 进口需国家局注册；Ⅰ类备案/Ⅱ类省局/Ⅲ类国家局 | 进口产品需境内代理人；国产与进口路径不同 |
| 日本 | 外国制造商登记 + PMDA 审评（一般/管理/高度管理分级） | 需 MAH（上市许可持有人）或指定 DMAH；日语文件 |
| 加拿大 | 器械注册（MDL），Class II/III/IV 原则上强制 **MDSAP** | MDSAP 是硬门槛；英法双语标签 |
| 澳大利亚 | ARTG 列入（Australian Register of Therapeutic Goods） | 接受部分 CE/海外证据；需澳洲代理人（Sponsor） |
| 巴西 | ANVISA 注册（Cadastro / Registro 分级） | 需本地注册持有人；葡语文件；MDSAP 成员 |
| 韩国 | MFDS 注册（KGMP 认证 + 产品注册） | 需韩国代理人；韩语文件 |
| 东南亚 | 新加坡 HSA / 马来西亚 MDA / 泰国 Thai FDA 为主，ASEAN AMDD 协调 | 各国差异大；常需本地代表 + 本地语言 |
| 中东 | 沙特 SFDA、阿联酋为主，GCC 协调 | 需本地代表；阿拉伯语标签 |

## 四、质量体系一体化（一次投入覆盖多市场）

- **ISO 13485:2016** 是底座，各国体系核查（中国 GMP、美国 QSR/820、欧盟 MDR 附件 IX 等）都以其为骨架。
- **MDSAP** 把美/加/日/巴/澳五国的体系审核合并成一次。
- 出海效率公式：**ISO 13485 打底 → MDSAP 覆盖五国 → 逐国产品注册**，避免"每进一国就重做一套体系审核"。
