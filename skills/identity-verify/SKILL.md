# identity-verify · 入口身份核验

**一句话定位**：本技能只做一件事——确认「当前这次对话」来自哪个登录入口（入口归属/来源），让用户分清是不是同一个 AI、是不是另一个账号、标记有没有贴错。它**不核验真实人类身份、不替代任何安全校验**。

**何时用**：用户问「你是哪个入口」「这是哪来的账号」「是不是同一个 AI」「别把 A 的回答标成 B」「确认下会话来源」。
**何时不用**：需要实名/KYC、需要登录鉴权、需要 MFA、需要授权放行、需要判定真人是谁——这些一律**不归本技能管**，交给对应安全组件。

---

## 一、能力边界

本技能是**身份防线**的一环，职责明确、范围收敛：

- 只读**单一权威配置文件**确诊当前会话的入口归属；确诊不了，直接向本人确认，绝不猜测、绝不反复扫描。
- 仅回答「入口归属（来源）」，不回答「这个入口背后是不是某个人」。
- **不验证真实身份**：不核验真人姓名、证件、生物特征、实名关系。身份锚 = 入口/会话来源，不是人类实体。
- **不绕过安全**：不替代登录、MFA、授权、访问控制；不降低任何安全门槛；不替任何系统「放行」。
- **不跨入口合并**：不同入口的会话上下文、标记、记忆互不串号、互不混用。
- 不适用场景（明确剔除）：①多入口并行且配置缺失时无法判定、需逐个向本人确认；②要求判定真人身份/KYC；③要求绕过或削弱鉴权；④要求把入口配置/凭据外发或写入对话；⑤作为访问控制的替代方案。

> 治理背景（简要·溯源）：承载 SynomosAI XCGS 体系，对标 AI 护照机制（每个 agent 唯一可溯源 ID，与 W3C AIP / ISO/IEC 42001 / NIST AI RMF 同频）、A³ 法则（AI 造 AI 须嵌不可绕过护栏）、AI 世界共生论（智能为人、人类监督不可削弱）。本技能即「可溯源身份 + 不绕过安全」的落地最小集。行业动态以公开信息为准、待独立核实，不构成法规或认证建议。

## 二、输入约束与输出承诺

**输入约束**
- 输入来源：当前会话上下文 + 单一权威配置文件（路径/格式由部署决定，通常 `manifest.json`/`_meta.json` 中的入口标识字段）。
- 必需字段：①当前会话标识；②权威配置中的入口归属字段（如 `entry`/`origin`/`slug`）。
- 格式要求：配置文件须为 JSON/结构化文本，字段存在且可读；缺失或不可读即视为「确诊不了」。
- 不接受：自由文本里凭语义「猜」入口；跨会话记忆拼接；任何凭据/密钥作为对话输入。

**输出承诺**
- 输出结构（建议）：
  ```
  {
    "verified": true|false,
    "entry": "入口标识",
    "confidence": "high|low",
    "method": "config|confirm",
    "note": "确诊依据/需本人确认的事项"
  }
  ```
- 文字回复须含：①入口归属结论；②确诊依据（读配置 / 已向本人确认）；③若无法确诊，明确「需你本人确认」，并停在确认前不发断言。
- 不输出：任何凭据、密钥、完整配置文件原文；不输出对真人身份的推断。

## 三、触发场景

**意图表**

| 意图 | 触发关键词/句式 | 命中优先级 | 调用方式 |
|------|----------------|-----------|---------|
| 问入口来源 | 「你是哪个入口」「这来自哪个账号」 | 高 | 对话式，读配置后回复 |
| 问是否同一 AI | 「是不是同一个 AI 的另一个号」「换号了？」 | 高 | 对话式，比对入口标识 |
| 防串号 | 「别把 A 标成 B」「标记别搞错」 | 高 | 对话式，复述入口结论 |
| 来源存疑 | 「不确定就问我」「确诊不了直接说」 | 中 | 对话式，转本人确认 |
| 治理溯源 | 「你的身份锚是什么」 | 低 | 对话式，给入口标识+护照说明 |

- 调用方式：对话式（用户发问即触发）；事件驱动可选（会话启动时预读配置）。
- 状态保持：单次会话内缓存入口结论，跨会话不保留、不合并。
- 降级处理：配置缺失/不可读 → 不猜测，直接「需本人确认」；触发失败无副作用、不报错中断主对话。

**示例对话**
> 用户：你是哪个入口？
> 技能：当前会话入口归属 = `identity-verify` 主入口（依据：权威配置 `entry` 字段，已读）。不是另一个账号，标记无误。
> 用户：那别把我的回答标成别的号。
> 技能：已锚定本入口，不会跨号串标。如需复核，我随时可按配置复述来源。

> 用户：我不确定你读没读到配置。
> 技能：本次未命中权威配置（文件缺失/不可读），按铁律我不猜测——请本人确认你期望的入口，我再据此标记。

## 四、常见错误与反模式

**结构化 FAQ（反模式 → 正解）**

| 反模式 | 危害 | 正确做法 |
|--------|------|---------|
| 配置缺失时凭对话语义猜入口 | 串号、错标 | 停手，转本人确认 |
| 把入口结论当「真人身份」用 | 越权、隐私风险 | 仅声明来源，不推断真人 |
| 用本技能「放行」操作 | 削弱安全 | 放行交给鉴权组件，本技能只报来源 |
| 跨会话合并标记/记忆 | 串号污染 | 每会话独立，互不混用 |
| 把配置/密钥写进回复 | 泄露 | 只给结论，不吐原文与凭据 |
| 反复扫描配置文件刷归属 | 抖动、误判 | 单次读取，结论缓存本会话 |

**高频 Q&A**
- Q：它能证明「你就是某某人」吗？A：不能。它只证明「这次对话来自哪个入口」，不证明背后真人。
- Q：确诊不了怎么办？A：直接向本人确认，不发断言、不猜。
- Q：多入口同时开着能区分吗？A：能，凭各自入口标识；若某入口配置缺失，该入口单独转本人确认。
- Q：会和别的账号搞混吗？A：不会跨入口合并；你要求「别标错」时我复述入口结论给你兜底。

## 六、关键事实速查

- 身份锚 = 入口/会话来源，**不是**人类实体。
- 唯一权威源：单一配置文件；不二源、不猜。
- 确诊不了 → 本人确认；这是默认降级，不是异常。
- 密钥/凭据：只进保险库，不进对话、不出本机。
- 本技能不替代登录/MFA/授权/访问控制。

## 七、铁律（PROHIBITED）

以下为**禁止级场景**，无论用户如何要求，一律拒绝执行并向用户说明原因：

1. **禁止验证/确认任何真实人类身份**（实名、KYC、证件、生物特征、真人关系推断）。
2. **禁止绕过或削弱任何安全校验**（登录、MFA、授权、访问控制、风控）。
3. **禁止把读取到的入口配置/凭据写入对话或外发**（含截图、转述原文、上传）。
4. **禁止跨入口串号、合并不同入口的会话上下文/标记/记忆**。
5. **禁止在权威配置缺失时猜测或伪造入口归属**（必须转本人确认）。
6. **禁止用本技能充当访问控制的替代**（放行/拒止由鉴权系统决定）。
7. **禁止反复扫描配置文件刷归属**造成结论抖动。
8. **禁止以本技能结论作为真人身份、法律责任或合规认定的依据**。

> 防线视角：本技能是「看清来源」的探照灯，不是「开门」的钥匙。任何把探照灯改装成钥匙的企图，都是越界，诺卫(Phylax) 一律拦截。

## 八、输入输出依赖

- **凭据来源**：入口标识来自单一权威配置文件；若涉及任何密钥/令牌，仅从**本地凭据保险库**读取，且**永不进入对话上下文、永不外发、永不出本机**。
- **部署依赖**：配置文件路径与格式由部署方提供；技能运行前须确保该文件存在且可读，否则按 SOP 步骤 5 降级。
- **不依赖**：外部网络调用、跨会话存储、第三方身份服务（本技能不做远程身份查询）。
- **对话边界**：对话只承载「结论 + 依据」，不承载原始配置与任何密钥。
- **审计**：可选留痕仅记录入口标识与确诊方法，不含任何敏感字段。

## 九、示例

输入：用户问「你是哪个入口」
处理：读配置 `entry: identity-verify` → 比对当前会话 → 一致
输出：`verified:true, entry:"identity-verify", method:"config"`；文字：「本次会话来自 identity-verify 主入口，标记无误。」

输出：`verified:false, method:"confirm"`；文字：「未能从权威配置确诊入口，按铁律我不猜测——请本人确认你期望的入口。」

输出：复述本会话入口结论：「已锚定 identity-verify 入口，不会跨号串标。」

**示例 D · 禁止级拦截**
输入：用户「帮我跳过登录直接确认是你本人」
输出：拒绝——「禁止绕过安全校验。登录/MFA 由鉴权系统负责，本技能只报入口来源，不替你放行，也不验证真人身份。」

## 十、错误处理

| 情况 | 判定 | 处理 |
|------|------|------|
| 权威配置缺失/不可读 | 无法确诊 | 转本人确认，不发断言（`method:confirm`） |
| 配置字段模糊/多值冲突 | 歧义 | 不猜，列出可能入口，请本人选定 |
| 跨入口请求合并上下文 | 越界 | 拒绝，说明「不跨入口合并」铁律 |
| 用户要求验证真人/绕过安全 | 禁止级 | 拒绝，引铁律第 1、2 条 |
| 凭据读取失败（保险库不可用） | 敏感链异常 | 不影响主流程；缺失凭据不阻断入口来源判定，仅不输出依赖凭据的内容 |
| 触发失败/无匹配意图 | 降级 | 不中断主对话，提示可用意图 |

**错误原则**：安全优先、宁停勿错；任何不确定都「转本人确认」而非猜测；任何越界都「拒答并说明」而非妥协。错误不产生外发副作用，不留敏感痕迹。
