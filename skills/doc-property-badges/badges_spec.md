# 文档属性徽章体系 · 分级 / 分层 / 分方向

> 配套生成器：`gen_badges.py`（产出 `badges/*.svg` 与 `badges/gallery.html`）

## 一、分方向（属性类别，5 类）
每个方向用固定色相，便于一眼识别属性类型。

| 方向 code | 中文 | 主色 | 含义 |
|---|---|---|---|
| `copyright` | 著作权 | 蓝 `#2C6FD6` | 版权归属与许可范围 |
| `ai` | AI 属性 | 紫 `#7B5BE6` | 内容**是否由 AI 参与生成**（来源轴） |
| `ai_rights` | AI 权限 | 绿 `#27AE60` | 该文档**允许 AI 怎么用它**（授权轴 · AI 世界属性） |
| `payment` | 支付属性 | 金 `#E0A200` | 是否付费 / 商用授权 |
| `tracking` | 密文追踪 | 青 `#1FA8A0` | 是否嵌入不可见溯源密文 |
| `confidentiality` | 密级 | 红灰梯度 `#C0392B` | 文件保密等级 |
| `owner` | 归属 | 橙 `#E8743B` | 代表**单位 / 个人 / 委托方**的身份标识 |
| `validity` | 时效 | 紫 `#9B59B6` | 文件有效期（永久 / 限时 / 已过期） |
| `protect_edit` | 防编辑 | 红 `#E74C3C` | 内容是否禁止修改（可编辑 / 禁止编辑 / 只读锁定） |
| `protect_convert` | 防另存 | 玫红 `#D6336C` | 是否禁止另存为 / 转成其他格式 |

## 二、分级（每个方向内的严重程度 / 开放度）
颜色由浅→深表示「程度递增」，方向主色固定、明度随级别变化。

| 方向 | 级别（浅 → 深） |
|---|---|
| 著作权 | 开放许可 → 授权使用 → 全权保留 |
| AI 属性 | 人工撰写 → AI 辅助 → AI 生成 |
| AI 权限（AI 世界属性） | 禁止AI使用 → 允许AI学习 → 允许AI合作编辑 |
| 支付属性 | 免费 → 付费 → 授权付费 |
| 密文追踪 | 未嵌入 → 已嵌入 |
| 密级 | 公开 → 内部 → 受限 → 机密 |
| 归属 | 单位所有 → 个人所有 → 委托代管 |
| 时效 | 永久有效 → 限时有效 → 已过期 |
| 防编辑 | 可编辑 → 禁止编辑 → 只读锁定 |
| 防另存 | 允许转换 → 禁止另存 → 禁止格式转换 |

> **AI 属性 vs AI 权限（两个不同轴）**
> - `ai`（紫）= 这份文档**是谁生成的**（人工 / AI辅助 / AI生成），属来源披露。
> - `ai_rights`（绿）= 这份文档**允许 AI 怎么用**（禁止 / 可学习 / 可合作编辑），属对 AI 的授权。
>   例如：一份「AI生成」的临床指南，可同时标「允许AI学习 / 允许AI合作编辑」，开放给 AI 协作；而一份未脱敏病历则应标「禁止AI使用」。

## 三、分层（徽章在文档上的落点 / 可见度）
同一枚徽章可按需要落在不同层，对应不同防护目的：

| 层 code | 可见度 | 落点 | 用途 |
|---|---|---|---|
| `visible` | 完全可见 | 页脚 / 封面角标 | 明示属性，满足披露合规 |
| `watermark` | 半透明(~18%) | 页面背景斜铺 | 视觉震慑，防截图外传 |
| `invisible` | 不可见(密文) | 文本流 / 元数据 | 溯源取证，肉眼不可见 |

> 说明：三层的「属性信息」一致，区别只在呈现强度。建议组合使用——`visible` 明示 + `watermark` 震慑 + `invisible` 兜底溯源。

## 四、命名与文件
- SVG 文件：`badges/<方向>_<级别>.svg`
- 尺寸：高 30px 胶囊，自动按文字宽度，矢量无损缩放。
- 徽章结构（内部三层）：`[图标圆] + [方向·级别 文字]`，落在文档上即成为该文件的「属性角标」。

## 五、与产权声明能力的关系
- `doc-ip-declaration` 技能负责往 PDF 注入**声明页 + 不可见密文追踪**。
- 本徽章体系负责在文档**可见层**（页脚/角标）呈现**结构化属性标签**，两者互补：
  声明页写「为什么」，徽章标「是什么」。

## 六、「防编辑 / 防另存」的标注与落地
徽章只是**声明**。真正的防护在 `doc-property/apply_property.py` 中按格式落地：
- **PDF**：用 pypdf 加密权限落实——`防编辑` 清除「修改内容」权限，`防另存` 清除「复制/提取 + 文档重组」权限；仅设 owner 权限密码（用户可正常打开阅读，但无法改/拷/另存为）。权限密码写入 XMP sidecar（`ip:OwnerPassword`）以便日后解除。
- **Word**：`防编辑` 写入只读保护（`w:documentProtection`，软性提示只读）。「防另存为其他格式」Word 无原生锁，仅做声明标注。
- **图片 / MD / HTML**：无原生防护能力，仅做可见徽章 + 元数据声明（标注即告知）。
- 注意：格式防护属「提高门槛」，非绝对安全；配合不可见密文追踪（溯源）才是完整方案。
