# 医械注册全球通关枢纽 · 万有无界技能包

> 本包为 WorkBuddy 技能 `medical-device-reg-hub` 的万有无界（阿里云）就绪适配版，用于「发布新技能」上传 zip 后装配到自定义 Agent。

## 用途
医疗器械注册工程师的随身资料库与导航枢纽。覆盖中国 NMPA / 美国 FDA / 欧盟 MDR / 日本 PMDA 及东南亚·拉美全球注册路径与分类，UDI、STED、生物相容性(ISO 10993)、GMP、上市后监管、标签与 IFU、供应商合规等 20 个专题枢纽，按「全生命周期 7 阶段」（需求立项→分类路径→技术文件→质量体系→注册申报→审评获批→上市后）结构化编排，附官方直达链接。技能遇匹配场景（注册路径/分类/技术文件/合规咨询）自动加载。

## 运行环境
- **运行引擎**：Claude Code 或 OpenClaw（万有无界自定义 Agent 支持的运行引擎）。
- **模型**：任意支持中文的通用大模型；本技能为知识/导航型，无特殊模型能力要求。
- **平台**：万有无界（上传本 zip 即装配到 Agent）。

## 依赖项
- 无代码依赖、无第三方库、无外部 API Key。
- 仅引用在线公开官方资源（NMPA / FDA / EU MDR / PMDA 等官网链接），运行时需联网访问。
- 知识正文见 `references/` 目录（30+ 枢纽 markdown）；`assets/overview.svg` 为全生命周期 7 阶段全景图。

## 数据配置
- 本技能**不采集、不上传任何用户数据**，无密钥 / 令牌 / 个人敏感信息配置。
- 所有链接来自公开官方站点，已浏览器级核验可达（截至 2026-08-14 共 119 条）。
- 若用于企业内网隔离环境，可将 `references/` 本地化后挂载为项目知识库替代在线访问。

## 装配方式
1. 将本目录打包为 zip（必须含 `SKILL.md`，≤10MB）。
2. 在万有无界「技能市场 → 发布新技能」上传 zip。
3. 表单自动预填：标识取 `name`，显示名称取 `displayName`，描述取 `SKILL.md` 的 `description`（已精简至 ≤200 字）。
4. 提交后走安全 / 完整性 / 可执行性三项认证（满分 100，按总分给技能等级）。
