# 临床评价枢纽

临床评价（Clinical Evaluation）是医疗器械注册申报的**核心证据文件**——Ⅱ/Ⅲ类产品（中国）、510(k)/PMA（美国）、MDR Annex I/II（欧盟）都必须证明产品临床使用的安全有效性。本枢纽汇总中国同品种比对/免临床目录、欧盟 CER（MDCG 系列）、美国 510(k) 实质等同的官方路径与直达入口，全部链接经官方渠道核验。

> 制作日期：2026-08-18 ｜ 链接核验：复用枢纽系列已核验清单 + 本轮 WebSearch/WebFetch 补充核验（免临床目录 2025 年版、MDCG 指南库临床评价分类）

## 一、临床评价路径总览（三条路）

| 路径 | 适用情形 | 交付物 |
| --- | --- | --- |
| ① 免于临床评价 | 产品列入免临床目录，且能证明与目录描述一致 | 与目录的对比说明（不是什么都不交！） |
| ② 同品种 / 等同性比对 | 有已上市同品种产品，可论证基本等同 | 等同性论证 + 临床文献/临床数据评价报告 |
| ③ 临床试验 | 无合适同品种 / 差异影响安全有效 / 创新产品 | 临床试验报告（GCP 合规） |

> 三条路不是任选：先查目录，不在目录再评估能否走同品种，都不行才上临床试验。美国 510(k) 的"实质等同（SE）"、欧盟 MDR 的"等同性（Equivalence）"与中国的"同品种比对"是同一逻辑在不同市场的落地。

## 二、中国 NMPA 路径

| 项目 | 官方入口 | 说明 |
| --- | --- | --- |
| 免于进行临床评价医疗器械目录（2025 年版） | [NMPA 通告（2025 年第 19 号）](https://www.nmpa.gov.cn/xxgk/ggtg/ylqxggtg/ylqxqtggtg/20250513095643145.html) | 2025-05 发布，共 1047 项，取代 2023 年版（2023 年第 33 号） |
| 医疗器械临床评价技术指导原则 | [NMPA 2015 年发布页](https://www.nmpa.gov.cn/directory/web/nmpa/ylqx/ylqxjgdt/20150612121301706.html) | 2015 年首发，此后多次修订；现行版本以 [CMDE 官网](https://www.cmde.org.cn/)指导原则专栏为准 |
| 同品种比对 / 等同性论证 | [CMDE 官网 · 临床评价](https://www.cmde.org.cn/) | 临床评价系列指导原则（等同性论证、报告撰写、境外数据接受等）在 CMDE 集中发布 |
| 注册申报资料要求 | 见「技术文件 STED 撰写枢纽」 | 2021 年第 121/122 号公告，临床评价资料为申报必备模块 |

关键规则：
- **免临床目录内**：提交申报产品与目录描述的**对比说明**即可免临床试验，但须证明与目录中已上市产品基本等同；
- **同品种比对**：选择已在境内获准注册的同品种，证明"基本等同"——差异不得对安全有效性产生不利影响，且差异影响须用申报产品自身数据验证；
- **境外临床数据**：符合中国人种差异考量后可接受境外临床试验数据，减少重复试验。

## 三、欧盟 MDR 路径

MDR Art. 61 要求临床评价贯穿产品生命周期；公告机构审 CER 是 IIb/III 类拿证的关键环节。

| 文件 | 完整标题（官方 MDCG 指南库） | 用途 |
| --- | --- | --- |
| MDCG 2020-13 | Clinical evaluation assessment report template | **CER 报告模板**（公告机构审评用） |
| MDCG 2020-5 | Guidance on clinical evaluation – Equivalence | 等同性论证指南 |
| MDCG 2020-6 | Guidance on sufficient clinical evidence for legacy devices | legacy 器械（遗留产品）临床证据要求 |
| MDCG 2023-7 | Exemptions from the requirement to perform clinical investigations (Art. 61(4)-(6)) | 豁免临床试验情形 |
| MDCG 2019-9 rev.1 | Summary of safety and clinical performance (SSCP) | IIb/III 类公示摘要 |
| MDCG 2020-7 / 2020-8 | PMCF plan / evaluation report template | 上市后临床跟踪模板（呼应上市后枢纽） |

官方入口：[MDCG 指南库（Clinical investigation and evaluation 分类）](https://health.ec.europa.eu/medical-devices-sector/new-regulations/guidance-mdcg-endorsed-documents-and-other-guidance_en) · [EC Health · Medical Devices](https://health.ec.europa.eu/medical-devices-sector)

> 关键规则：等同性论证须满足三要素（技术特性、生物学特性、临床特性）并证明可获取充分的等同器械数据（access to data）；无法满足等同性 → 必须开展临床试验。

## 四、美国 FDA 路径

| 项目 | 官方入口 | 说明 |
| --- | --- | --- |
| 510(k) 实质等同（SE） | [FDA 510(k)](https://www.fda.gov/medical-devices/premarket-submissions/premarket-notification-510k) | 与 predicate（对比器械）证明实质等同：预期用途 + 技术特性 |
| 510(k) 数据库（查 predicate） | [FDA 510(k) Clearances](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpmn/pmn.cfm) | 查已清关产品与 predicate 的对应 |
| De Novo / PMA | [FDA Device Advice](https://www.fda.gov/medical-devices/device-advice-comprehensive-regulatory-assistance) | 新型低中风险走 De Novo；高风险走 PMA（需更充分临床证据） |
| FDA 指南库 | [Search FDA Guidance Documents](https://www.fda.gov/regulatory-information/search-fda-guidance-documents) | 510(k) Program / Substantial Equivalence 相关指南在此检索（FDA 改版频繁，勿存死链） |

> 关键规则：FDA 的 510(k) SE 论证核心是"预期用途相同 + 技术特性不引入新的安全有效性问题"；**无 predicate 或无法建立 SE → De Novo / PMA**。关节镜钳类多为 Class I 豁免 510(k)（见「骨科手术器械_全球注册路径汇编」）。

## 五、临床评价报告（CER）撰写要点

1. **文献检索方案与筛选**：数据库、检索式、纳入排除标准——先定方案再检索，报告要可追溯；
2. **等同性/同品种论证**：逐项对比（预期用途、技术/生物/临床特性），差异分析其对安全有效性的影响；
3. **数据来源三角**：临床文献 + 临床经验数据（上市后使用/不良事件）+ 临床试验（如需要）；
4. **与风险管理呼应**：临床评价结论须支持获益-风险判定（呼应「风险管理枢纽」）；
5. **欧盟 CER 特别要求**：按 MDCG 2020-13 模板结构组织，公告机构逐章审。

## 六、常见误区

- ❌ 以为"列入免临床目录 = 什么都不用交" → 必须提交**与目录的对比说明**
- ❌ 同品种比对随便选个产品 → 必须选**境内已获准注册**的同品种，且差异须论证不影响安全有效
- ❌ 欧盟 legacy 器械以为可免临床 → MDCG 2020-6 明确要求充分的临床证据
- ❌ 境外临床数据直接照搬 → 中国须考虑**人种差异**，按《接受境外临床数据指导原则》论证
- ❌ CER 写成产品描述汇编 → 审评看的是**证据链 + 论证逻辑**，不是产品说明书
