## 使用说明

1. 技能触发后，按 SKILL.md 的「references/ 文件导航」表加载最相关的 1–2 个文件。
2. 引用结论时尽量附文件中的官方直达链接，便于核验。
3. 法规/标准会更新，关键数据提示以官方最新发布为准；标注 ⚠️ 待核验的条目（如日本 JMDN 具体编码）须用户自行在 PMDA 查实。
4. 生成交付物（HTML/Markdown 资料页）时，沿用清晰的官方链接排版，确保链接经浏览器级核验可达。
5. **关于官方法规深读（EUDAMED / FDA UDI / MDR PMS / 中国 MAH）**：四篇均基于 OJEU / FDA / NMPA 等官方法规原文原创整理（非第三方培训再创作），可纳入发布版；强制日期与文号以各官方最新原文为准。第三方培训类深读资料（五主题 + 580 附件索引）因版权考量不纳入发布版。
