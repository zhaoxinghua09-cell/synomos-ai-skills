# GMP / 质量体系与验证枢纽

无菌 / 植入 / 复用器械的注册绕不开质量体系与过程验证。本枢纽汇总中国 GMP 附录、ISO 13485 / 14971、FDA 过程验证、PIC/S、洁净室 ISO 14644、清洁与再处理验证的官方入口，全部可点击直达。适用于质量、注册、验证岗位。


## 质量体系（QMS）总览对照

同一套质量体系，全球四套法规框架并行。核心差别在适用范围、强制力与审核主体。

| 维度 | 中国 | 美国 | 欧盟 | 国际通用 |
| --- | --- | --- | --- | --- |
| 核心法规/标准 | 《医疗器械生产质量管理规范》+ 附录（无菌/植入/体外诊断） | 21 CFR 820（QSR） | MDR 2017/745 Annex IX / ISO 13485 作为符合性基础 | ISO 13485:2016 |
| 风险管理 | GB/T 42062（等同 ISO 14971） | ISO 14971（FDA 认可） | ISO 14971 + MDCG 2021-9 | ISO 14971:2019 |
| 审核主体 | 省/国家药监局 GMP 飞检 | FDA 现场核查（QSR 820） | 公告机构（Notified Body） | 第三方认证机构 |
| 过程验证要求 | GMP 附录 + 验证确认管理 | FDA《Process Validation》2011 | MDR + ISO 13485（V&V 条款） | ISO 13485:2016 条款 7.5.6 |

> 关键提示：无菌医疗器械（如关节镜钳）必须同时满足「质量管理规范」与「无菌医疗器械附录」；过程确认（IQ/OQ/PQ）是注册技术文件和体系核查的必查项。

## 质量管理体系核心标准

ISO 13485 是医疗器械 QMS 的通用语言，ISO 14971 是风险管理的通用框架。

| 项目 | 说明 / 入口 |
| --- | --- |
| ISO 13485:2016（医疗器械 QMS） | [iso.org/standard/59752.html](https://www.iso.org/standard/59752.html) — 现行版本，全球通用 QMS 标准 |
| ISO 14971:2019（医疗器械风险管理） | [iso.org/standard/72704.html](https://www.iso.org/standard/72704.html/) — 风险分析、评价与控制通用标准 |
| 中国转化：GB/T 42062-2022 | 等同采用 ISO 14971:2019，NMPA 发布实施 |
| ISO 13485 与中国 GMP 关系 | ISO 13485 为体系基础；中国 GMP 为强制规范，两者结合构成注册体系核查依据 |

I 类II 类III 类 质量体系要求对所有类别适用；III 类（植入/无菌）监管最严，核查最频。

## 过程确认 / 验证（Process Validation）

对不能靠终检验证的生产过程（灭菌、清洗、焊接、成型），须做前瞻性确认（IQ/OQ/PQ）。

| 项目 | 说明 / 入口 |
| --- | --- |
| FDA《Process Validation: General Principles and Practices》(2011) | [fda.gov Process Validation 2011 PDF (UCM070336)](https://www.fda.gov/downloads/Drugs/GuidanceComplianceRegulatoryInformation/Guidances/UCM070336.pdf) — 三阶段（工艺设计/确认/持续核实）权威指南，常被医疗器械复用 |
| ISO 13485:2016 条款 7.5.6（验证确认） | [iso.org/standard/59752.html](https://www.iso.org/standard/59752.html) — 过程确认要求条款 |
| 过程确认通用要求 | IQ（安装确认）/ OQ（运行确认）/ PQ（性能确认）+ 再确认计划 + 变更控制 |

> 提示：关节镜钳等复用外科器械的清洗、灭菌、包装过程均属须确认过程；验证报告是技术文件与体系核查核心证据。

## 清洁 / 再处理验证（含复用器械）

可重复使用器械的清洁与再处理验证，是欧盟 MDR 与美国 FDA 的重点审查项。

| 项目 | 说明 / 入口 |
| --- | --- |
| AAMI ST98:2022（清洁验证，FDA 认可标准） | [accessdata.fda.gov ST98 标准条目](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfStandards/detail.cfm?standard__identification_no=43767) — 医疗器械清洁确认标准（FDA 认可共识标准 No.43767） |
| ASTM F3127-16（清洁度评估） | 同见 FDA 认可标准库（上条链接可查标准号明细） |
| FDA 再处理质量影响因素 | [fda.gov Factors Affecting Quality of Reprocessing](https://www.fda.gov/MedicalDevices/ProductsandMedicalProcedures/ReprocessingofReusableMedicalDevices/ucm454622.htm) — 复用器械再处理质量影响因素指南 |
| 清洁验证关键参数 | 残留限度（蛋白/内毒素/颗粒物）、清洗工艺窗口、最坏情况（worst-case）选择 |

复用器械重点 欧盟 MDR 对 reusable surgical instruments 要求提供再处理确认（含清洗、消毒、灭菌、包装），须在 IFU 写明经确认的再处理程序。

## 洁净室与环境污染控制（ISO 14644）

无菌生产环境分级与监测依据 ISO 14644 系列（由 ISO/TC 209 维护）。

| 项目 | 说明 / 入口 |
| --- | --- |
| ISO/TC 209（洁净室技术委员会） | [iso.org/committee/54874.html](https://www.iso.org/committee/54874.html) — ISO 14644 系列归口技术委员会，可查全部分标准 |
| ISO 14644-1（分级） | 空气洁净度等级（Class 5/7/8 等）定义，无菌车间核心依据 |
| ISO 14644-2（监测） | 洁净室持续监测规范 |
| 中国对应标准 | GB 50073《洁净厂房设计规范》+ YY 0033《无菌医疗器具生产管理规范》 |

## 中国 GMP 附录 · 无菌医疗器械

国家药监局发布的《医疗器械生产质量管理规范》无菌医疗器械附录（2015 年第 101 号公告）。

| 项目 | 说明 / 入口 |
| --- | --- |
| 附录全文（CMDE 发布页） | [cmde.org.cn 无菌医疗器械附录](https://www.cmde.org.cn/flfg/fgwj/ggtg/20220110131758771.html) — 2015 年第 101 号公告，2015-10-01 施行 |
| 适用范围 | 无菌提供、直接接触无菌组织的医疗器械（含无菌关节镜钳） |
| 关键要求 | 生产环境洁净级别、人员、设备、文件、灭菌过程确认、无菌检验 |
| 配套附录 | 植入性医疗器械附录、体外诊断试剂附录（同一规范体系下） |

> 注册提示：无菌产品注册体系核查以《规范》+ 本附录为基准；现场核查（飞检）常围绕洁净生产、过程确认、追溯展开。
