# 技术文件 / STED 撰写枢纽

  不同市场要求的技术文档结构差异巨大。本枢纽梳理 FDA 510(k) Summary、欧盟 MDR 技术文档、中国注册申报资料、日本技术资料 的结构模板与官方指南，并附 IMDRF STED 国际协调格式，方便对照撰写。

## 文档类型对照

    同一款器械，监管提交物名称不同，但核心证据链（描述→风险→验证→临床→标签）高度一致。

    
| 框架 | 正式名称 | 法规依据 | 适用 |
| --- | --- | --- | --- |
| 欧盟 MDR | Technical Documentation（技术文档） | MDR 2017/745 Annex II & III | 全部器械，IIa 以上由 NB 审评 |
| 美国 FDA | DHF + DMR；510(k) Summary | 21 CFR 820.30 / 820.181；807.92 | II/III 类设计控制；510(k) 需 Summary |
| ISO 13485 | Medical Device File（医疗设备档案） | ISO 13485:2016 条款 4.2.3 | QMS 范围内所有器械 |
| IMDRF | STED（技术文档摘要） | IMDRF/GHTF SG1 N011 | 国际协调格式，多国接受 |
| 中国 NMPA | 注册申报资料（综述/研究/临床等） | 2021年第121号（境内）/122号（进口） | II/III 类注册 |

  

  
    ## IMDRF STED（国际协调格式）

    由 GHTF 创立、IMDRF 维护的 harmonized 技术文档摘要格式，被美/欧/日/加/澳等多国认可，是撰写底座。

    
| 资源 | 入口 |
| --- | --- |
| IMDRF 官网（STED 文档库） | [imdrf.org](https://www.imdrf.org/) |
| STED 章节结构 | 1 器械描述与规格 / 2 基本信息（标签） / 3 设计与制造 / 4 通用安全性能原则(EP) / 5 风险分析 / 6 验证与确认 |

    建议：以 STED 六章为骨架撰写，再按各市场 Annex/章节映射裁剪，可最大化复用、减少重复工作。

  

  
    ## 美国 510(k) Summary

    510(k) 须提交 Summary（21 CFR 807.92）或 Statement；实质等同(SE) 论证是核心。

    
| 项目 | 说明 / 入口 |
| --- | --- |
| 510(k) 项目总览 | [fda.gov/medical-devices/.../premarket-notification-510k](https://www.fda.gov/medical-devices/premarket-submissions/premarket-notification-510k) |
| 法规（Summary 格式） | [21 CFR 807 Subpart E（§807.92 内容格式）](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-807/subpart-E) |
| eSTAR 电子模板 | [fda.gov ... electronic-submission-template-estar](https://www.fda.gov/medical-devices/interactive-review-and-electronic-submission-template-estar) — 自 2023 起 510(k) 强制电子提交 |
| Summary 必备内容 | 器械名称/分类/预期用途、predicate 对比、技术特征、性能数据摘要、标准符合性、标签要点 |

    II 类III 类(部分) 注：基础手动复用器械（如部分外科钳）属 I 类豁免 510(k)，无需 Summary。

  

  
    ## 欧盟 MDR 技术文档

    Annex II（技术文档）+ Annex III（PMS 计划）为法定结构；IIa 以上由 NB 审评。

    
| 项目 | 说明 / 入口 |
| --- | --- |
| MDR 法规全文（Annex II/III） | [eur-lex.europa.eu/eli/reg/2017/745/oj](https://eur-lex.europa.eu/eli/reg/2017/745/oj) |
| MDCG 指南库 | [health.ec.europa.eu ... MDCG endorsed documents](https://health.ec.europa.eu/medical-devices/new-mdr-and-ivdr-guidance/guidance-mdcg-endorsed-documents_en) |
| Annex II 六章 | 1 器械描述与规格 / 2 标签与IFU / 3 设计与制造 / 4 GSPR符合性 / 5 获益-风险与风险管理 / 6 验证与确认 |
| 关键支撑 | 临床评价报告(CER)、PMS 计划、SSCP（IIb/III 公示摘要） |

    MDR 下即使 I 类（非无菌/非测量/非复用手术器械）也须备齐完整技术文档并持续维护，仅审评方式不同（自我声明 vs NB）。

  

  
    ## 中国注册申报资料

    依据《医疗器械注册申报资料要求及说明》（2021年第121号 境内 / 第122号 进口），通过 eRPS 提交。

    
| 项目 | 说明 / 入口 |
| --- | --- |
| 法规公告 | 国家药监局 2021年第121号（境内）/ 第122号（进口）公告 |
| 审评中心 CMDE | [cmde.org.cn](https://www.cmde.org.cn/)（申报资料要求、指导原则） |
| eRPS 电子提交 | [erps.cmde.org.cn](https://erps.cmde.org.cn/)（电子申报系统） |
| 资料模块 | 1 监管信息 / 2 综述资料 / 3 非临床资料（研究/验证/灭菌/包装）/ 4 临床评价 / 5 产品说明书标签 / 6 质量管理体系 |

    II 类III 类 II 类由省级药监局审评，III 类由国家局审评；临床评价可用同品种比对路径。

  

  
    ## 日本技术资料

    日本以“承認基準（审查基准）”为核心，境外厂经 MAH/DMAH 提交；技术资料结构接近 STED。

    
| 项目 | 说明 / 入口 |
| --- | --- |
| PMDA 官网 | [pmda.go.jp/english](https://www.pmda.go.jp/english/) |
| 审查基准（承認基準） | 按 JMDN 类别对应审查基准；满足者走第三方认证(RCB)或承认 |
| 技术资料结构 | 器械概述 / 原理 / 规格 / 制造 / 生物学/性能评价 / 临床评价 / 标签 |
| 外国制造业者认定 | 境外厂须完成“外国製造業者認定”(FGMP) 方可出口日本 |

  

  
    ## 结构差异对照表

    
| 章节 | 美国 510(k) | 欧盟 MDR | 中国注册 |
| --- | --- | --- | --- |
| 器械描述 | Summary 第1部分 | Annex II Ch.1 | 综述资料 |
| 标签/IFU | 标签要点 | Annex II Ch.2 | 说明书标签模块 |
| 设计制造 | DHF（设计历史） | Annex II Ch.3 | 非临床资料 |
| 风险/原则 | 风险管理文件 | Annex II Ch.4 GSPR | 研究资料+风险管理 |
| 验证确认 | 性能数据摘要 | Annex II Ch.6 | 非临床研究 |
| 临床 | SE 对比/临床 | CER（临床评价报告） | 临床评价/临床试验 |

    通用秘诀：以 IMDRF STED 六章为中轴撰写一次，再映射到各国章节编号。生物相容性(ISO 10993)、灭菌(ISO 11135/11137)、 packaging(ISO 11607)、软件(IEC 62304) 等支撑证据全球通用。
