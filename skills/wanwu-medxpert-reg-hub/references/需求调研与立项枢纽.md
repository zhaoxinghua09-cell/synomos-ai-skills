# 需求调研与立项枢纽

做对产品，比做快产品更重要。本枢纽覆盖医械立项前端：市场需求与临床需求挖掘、竞品分析（用官方数据库）、PRD/设计输入（法规接口）、立项评审（商业+法规双轨）。方法论部分为行业通行做法（非官方强制要求），法规接口均附已核验官方入口。

> 制作日期：2026-08-18 ｜ 链接核验：全部复用枢纽系列已核验清单（510(k)/De Novo/UDI 数据库、ISO 13485、eCFR 820），零新增核验

---

## 一、立项总览（需求 → 立项 → 设计输入）

```
市场需求/临床需求 → 产品概念 → 竞品与可行性分析 → 立项评审
    → PRD（产品需求文档）→ 设计输入（Design Input）→ 设计开发
```

> 法规接口：设计输入是 **ISO 13485 7.3.3 / FDA 21 CFR 820.30(c)** 的强制起点——需求必须被记录、评审并转化为可验证的设计输入，这是后续设计验证/确认（呼应「设计开发控制枢纽」「风险管理枢纽」）的依据。

---

## 二、市场调研与临床需求挖掘

| 方法 | 要点 |
| --- | --- |
| KOL / 临床专家访谈 | 医生、护士、手术室一线——问"痛点/未满足需求"，而非"想要什么" |
| 手术量与流行病学数据 | 判断细分市场容量（如关节镜手术量、骨科疾病谱） |
| 文献与专利调研 | PubMed/临床文献 + 专利检索（FTO 自由实施分析） |
| 问卷与使用观察 | 结构问卷 + 手术跟台观察真实使用流程 |
| 竞品临床反馈 | 已上市产品的临床文献、不良事件公开数据（呼应「上市后监管枢纽」） |

> 关键提示：医械需求调研的黄金问题——**"现有方案哪里不够好？"**（器械操作性、手术时间、并发症率、成本），答案直接决定产品差异化定位。

## 三、竞品分析（官方数据库可查）

| 数据库 | 用途 | 官方入口 |
| --- | --- | --- |
| FDA 510(k) 数据库 | 查已清关竞品与 predicate（实质等同对比对象） | [FDA 510(k) Clearances](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpmn/pmn.cfm) |
| FDA De Novo | 查新型低中风险产品获批情况 | [FDA De Novo](https://www.fda.gov/medical-devices/premarket-submissions/denovo-classification-request) |
| FDA PMA 数据库 | 查高风险竞品（PMA 批准） | [PMA Approvals](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpma/) |
| 美国 GUDID / 各国 UDI 库 | 查已上市产品型号与规格（UDI 数据） | 见「UDI 全球标识枢纽」 |
| 中国 NMPA 数据查询 | 查国内已注册竞品 | NMPA 官网→医疗器械→数据查询（通用入口） |
| 13 市场注册实证 | 关节镜钳等产品的全球竞品分布 | 「篮钳剪线钳过线钳_全球注册路径汇编」 |

> 关键提示：竞品分析直接产出两条线——① 产品定位（差异化卖点）；② **注册路径预判**（选哪个 predicate、走什么分类），与「主索引」分类与路径章节联动。

## 四、PRD 与设计输入（法规接口）

### PRD（产品需求文档）核心章节

| 章节 | 内容 |
| --- | --- |
| 预期用途与适应症 | 一句话预期用途 + 适用人群/科室/场景 |
| 用户需求 | 临床需求 → 功能/性能需求（可测量指标） |
| 关键性能指标 | 力学/尺寸/材料/灭菌/有效期等（对应产品技术要求雏形） |
| 法规与标准要求 | 适用标准清单（ISO/YY/GB）——立项即定，避免后期返工 |
| 风险与可用性考量 | 初步风险分析、使用场景（呼应「风险管理枢纽」「软件人因枢纽」） |
| 上市与渠道计划 | 目标市场、注册路径、定价（呼应「市场准入与销售枢纽」） |

### 设计输入（Design Input）要点

- **输入必须可验证**：每条输入对应一种验证方法（测试/分析/检查）；
- 输入来源：用户需求 + **适用法规标准** + **风险分析输出** + 可用性/灭菌/包装要求；
- 输入评审：立项评审通过后锁定为设计输入基线（变更走变更控制，呼应「变更延续管理枢纽」）。

## 五、立项评审要素（商业 + 法规双轨）

| 维度 | 评审要点 |
| --- | --- |
| 市场 | 市场规模、增长率、竞争格局、定价空间 |
| 法规 | 分类与注册路径、周期/费用/有效期（见「注册周期费用有效期对比枢纽」）、临床评价难度（见「临床评价枢纽」） |
| 技术 | 设计可行性、材料与工艺成熟度、专利/FTO |
| 商业 | 成本结构、毛利、渠道与集采影响（见「市场准入与销售枢纽」） |
| 退出条件 | 明确"什么情况下不做"（里程碑评审 KILL 标准） |

> 提示：立项评审建议用**评分矩阵**（市场/法规/技术/商业各维度打分），避免拍脑袋；法规维度建议注册工程师（RA）早期介入——**分类界定、免临床目录、标准清单在立项期确定，能省一年弯路**。

## 七、常见误区

- ❌ 需求调研只问"你想要什么" → 要挖**未满足需求与痛点**，用户说出来的常常不是真需求
- ❌ 立项不做 FTO 专利分析 → 产品做出来才发现侵权，损失最大
- ❌ 跳过竞品注册路径分析 → 同品对手的分类/注册路径是**最便宜的调研报告**
- ❌ 设计输入写"要好的、要快的" → 不可验证的输入导致验证/确认无法闭环
- ❌ 立项期不考虑集采/医保 → 定价空间决定产品规格设计（呼应「市场准入与销售枢纽」）
