# 枢纽总览 · 以全生命周期 7 阶段为纲领

> 纲领来源：**注册工程师资料枢纽 · 阶段地图**（注册工程师工作流 7 阶段）
> 覆盖范围：20 个专题枢纽 + 1 份产品实证 + 5 篇市场实务 + 2 份索引 = **28 份资料**
> 结构：第一级 = 生命周期 7 阶段；第二级 = 每阶段要点 × 关联枢纽 × 枢纽内核心模块
> 更新：2026-08-19

---

## 纲领 · 全生命周期 7 阶段

> ① **立项与可行性** → ② **分类与路径** → ③ **技术文件** → ④ **质量体系** → ⑤ **注册申报** → ⑥ **审评与获批** → ⑦ **上市后**
> 从需求定义开始，到上市后监管结束——每个阶段都有一组枢纽支撑。

---

## 阶段一 · 立项与可行性
> 要解决：这个产品值不值得做、走什么策略、要花多少钱多久。

| 二级要点 | 关联枢纽 | 枢纽内核心模块 |
|---|---|---|
| 立项主线 | **需求调研与立项枢纽** | 需求挖掘→竞品分析（官方库）→PRD/设计输入→立项评审（商业+法规双轨） |
| 风险与可行性预判 | **风险管理枢纽** | 全球标准与法规对照｜ISO 14971 六步流程（风险分析→评价→控制→残余风险→综合→评审）｜风险文件在各国案卷中的位置 |
| 市场法规概览 / 分类数据库 | **注册工程师资料枢纽** | 四市场（NMPA/FDA/MDR/PMDA）立项与可行性：法规概览、产品分类库、审查费（MDUFA） |
| 预算与排期 | **注册周期费用有效期对比枢纽** | 六市场横向对比：注册周期 / 费用 / 证书有效期（典型区间） |
| 供应链可行性（物料取证） | **原材料供应商合规枢纽** | 物料取证清单（按采购类型） |
| 竞品/渠道预判 | **市场准入与销售枢纽** | 渠道与招投标（五/六） |

## 阶段二 · 分类与路径
> 要解决：产品在目标市场算什么类别、走哪条注册路径。

| 二级要点 | 关联枢纽 | 枢纽内核心模块 |
|---|---|---|
| 四市场分类与上市路径 | **注册工程师资料枢纽** | 分类与上市路径：中国Ⅰ/Ⅱ/Ⅲ、FDA 510(k)/PMA/De Novo、EU 分类规则、日本一般/管理/高度管理 |
| 产品级路径实证 | **篮钳剪线钳过线钳·全球注册路径汇编** | 13 市场 × 三类关节镜器械：注册总览表、各市场详情（NMPA/FDA/MDR/PMDA/巴西/墨西哥/阿根廷/东盟）、技术标准汇总、代理推荐 |
| 临床路径前置判断 | **临床评价枢纽** | 临床评价路径总览（三条路）、免临床目录 |

## 阶段三 · 技术文件
> 要解决：把产品做成符合各市场要求的技术卷宗。

| 二级要点 | 关联枢纽 | 枢纽内核心模块 |
|---|---|---|
| 设计控制主线 | **设计开发控制枢纽** | ISO 13485 7.3 / 21 CFR 820.30 九步流程（输入/输出/评审/V&V/转移/变更） |
| 软件与人因 | **软件人因枢纽** | IEC 62304 软件生命周期｜IEC 62366-1 可用性｜FDA 三级关注｜IMDRF SaMD｜网络安全(MDCG 2019-16) |
| 灭菌与包装 | **灭菌包装验证枢纽** | 灭菌方法选型｜过程确认 IQ/OQ/PQ｜无菌屏障包装 ISO 11607 |
| 技术卷宗结构 | **技术文件 STED 撰写枢纽** | IMDRF STED 结构｜文档类型对照（STED/510k Summary/MDR 技术文档/注册资料） |
| 生物学评价 | **生物相容性测试规划枢纽** | 生物学评价框架总览｜ISO 10993-1:2025（第 6 版）｜GB/T 16886.1-2022｜FDA 10993-1 指南｜**终点选择矩阵**｜ISO/TC 194 |
| 风险管理入卷 | **风险管理枢纽** | 风险管理文件在各国案卷中的位置（三/四） |
| 说明书/标签/IFU | **标签与 IFU 枢纽** | 中国局令 6 号｜欧盟 MDCG 2019-15 rev.1｜ISO 15223-1:2021 符号｜ISO 20417（IFU 内容） |
| 检验与验证前置 | **GMP 质量体系与验证枢纽** | 过程确认/验证｜清洁/再处理验证（含复用器械） |

## 阶段四 · 质量体系
> 要解决：工厂/体系达到目标市场的质量体系要求。

| 二级要点 | 关联枢纽 | 枢纽内核心模块 |
|---|---|---|
| 体系标准总览 | **GMP 质量体系与验证枢纽** | QMS 总览对照｜ISO 13485｜QSR 21 CFR 820/QMSR｜PIC/S GMP PE 009-14｜中国 GMP 附录·无菌 |
| 洁净室与环境 | **GMP 质量体系与验证枢纽** | 洁净室与环境污染控制（ISO 14644） |
| 供应商管理 | **原材料供应商合规枢纽** | 物料取证清单（按采购类型）＋供应商审计 |
| 委托生产 | **CN 委托生产 MAH 实务** | 制度依据｜禁止委托目录（2022 第 17 号）｜质量协议（2022 第 20 号）｜跨区域协同监管｜责任划分与放行分工 |
| 供应链穿透应对 | **FDA 创伤敷料供应链穿透检查枢纽** | 检查逻辑变化｜重点品类｜企业应对能力 |

## 阶段五 · 注册申报
> 要解决：资料递上去、数据库注册好、审评沟通顺畅。

| 二级要点 | 关联枢纽 | 枢纽内核心模块 |
|---|---|---|
| 申报流程主线 | **注册检验与申报实操枢纽** | 四市场递交对照（含日本）｜注册检验（委托/自检126号）｜eRPS/eSTAR 7.0/EUDAMED/PMDA｜创新通道·Pre-Sub·MDUFA｜审评沟通机制｜常见误区 |
| 四市场申报与获批 | **注册工程师资料枢纽** | 注册申报与获批：申报系统、递交清单、审评沟通 |
| 临床评价报告随申报 | **临床评价枢纽** | NMPA 路径｜EU MDR 路径｜FDA 路径｜**CER 撰写要点**｜常见误区 |
| 欧盟数据库义务 | **EU EUDAMED 数据库实务** | 六个模块（渐进式上线）｜强制启用时间线｜SRN｜注册义务｜数据提交方式 |
| 美国 UDI 申报 | **FDA UDI 实施实务** | 发码机构｜GUDID｜合规日期（按类别）｜编码与条码 |

## 用法建议

1. **按项目走**：接到产品 → 从 ① 立项往下逐阶段用对应枢纽，形成完整注册路线图。
2. **按市场走**：总枢纽 + 各市场实务（EUDAMED/UDI/PMS）组合成单市场全流程。
3. **查缺补漏**：对照 7 阶段查哪个环节资料还薄（当前薄弱：⑤申报模板类、⑥获证后合规）。
