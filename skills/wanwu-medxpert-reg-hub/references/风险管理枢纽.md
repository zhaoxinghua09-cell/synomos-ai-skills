# 风险管理枢纽（ISO 14971）

风险管理文件（Risk Management File）是**每份医疗器械注册案卷的必备文件**——无论走中国 NMPA、美国 510(k)/PMA、欧盟 MDR 还是日本 PMDA，审评首先看的都是"风险是否被识别、评价与控制"。本枢纽汇总 ISO 14971 全球落地标准、官方入口、六步流程与案卷位置，全部链接经官方渠道核验。适用于注册、研发、质量岗位。

> 制作日期：2026-08-18 ｜ 链接核验：复用枢纽系列已核验清单 + 本次补充核验（MDCG 指南库无风险管理专项指南；FDA Design Control 指南 slug 随改版变动，用指南库搜索入口）

## 一、全球标准与法规对照

同一套风险管理，全球落地载体不同，但都指向 ISO 14971 的方法论。

| 市场 | 标准 / 法规 | 说明 |
| --- | --- | --- |
| 国际 | ISO 14971:2019 | 风险管理通用框架（风险分析→评价→控制→评审） |
| 中国 | **GB/T 42062-2022**（等同采用 ISO 14971:2019） | 现行国标；旧版 YY/T 0316（等同 ISO 14971:2007）已被替代 |
| 美国 | ISO 14971（FDA 认可共识标准）+ 21 CFR 820.30 设计控制 | FDA 将 ISO 14971 作为设计控制中风险分析的认可标准 |
| 欧盟 | MDR Annex I GSPR（第 3-9 条风险要求）+ **EN ISO 14971**（协调标准） | 协调标准提供"符合性推定"，公告机构按此审风险文件 |
| 日本 | JIS T 0304（等同 ISO 14971） | 日本 PMDA 认可的风险管理标准 |

> 关键提示：中国《医疗器械注册申报资料要求及说明》（2021 年第 121/122 号公告）在**非临床资料**中明确要求提交风险管理资料；欧盟 MDR Annex II 技术文档第 5 章要求"获益-风险分析与风险管理"。风险管理不是质量体系文件的附属，是独立技术文件。

## 三、风险管理六步流程（ISO 14971:2019）

写风险管理报告时按此顺序组织证据链：

1. **风险分析**
   - 确定预期用途与**可合理预见的误用**（misuse）
   - 识别与器械有关的**危险**（能量危害/生物学危害/化学危害/操作危害/信息危害）
   - 对每个危险情况**估计风险**（严重度 × 发生概率）
2. **风险评价**：将估计风险与**可接受准则**比较，判定是否需要风险控制
3. **风险控制**：按优先级——① 本质安全设计（消除/降低）→ ② 防护措施 → ③ 安全信息（警告/说明书）；验证控制有效性；评估每个剩余风险是否可接受
4. **综合剩余风险评价**：所有风险控制后，整体剩余风险是否可接受（结合获益-风险判断）
5. **风险管理报告（评审）**：汇总输出风险管理报告，作为注册资料提交
6. **生产与生产后活动**：收集上市后数据（PMS/不良事件/召回），反馈更新风险分析——与「上市后监管枢纽」形成闭环

> 提示：关节镜钳等复用外科器械的风险分析重点——锐利件断裂、重复灭菌老化（NiTi 等材料湿热灭菌性能衰减）、清洁不彻底导致感染、再处理程序不当等，须在 IFU 写清经确认的再处理程序。

## 四、风险管理文件在各国案卷中的位置

| 市场 | 案卷位置 | 要点 |
| --- | --- | --- |
| 中国 | 注册申报资料·**非临床资料**（风险管理研究/报告） | 依据 121/122 号公告；与技术要求、检验报告呼应 |
| 美国 | 510(k)/PMA 提交材料中的**风险分析部分** | 与实质等同（SE）对比、性能测试结合呈现 |
| 欧盟 | Annex II 技术文档**第 5 章获益-风险** + Annex I GSPR 符合性 | 公告机构重点审；III 类还须 SSCP 公开摘要体现风险-获益 |
| 国际 | IMDRF STED 技术文档**风险模块** | 按 STED 六章撰写一次，映射各国章节（见「技术文件 STED 撰写枢纽」） |

## 五、常见误区

- ❌ 把风险管理写成质量体系文件的一部分 → 它是**独立技术文件**，须单独成册
- ❌ 直接套模板不按产品实际分析 → 审评一眼识破，重点看危害识别的"产品相关性"
- ❌ 风险管理做完就归档 → 变更（材质/工艺/灭菌/软件）触发**风险再评估**，与「变更管理」呼应
- ❌ 忽略生产后数据 → ISO 14971 明确要求 PMS 数据反馈闭环，与「上市后监管」呼应
