# 上市后监管枢纽

拿证只是开始。不良事件监测、召回、FSCA、PSUR、PMCF 是产品在各国持续合规的核心。本枢纽汇总 FDA MDR、欧盟 MDR 警戒与 MDCG 2022-21(PSUR)、中国 2018 令第 1 号与监测系统、PMDA 不具合报告的官方入口，全部可点击直达。


## 上市后监管（PMS）框架总览

各国均要求制造商建立上市后监督体系，核心动作是「监测—报告—纠正（FSCA/召回）」闭环。

| 维度 | 美国 | 欧盟 | 中国 | 日本 |
| --- | --- | --- | --- | --- |
| 核心法规 | FD&C Act + 21 CFR 803（MDR） | MDR 2017/745 第 2 章 + 第 87-92 条 | 2018 年第 1 号令 + 监测办法 | 药机法 + PMDA 報告制度 |
| 定期报告 | — | PSUR（MDCG 2022-21 指南） | 定期风险评价（依风险） | 定期安全更新报告 |
| 警戒系统 | MAUDE 数据库 | EUDAMED 警戒模块 | 国家不良事件监测信息系统 | PMDA 不具合等報告 |
| 纠正措施 | Recall（FDA 主导分级） | FSCA（现场安全纠正） | 召回（NMPA 分级） | 自主回収 / 改善措置 |

> 关键提示：FSCA（Field Safety Corrective Action）是欧盟 MDR 警戒体系的核心概念，依据 MDR 第 87–89 条与 MDCG 2022-21（PSUR 指南）执行，切勿与临床研究的「实质性修改」指南混淆。

## 美国 FDA 不良事件报告（MDR）

制造商、进口商、用户机构对致死/严重伤害事件须按 21 CFR 803 报告。

| 项目 | 说明 / 入口 |
| --- | --- |
| FDA MDR 强制报告要求总览 | [fda.gov Medical Device Reporting (MDR)](https://www.fda.gov/medical-device-reporting-mdr) — 制造商/进口商/用户机构义务总览 |
| eCFR 21 CFR 803 全文 | [ecfr.gov title-21 part-803](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-803) — Medical Device Reporting 法规原文 |
| 报告时限 | 致死 30 日历日；严重伤害/故障 90 日历日（依 803.50/803.52） |
| 数据库 | MAUDE（公开不良事件数据库） |

I 类II 类III 类 全部适用 MDR 报告义务。

## 欧盟 MDR 警戒 + PSUR（MDCG 2022-21）

MDR 第 87–92 条建立警戒体系；MDCG 2022-21 给出 PSUR 的编写与提交指南。

| 项目 | 说明 / 入口 |
| --- | --- |
| MDCG 2022-21（PSUR 指南 PDF） | [health.ec.europa.eu MDCG 2022-21 PSUR](https://health.ec.europa.eu/document/download/a7df24c3-d4a3-4218-a8e0-726febfa01c2_en?filename=mdcg_2022-21_en.pdf) — 定期安全更新报告编写指南 |
| MDR 警戒条款 | Article 87（严重事件/Field Safety Corrective Action 报告义务）、88（趋势报告）、89（分析评估）、92（EUDAMED 警戒） |
| 核心文件 | PMS Plan、PMS Report（IIa 以下）、PSUR（IIb/III 及部分植入） |
| FSCA 定义 | Field Safety Corrective Action：为消除/降低风险，在现场对器械/IFU/流程采取的纠正措施 |

> 纠正对照：美国称 Recall、欧盟称 FSCA、中国称 召回。三者在报告触发、分级、时限上不同，跨国产品需分别建流程。

## 欧盟 PMCF 模板（MDCG 2020-7 / 2020-8）

上市后临床跟踪（PMCF）是 PMS 的组成部分，MDCG 提供 Plan 与 Report 模板。

| 项目 | 说明 / 入口 |
| --- | --- |
| MDCG 指南总入口 | [health.ec.europa.eu MDCG endorsed documents](https://health.ec.europa.eu/medical-devices-sector/new-regulations/guidance-mdcg-endorsed-documents-and-other-guidance_en) — 含 MDCG 2020-7（PMCF Plan 模板）、2020-8（PMCF Report 模板）等 |
| MDCG 2020-7 | PMCF Plan 模板（上市后临床跟踪计划） |
| MDCG 2020-8 | PMCF Evaluation Report 模板（评估报吿） |
| 关联 | PMCF 结论回流至 PSUR / 技术文档临床章节 |

## 中国 不良事件监测与再评价

《医疗器械不良事件监测和再评价管理办法》（2018 年第 1 号令）建立监测与再评价义务。

| 项目 | 说明 / 入口 |
| --- | --- |
| 2018 年第 1 号令全文（PDF） | [samr.gov.cn 不良事件监测和再评价管理办法 PDF](https://www.samr.gov.cn/cms_files/filemanager/samr/www/samrnew/samrgkml/nsjg/bgt/202106/W020211127427208653527.pdf) — 2018 年第 1 号令 |
| 国家监测系统 | [maers.adrs.org.cn](http://maers.adrs.org.cn/) — 国家医疗器械不良事件监测信息系统（企业/机构填报入口） |
| 主体责任 | 注册人/备案人须建立监测体系、主动收集、定期分析、开展再评价 |
| 召回分级 | 一级（严重）/ 二级 / 三级（一般），由 NMPA 组织 |

> 注册提示：注册人须指定不良事件监测负责人，产品上市后持续上报；再评价结论可触发注册变更或注销。

## 日本 PMDA 不具合等報告

日本要求 MAH/DMAH 对不具合、感染症、死亡等事件向 PMDA 报告。

| 项目 | 说明 / 入口 |
| --- | --- |
| PMDA 医療機器不具合等報告 | [pmda.go.jp 不具合等報告](https://www.pmda.go.jp/safety/reports/mah/0006.html) — 製造販売業者等による不具合・感染症・死亡報告制度 |
| 报告类型 | 不具合報告（故障/品质）、感染症報告、死亡・重篤な被害報告 |
| 责任方 | MAH（製造販売業者）/ DMAH（外国特例MAH） |
