# 生物相容性测试规划枢纽

任何与人体接触（尤其是植入、血液接触、组织接触）的器械，注册前必须做生物学评价。本枢纽汇总 ISO 10993-1（第 6 版 2025）、FDA 指南、GB/T 16886.1、ISO/TC 194 的官方入口与测试终点选择框架，全部可点击直达。适用于研发、注册、质量岗位。


## 生物学评价框架总览

生物相容性 ≠ 直接做全套动物试验。先做基于风险（接触性质/时间/材料）的「评价」，再确定「是否需试验」。

| 维度 | 说明 |
| --- | --- |
| 核心理念（ISO 10993-1） | 基于器械与人体接触的性质、程度、频次、时间进行「生物学风险评价」，试验是最后手段 |
| 评价流程 | 材料表征 → 等同性论证 → 已有数据 gaps 识别 → 必要时补充试验 → 风险受益判定 |
| 评价终点 | 细胞毒性、致敏、刺激/皮内反应、全身毒性、遗传毒性、血液相容性、植入、降解等 |
| 与化学表征关系 | ISO 10993-18（化学表征）与 ISO 10993-17（可沥滤物允许限度）支撑评价 |

> 关键提示：金属植入物（如 Ni-Ti 关节镜器械）重点关注：细胞毒性、致敏、刺激、血液相容性、遗传毒性、植入后局部效应，以及材料表征/可沥滤物。

## ISO 10993-1:2025（第 6 版）

生物学评价的顶层标准，2025 年发布第 6 版，取代此前版本，强化化学表征与基于风险的方法。

| 项目 | 说明 / 入口 |
| --- | --- |
| ISO 10993-1:2025 标准页 | [iso.org/standard/84512.html](https://www.iso.org/standard/84512.html) — 现行第 6 版（Biological evaluation of medical devices — Part 1） |
| 版本演进 | 2018（第 5 版）→ 2025（第 6 版）；第 6 版强调化学表征优先、减少不必要动物试验 |
| 配套系列 | ISO 10993-2（动物福利）/ -3（遗传毒性等）/ -4（血液相容）/ -5（细胞毒性）/ -6（植入）/ -11（全身毒性）/ -18（化学表征）/ -17（可沥滤物） |

II 类III 类 接触人体/植入器械普遍适用；测试范围由接触类型与持续时间决定。

## 中国标准 GB/T 16886.1-2022

等同采用 ISO 10993-1:2018（第 5 版）的强制性国标，是中国注册生物学评价的直接依据。

| 项目 | 说明 / 入口 |
| --- | --- |
| GB/T 16886.1-2022 官方全文 | [openstd.samr.gov.cn GB/T 16886.1-2022](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=1650E4742A3734023A1E10CF0BCA0AE0) — 全国标准信息公共服务平台 |
| 采用关系 | MOD/IDT 采标 ISO 10993-1:2018；NMPA 注册技术要求以 GB/T 16886 系列为准 |
| 注册提交 | 生物学评价报告 + 研究资料（研究资料 4.1.4 项），按《医疗器械生物学评价报告》格式提交 |

> 注意：中国现行注册依据多为 GB/T 16886.1-2022（等同 2018 版）。ISO 10993-1:2025 第 6 版为国际最新，研究布局可超前，但国内提交仍以现行国标版本为基准。

## FDA 使用 ISO 10993-1 指南（2023）

FDA 2023-09 更新的指南，说明 FDA 如何使用 ISO 10993-1 进行器械生物学评价审查。

| 项目 | 说明 / 入口 |
| --- | --- |
| FDA《Use of International Standard ISO 10993-1》 | [fda.gov Use of ISO 10993-1 (Sept 2023)](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/use-international-standard-iso-10993-1-biological-evaluation-medical-devices-part-1-evaluation-and) — 2023-09 更新版（510(k)、De Novo、PMA 均适用） |
| 关键变化 | 强调化学表征、可沥滤物评估，减少重复动物试验；明确「abuse」终点（如器械破损释放颗粒） |
| 适用范围 | 所有接触人体的器械生物学评价资料准备 |

## 生物学评价终点选择矩阵

按「接触类型 × 接触时间」映射到所需评价终点（依据 ISO 10993-1 表 1/附录 A 框架）。

| 接触类型 | 接触时间 | 典型终点 |
| --- | --- | --- |
| 表面接触（皮肤/黏膜/损伤表面） | ≤24h / >24h~30d / >30d | 细胞毒性、致敏、刺激或皮内反应 |
| 外部接入（血路/组织/骨/牙） | ≤24h / >24h~30d / >30d | + 全身毒性、遗传毒性、血液相容、植入 |
| 植入（组织/血液 / 植入器械） | ≤24h / >24h~30d / >30d | + 遗传毒性、血液相容、植入、致癌性（长期） |
| 金属植入示例（Ni-Ti 关节镜钳） | 短期外部接入/植入 | 细胞毒性、致敏、刺激、血液相容、遗传毒性、植入、材料表征 |

> 规划提示：先用「材料表征 + 等同器械已有数据」论证可豁免部分试验；确需试验时按上表选终点，并在评价报告中写明 rationale。
