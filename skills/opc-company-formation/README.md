# 一人公司办企业全流程（OPC）

想低成本开一家自己的公司？一人公司（OPC）开办全流程——主体形式对比（一人公司 vs 个体户 vs 个独 vs 合伙）、注册前决策三件事（名称/经营范围/注册资本·含 2024 新公司法 5 年认缴与加速到期风险）、材料清单、线上注册流程（以北京 e 窗通为例，各地一网通办通用）、费用预算、税务速览（小微实际税负 5%、小规模免增值税）、注册后运营合规（社保/发票/年报/代账交接）、变更与注销（减资 45 天公告、简易注销 20 天）、资质许可（ICP/EDI 条件与流程）、一人公司红线自保（举证责任倒置/财务隔离/年度审计）。从"要不要开"到"怎么开对、怎么活、怎么退出"全生命周期一站讲清。
