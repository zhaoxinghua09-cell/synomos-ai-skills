# 一人公司（OPC）办企业全流程

> 适用：以自然人身份开办**一人公司**（只有一个股东的公司，含一人有限公司/一人股份公司），轻资产承接 AI 服务、软件接口、品牌、公众号等生意。医疗器械等实体经营另设主体。
> 原则：工商注册免费、线上全程可办；**注册前决策做对，比注册动作本身重要 10 倍**。
> 法律背景：2024-07-01 施行的新《公司法》**删除了一人公司专节**，准入大幅放宽（可设多家、可设一人股份公司），但责任强化（举证责任倒置保留、新增横向人格否认）。

## 〇、先想清楚：办哪种主体？（决策第一关）

| 主体 | 责任 | 税负 | 适合 |
|---|---|---|---|
| **一人有限公司（OPC）** | 有限责任（举证责任倒置） | 企业所得税（小微实际 5%）+ 分红个税 20%（双重征税） | 品牌化、风险隔离、轻资产 AI 服务 |
| 个体工商户 | 无限责任 | 个税 5-35%（年 ≤200 万部分减半，至 2027） | 小规模、低风险、试水 |
| 个人独资企业 | 无限责任 | 个税 5-35% 累进 | 不需"有限公司"招牌 |
| 合伙企业 | 普通合伙人无限责任 | 先分后税 | 投资类/专业服务机构 |
| 多人有限公司 | 有限责任（无倒置） | 同有限公司 | 需股权融资/合伙人/强治理 |

> 选 OPC 的核心理由：**有限责任 + 有限公司招牌**（签约/信用优于个体户）。代价：双重征税 + 举证责任倒置 + 年度审计成本。

## 一、前置决策（注册前三件事，一次做对）

### 1. 公司名称（核名用，备 3 个候选）
- 格式：`地域 + 字号 + 行业 + 组织形式`，如「XX 医疗科技（北京）有限公司」
- 行业词建议带「科技/信息」而非「医疗器械」——轻资产定位更贴，且「医疗器械」类名称对经营范围/监管要求更严
- ⚠️ 核名在注册地市场监管局系统**实时校验**（重名/禁用词），必须备 3 个候选

### 2. 经营范围（一次写全，避免后改）
- 轻资产建议覆盖：技术服务/技术开发/技术咨询/技术转让/技术推广、软件开发、信息技术咨询、信息系统集成、健康咨询（不含诊疗）、企业管理咨询、会议展览、货物进出口、技术进出口
- ⚠️ 许可项（医疗器械销售/经营、互联网信息服务等）**初期别写**，按需再变更经营范围（常规操作）
- ⚠️ 后续做收费接口/软件产品可能要 ICP/EDI 许可，到时增项

### 3. 注册资本（认缴制，无需实缴，但别乱写高）
- 轻资产建议 **10-50 万**；确定做经营性 App/收费接口（ICP 需 100 万+）可一步到位或先小后大（增资=线上变更、免费、几天可办）
- 🔴 **2024 新公司法**：新设有限公司认缴期限**最长 5 年**（非以前的 10-30 年）；技术/知识产权可作价出资
- 🔴 **加速到期风险（新法第 54 条）**：公司不能清偿到期债务时，债权人可要求**未届出资期限的股东提前实缴**——注册资本写太高=兜底责任虚高，量力而行
- ⚠️ 认缴制无需验资，但以房产/专利实缴需第三方评估

| 材料 | 说明 |

| 注册地址证明 | 房产证 / 租赁合同 + 产权人证明；或**集群注册/园区托管地址**（无实体办公时） |
| 公司名称 3 候选 | 核名用 |

| 电子邮箱 | 接收电子执照等 |

## 三、注册流程（线上全程，约 3-7 个工作日）

> 以北京为例走「**北京 e 窗通**」（北京市企业开办一网通办，官方入口）；其他城市走当地「一网通办/开办企业一窗通」平台，流程一致。

1. **核名**：e 窗通「名称自主申报」，即时出结果
2. **一网通办填报**：营业执照 + 刻章 + 社保登记 + 公积金 + 发票一次联办
3. **实名认证**：法人/股东/监事「登记注册身份验证」APP 人脸识别
4. **领执照**：电子营业执照即时 + 纸质邮寄/窗口（部分区 1-3 工作日）
5. **刻章**：公章/财务章/法人章/发票章（部分区新设企业首套免费）
6. **银行开户**：对公基本户（小微企业费率优惠银行，0-500 元）
   - ⚠️ 无实体租赁合同可能被拒——**提前与挂靠园区/孵化器沟通推荐网点**
7. **税务登记**：电子税务局「新办套餐」报到、核定税种、三方协议、开通发票
   - 新设企业默认选**小规模纳税人**（年收 ≤500 万）
8. **记账报税**：代理记账 2000-6000 元/年（或自聘会计）

⚠️ **地址性质**：注册地址须**商用/办公性质**（住宅不能注册）；无实体办公可用**集群注册/园区托管地址**（年费一般 <5000 元，常含代理记账打包）。

| 刻章 | 0-500 元（看城市政策） |

## 五、税务速览（轻资产小公司实际税负很低）

- **增值税**：小规模纳税人月销 ≤10 万**免征**；3% 征收率**减按 1%**（财政部 2023-19 号公告，**执行至 2027-12-31**）
- **企业所得税**：小型微利企业（年应纳税所得额 ≤300 万、从业 ≤300 人、资产 ≤5000 万）实际税负 **5%**（延续至 2027-12-31）
- **个税**：利润分红按 20% 缴个税（双重征税即在此）
- **六税两费**：小规模/小微/个体户减半征收（城建税/印花税等，至 2027-12-31）
- **研发加计扣除**：研发费用 100% 税前加计（形成无形资产 200% 摊销）；设备器具 ≤500 万一次性税前扣除（2024-2027）
- **报税节奏**：个税月报；增值税 + 企业所得税季报；印花税 + 汇算清缴年报（代理记账会处理，但你要知道节奏）

| 2 | 微信公众号（企业订阅号） | 300 元/年认证 | 认证后名称受保护；医疗类内容需资质备案 |
| 3 | Gitee/GitHub 组织占位 | 免费 | 品牌命名 |

| 5 | 接口/MCP 产品化 | 待定 | 知识库产品化后 |

## 七、一人公司红线与自保（🔴 最重要一节）

### 法律现状（新《公司法》2024-07-01 施行，多源交叉验证）
1. ✅ **已放开**：新法删除"一个自然人只能设一家一人公司"限制——可设多家一人公司、可设一人股份公司、一人公司可再投资一人公司（旧法第 58 条已废止）
2. 🔴 **举证责任倒置保留**（新法第 23 条第 3 款）：只有一人股东的公司，股东**不能证明公司财产独立**的 → 对公司债务承担**连带责任**。举证在股东这边（一般公司是债权人举证，一人公司反过来）
3. 🔴 **新增横向人格否认**（新法第 23 条第 2 款）：股东利用其控制的**两个以上公司**滥用独立地位逃避债务 → 各公司对任一公司债务互负连带责任——**设多家公司时，每家都要财务边界清晰**

### 自保动作（防"刺破公司面纱"）
- **财务隔离三法则**：① 开独立对公账户，公私资金严格分流 ② 股东报销/往来必须开发票、如实入账 ③ 每季度打印银行流水备查
- **三流一致**：合同流、发票流、资金流一致，杜绝"个人卡收款"（判例：个人卡收款 100 万 → 破产时个人房产抵债）
- **年度审计（强烈建议做）**：新法虽删一人公司专节的强制审计规定，但《公司法》第 208 条仍要求所有公司年度编制财务会计报告并审计；更关键的是**年度审计报告是证明财产独立的第一举证路径**——司法审查是实质性审查（报告完整性/连续年份/真实性/机构资质），裸奔=败诉高危。成本约 3000-5000 元/年，建议请无利害关系的第三方事务所
- **书面化决策**：股东决定采用书面形式并置备于公司（决策留痕）

## 八、风险与避坑清单

- **地址异常**：挂靠/集群地址未接收信函 → 列入经营异常名录 → 影响贷款/投标（案例：罚款 5000 元）
- **发票合规**：虚开/三流不一致 → 税务风险
- **代客理财/荐股需牌照**：一人公司不能随便接外部资金；自有资金运作 OK
- **合同主体 = 收款主体**：签合同主体与收款账户须一致
- **CFC 陷阱**：警惕"包你 0 税"代理——中国 CFC 规则（2023 年 17 号公告，实际税负低于 12.5% 门槛可能被视同分配征税）
- **注销成本不对称**：中国公司注销痛苦，容易死的业务放运营壳，别放主体
- **公司法人社保别断**（保留中国税务居民身份时）
- **出口管制/制裁筛查**（欧美买家）+ 产品责任险
- **市场采购贸易 1039**（若选义乌）：受限品 + 单票上限（约 15 万美元），长大转 0110 需干净账
- **融资视角**：VC 通常回避纯一人公司（治理结构质疑）——如需融资预留股权池（代持/持股平台）

## 九、OPC 商业生存提醒（注册只是起点）

行业数据（参考，截至 2025-06 全国 OPC 超 1600 万家、占企业 27.4%），首批 OPC 四大死因：
1. **变现黑洞**：研发/算力成本高，启动金 3 个月耗尽，B 端压价
2. **能力跛脚**：会技术不会拓客/售后/供应链，单短板即死
3. **行业内卷**：无核心技术的套壳公司恶性价格战
4. **肉身崩盘**：一人包揽全部，超负荷先于资金链断裂

**生存三角**：精准市场定位（有支付意愿的真实需求）＋ 核心技术壁垒（别只堆 AI 工具）＋ 严格成本控制（克制扩张）。

## 十、注册后运营合规（公司活起来）

### 1. 时限红线（注册后必做，逾期有罚）
| 事项 | 时限 | 入口/说明 |
|---|---|---|
| 税务报到 | 执照领取后 **30 日内** | 电子税务局「新办纳税人开业」→ 税务信息确认 → 票种核定；逾期列非正常户影响开票 |
| 银行开户 | 尽快（多数园区要求 60 日内） | 开户后 **3 个工作日内**告知税务，签三方扣款协议（企业-银行-税务） |
| 社保开户 | 用工之日起 **30 日内**（《社会保险法》） | 逾期可处欠缴金额 1-3 倍罚款；**无员工时法人可作为参保人先办理** |
| 公积金开户 | 30 日内办理缴存登记 | 逾期可责令限期缴存、法院强制执行 |
| 印章备案 | 领照后即办 | 公安备案刻章点刻制（公章/财务章/发票章/合同章/法人名章），未备案印章无效 |

### 2. 日常运营节奏
- **报税**：个税月报；增值税 + 企业所得税季报；印花税 + 汇算清缴年报（小规模以季报为主）
- **年报公示**：每年 **6 月 30 日前**通过「国家企业信用信息公示系统」报送年度报告；漏报 → 经营异常名录 → 影响贷款/投标/变更
- **社保缴费**：每月固定日前保证账户余额（税务代扣或银行托收）；每年 6-7 月做基数申报
- **发票（数电发票时代）**：票种核定后**无需领用**，在电子发票服务平台额度内直接「蓝字发票开具」；无税控设备
- **久悬账户**：基本户开立 6 个月无资金往来会被列为久悬账户，需到网点激活

### 3. 代理记账交接清单（每月交给代账的）
- 收入/成本发票（或开票汇总）
- 银行流水 + 回单
- 工资表（如有员工）+ 社保/公积金缴费凭证
- 费用票据（报销单/合同）
- 简单留档即可，专业判断交给代账（2000-6000 元/年）

## 十一、变更与注销（公司生命周期后半程）

### 1. 常见变更（线上可办，一般 3 个工作日）
- **经营范围变更 / 增资 / 股权变更 / 法定代表人变更**：当地政务平台「变更登记」+ 实名认证即可
- **减资（注册资本调低）**——《公司法》第 224 条：
  1. 股东会作出减资决议
  2. 编制资产负债表和财产清单
  3. 决议之日起 **10 日内通知债权人** + **30 日内公告**（报纸或国家企业信用信息公示系统，公示系统免费），公告期 **45 天**
  4. 公告期满后申请变更登记（材料：登记申请书/章程修正案/债务清偿或担保说明）
  - ⚠️ 减资须**按持股比例同比减少**（全体股东另有约定除外）

### 2. 注销（退出）
- **简易注销**（轻资产无债公司首选）：未发生或已清偿债权债务 + 结清税费/工资/社保，全体投资人书面承诺 → **公示 20 日** → 无异议 → 期满 **20 日内**申请 → **1 个工作日办结**（符合涉税即办条件的免清税证明）
  - ❌ 不适用：被列入经营异常名录 / 股权被冻结/出质 / 对外投资未处理 / 欠税（滞纳金、罚款）/ 正处诉讼仲裁 / 受行政处罚未执行完毕
- **普通注销**：税务注销（清税）→ 发布债权人公告（45 日）→ 清算报告 → 企业注销 → 社保注销 → 银行销户 → 印章注销；政务平台「企业注销登记一件事」专区可同步办理
- ⚠️ 2025 版《企业注销指引》新增责任：被吊销满 3 年未注销可被**强制注销**；注销前须清偿欠薪等

## 十二、资质许可（按需办理）

### 1. ICP 备案 vs ICP 许可证（别搞混）
- **ICP 备案**：域名备案，所有境内上线网站必做，免费（服务器商一般可代办）
- **ICP 经营许可证**（B25 信息服务）：网站/APP 有**经营性功能**（收费/会员/广告/电商/付费内容）**必须办**；纯信息展示不需要；即使入驻第三方平台，涉经营性场景仍需单独办理
- 办理条件（缺一不可）：**纯内资**（无外资，需股权穿透至自然人）｜**注册资本 ≥100 万**（认缴即可）｜经营范围含「增值电信业务/第二类增值电信业务」｜**至少 3 名在职员工近 1 个月社保**（含 1 名计算机相关专业人员）｜域名已备案且持有人=公司｜服务器在大陆
- 流程：工信部电信业务市场综合管理信息系统（tsm.miit.gov.cn）→ 省通信管理局审核 **20-40 个工作日** → 下发电子+纸质许可证；**5 年有效，每年 1-3 月年报**
- 成本：自办 0 元（周期 1-3 个月）/ 代办 3000-15000 元（1-2 个月）
- 🔴 **与注册资本联动**：打算做收费接口/App 的，注册时就**经营范围带上「增值电信业务」、注册资本直接 100 万**，避免事后变更 + 补社保

### 2. EDI 许可证（在线数据处理与交易处理）
- 涉及**第三方交易平台**（撮合商家入驻、B2B 平台）时办理；自营电商一般不需要
- 条件与 ICP 类似（内资、100 万、3 人社保、服务器境内）

### 3. 医疗器械经营许可（如做器械生意）
- 二类：**经营备案**；三类：**经营许可证**（前置，需质量负责人/经营场所/质量制度）
- 与轻资产 AI 服务公司**分离——实体经营另设主体**，别混入同一家公司
