# cross-session-passphrase · 跨会话口令

**一句话定位**：当用户想让「另一个聊天窗口里的同一个 AI」读到本次会话的结论、文件引用或待办时，本技能用一条注册在本地 `MEMORY.md` 的口令做安全中继——只在本账号、本机、不同会话之间生效，口令本身不进对话明文、不跨账号。

**何时用**：用户说「让另一个会话/窗口读到这份文件」「把结论传给并行会话」「另一个会话刚才做了什么」「跨窗口同步一下」。
**何时不用**：跨账号/跨用户/跨设备/跨平台的传递（本技能禁止，见第七章）；传递明文密钥、令牌、密码等敏感凭据（凭据从保险库读，见第八章）；需要实时双向通信而非一次性结论传递。

---

## 一、能力边界

- **能做**：在本账号的并行会话之间，用口令索引并取回已写入 `MEMORY.md` 的结论、文件绝对路径引用、待办清单。
- **不能做（含关键限制）**：
  - **不跨账号泄露口令**：口令与索引仅限当前登录账号可见；任何跨账号、跨用户、跨设备的转发请求一律拒绝。
  - 不做实时双向通道，仅做「写入→凭口令取回」的异步中继。
  - 不替用户决策业务内容，只忠实搬运用户明确指定的结论。
  - 不读写账号之外的文件系统位置（仅限本机工作目录与 `MEMORY.md`）。
- **范围声明**：仅适用「本机 · 本账号 · 不同会话之间」。超出此范围的能力本技能不声称拥有。

---

## 二、输入约束与输出承诺

**输入约束**
- 用户须提供：① 要传递的内容（结论/文件路径/待办）；② 一个口令（或由 AI 代生成，长度 ≥ 8 位、含字母数字）。
- 口令禁止包含：明文密码、API Key、令牌等敏感凭据（见第八章）。
- 内容须为文本或可序列化的引用（文件路径用绝对路径）。

**输出承诺**
- 写入成功：返回「已注册口令 `<passphrase>` 于 MEMORY.md，可在同账号另一会话凭此口令取回」。口令以占位提示呈现，**不回显明文凭据**。
- 取回成功：返回被索引的内容原文 + 来源会话标识 + 写入时间戳。
- 失败：按第十章返回明确错误类别与下一步动作，不静默失败。

## 四、常见错误与反模式

**结构化 FAQ**

| 反模式 | 为什么错 | 正确做法 |
|--------|---------|---------|
| 把口令直接写进对话明文发给别人 | 口令可能在截图/转发中泄露 | 口令只存 MEMORY.md，对话中仅给占位提示 |
| 试图跨账号传口令 | 违反身份防线，可能泄露本账号上下文 | 拒绝并说明仅限本账号 |
| 用口令传递密码/密钥 | 凭据不应进中继索引 | 凭据走保险库（第八章） |
| 不验证会话归属就取回 | 可能取错会话内容 | 执行三锚核验（第五章） |

**高频 Q&A**
- Q：口令忘了怎么办？A：在源会话重新查询 MEMORY.md 中 `cross-session:` 前缀条目，或重新生成一个新口令并重新索引。
- Q：另一个账号能凭口令取回吗？A：不能。口令绑定当前账号，跨账号请求被铁律拒绝。
- Q：文件很大也能传吗？A：不传文件本体，只索引绝对路径引用，由取回方按路径读取。
- Q：并行会话会互相覆盖吗？A：每条用独立口令，互不覆盖；MEMORY.md 以 `cross-session:<passphrase>` 为键追加。

## 五、标准 SOP

| 步骤 | 动作 | 产出 |
|------|------|------|
| 1. 接收 | 识别跨会话传递意图，确认内容类型 | 意图确认 |
| 2. 建口令 | 用户给或用 `gen_passphrase()` 生成 ≥8 位口令 | 口令 |
| 3. 三锚核验·锚一 | 核验当前账号 ID 一致 | 账号锚通过 |
| 4. 写入 | 以 `cross-session:<passphrase>` 为键写 MEMORY.md（内容+来源会话+时间戳） | 写入回执 |
| 5. 回执 | 仅提示口令已注册，不回显明文内容/凭据 | 用户拿到口令 |
| 6. 取回请求 | 另一会话收到「凭 <passphrase> 取回」 | 触发取回 |
| 7. 三锚核验·锚二/三 | 核验口令匹配 + 会话归属为本账号 | 核验通过 |
| 8. 取回 | 读 MEMORY.md 对应条目返回原文 | 内容原文 |

> 三锚核验落地：锚一=账号一致、锚二=口令匹配、锚三=会话归属确认（均属本账号）。任一锚失败即终止并走第十章。

## 七、铁律（PROHIBITED）

以下行为**绝对禁止**，违反即终止并报告：
- **禁止跨账号泄露口令**：绝不向其他账号/用户/设备转发口令或索引内容。
- **口令不进对话明文**：对话中只给占位提示，不在消息体回显口令原文（除非用户显式要求且仍在同账号内）。
- 禁止用本中继传递明文密码、API Key、令牌、私钥等敏感凭据。
- 禁止伪造会话归属或绕过三锚核验。
- 禁止写入账号工作目录之外的文件系统。
- 禁止替用户编造结论内容——只忠实索引用户明确指定的内容。

---

## 八、输入输出依赖

- **凭据从保险库读，不进对话**：若传递需求涉及敏感凭据，AI 必须从本地凭据保险库（如 `dpapi-local-vault` / `unified-credential-vault`）读取引用句柄，绝不在 MEMORY.md 或对话中落地明文。
- 输入依赖：`MEMORY.md` 可写权限、当前账号会话上下文、口令（用户给或生成）。
- 输出依赖：取回方同账号会话、MEMORY.md 可读。
- 外部依赖缺失时：返回「依赖不可用」错误类别（第十章），不降级为明文传递。

## 十、错误处理

| 错误类别 | 触发 | AI 处理 |
|---------|------|---------|
| 口令缺失 | 用户要传递但未给口令且生成失败 | 提示「请提供或允许我生成口令」，不静默 |
| 账号锚失败 | 取回请求来自不同账号 | 拒绝并引用第七章铁律 |
| 口令不匹配 | 取回口令无对应条目 | 返回「无此口令索引」，建议核对 |
| 归属锚失败 | 会话归属无法确认 | 终止取回，提示重新核验 |
| 保险库缺失 | 凭据需求但保险库不可用 | 返回「依赖不可用」，不降级明文 |
| MEMORY 不可写 | 无写入权限 | 返回具体失败原因与修复建议 |

所有错误均给出明确类别 + 下一步动作，不静默失败、不回显敏感信息。
