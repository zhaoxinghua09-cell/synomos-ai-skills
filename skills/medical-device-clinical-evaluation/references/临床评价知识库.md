# 临床评价知识库（专题实操版）

临床评价是注册申报的核心证据文件——中国Ⅱ/Ⅲ类、美国 510(k)/PMA、欧盟 MDR 均须证明临床使用的安全有效性。本知识库提供**路径判定 → 报告撰写 → 数据评估**的可操作内容，官方链接经核验可直达。

> 制作日期：2026-08-27 ｜ 链接来源：复用注册枢纽已核验清单（2026-08-14 浏览器级复核）

---

## 一、临床评价路径判定决策树（先走这条路）

| 步骤 | 判定 | 交付物 | 依据 |
| --- | --- | --- | --- |
| ① 查免临床目录 | 产品列入且与目录描述一致 | 与目录描述的**对比说明**（不是什么都不交！） | 免临床目录 2025 年版（NMPA 2025 年第 19 号通告，1047 项） |
| ② 同品种/等同性比对 | 有已上市同品种可论证基本等同 | 等同性论证 + 临床文献/数据评价报告 | 中国同品种比对指导原则 / MDCG 2020-5 / 510(k) SE |
| ③ 临床试验 | 无合适同品种 / 差异影响安全有效 / 创新产品 | 临床试验报告（GCP 合规） | NMPA 临床试验指导原则 / MDR Art. 61 / FDA IDE |

> 三条路不是任选：**先查目录，不在目录再评估能否走同品种，都不行才上临床试验**。美欧的"实质等同/等同性"与中国的"同品种比对"是同一逻辑在不同市场的落地。

## 二、中国 NMPA 路径

| 项目 | 官方入口 | 说明 |
| --- | --- | --- |
| 免于进行临床评价医疗器械目录（2025 年版） | [NMPA 通告（2025 年第 19 号）](https://www.nmpa.gov.cn/xxgk/ggtg/ylqxggtg/ylqxqtggtg/20250513095643145.html) | 共 1047 项，取代 2023 年版（33 号） |
| 临床评价技术指导原则 | [CMDE 官网指导原则专栏](https://www.cmde.org.cn/) | 等同性论证、报告撰写、境外数据接受等集中发布 |
| 注册申报资料要求 | 2021 年第 121/122 号公告 | 临床评价资料为申报必备模块 |

关键规则：
- **免临床目录内**：提交申报产品与目录描述的**对比说明**即可免临床试验，但须证明与目录中已上市产品基本等同；
- **同品种比对**：选择境内已获准注册的同品种，论证"基本等同"——差异不得对安全有效性产生不利影响，且差异影响须用申报产品自身数据验证；
- **境外临床数据**：符合中国人种差异考量后可接受境外临床试验数据，减少重复试验。

## 三、欧盟 MDR 路径（CER）

MDR Art. 61 要求临床评价贯穿产品生命周期；公告机构审 CER 是 IIb/III 类拿证的关键环节。

| 文件 | 完整标题 | 用途 |
| --- | --- | --- |
| MDCG 2020-13 | Clinical evaluation assessment report template | **CER 报告模板**（公告机构审评用） |
| MDCG 2020-5 | Guidance on clinical evaluation – Equivalence | 等同性论证指南 |
| MDCG 2020-6 | Guidance on sufficient clinical evidence for legacy devices | legacy 器械临床证据要求 |
| MDCG 2023-7 | Exemptions from the requirement to perform clinical investigations (Art. 61(4)-(6)) | 豁免临床试验情形 |
| MDCG 2019-9 rev.1 | Summary of safety and clinical performance (SSCP) | IIb/III 类公示摘要 |
| MDCG 2020-7 / 2020-8 | PMCF plan / evaluation report template | 上市后临床跟踪模板 |

官方入口：[MDCG 指南库（Clinical investigation and evaluation 分类）](https://health.ec.europa.eu/medical-devices-sector/new-regulations/guidance-mdcg-endorsed-documents-and-other-guidance_en)

> 关键规则：等同性论证须满足**三要素**（技术特性、生物学特性、临床特性）并证明可获取充分的等同器械数据（access to data）；无法满足等同性 → 必须开展临床试验。

## 四、美国 FDA 路径

| 项目 | 官方入口 | 说明 |
| --- | --- | --- |
| 510(k) 实质等同（SE） | [FDA 510(k)](https://www.fda.gov/medical-devices/premarket-submissions/premarket-notification-510k) | 与 predicate 证明实质等同：预期用途 + 技术特性 |
| 510(k) 数据库（查 predicate） | [FDA 510(k) Clearances](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpmn/pmn.cfm) | 查已清关产品与 predicate 对应 |
| De Novo / PMA | [FDA Device Advice](https://www.fda.gov/medical-devices/device-advice-comprehensive-regulatory-assistance) | 新型低中风险走 De Novo；高风险走 PMA（需更充分临床证据） |
| FDA 指南库 | [Search FDA Guidance Documents](https://www.fda.gov/regulatory-information/search-fda-guidance-documents) | 搜 510(k) Program / Substantial Equivalence |

> 核心规则：510(k) SE 论证核心是"**预期用途相同 + 技术特性不引入新的安全有效性问题**"；无 predicate 或无法建立 SE → De Novo / PMA。

## 五、临床评价报告（CER）撰写框架

按 MDCG 2020-13 模板结构组织（欧盟），中国/美国对照调整章节：

1. **临床评价范围与背景**：产品描述、预期用途、目标人群、临床背景
2. **等同性/同品种论证**：逐项对比（预期用途、技术/生物/临床特性），差异分析对安全有效性的影响
3. **文献检索方案**：数据库（PubMed、Cochrane、Embase 等）、检索式、时间范围、纳入排除标准——**先定方案再检索，报告可追溯**
4. **临床数据评估**：
   - 数据来源三角：临床文献 + 临床经验数据（上市后使用/不良事件）+ 临床试验（如需要）
   - 每项数据评估：相关性、方法学质量、数据完整性、与申报产品的关联度
   - 权重赋值：同型号/同适应证数据权重最高，跨产品推断需论证
5. **获益-风险结论**：与风险管理文件呼应（ISO 14971），临床评价结论须支持获益-风险判定
6. **结论与参考文献**：明确声明临床评价结论；参考文献完整可追溯

### 文献检索方案模板

| 要素 | 内容 |
| --- | --- |
| 数据库 | PubMed / Cochrane Library / Embase / CNKI（中国） |
| 检索式 | PICO 结构：Population（人群）+ Intervention（器械）+ Comparison + Outcome |
| 时间范围 | 建议近 10 年为主 + 关键经典文献 |
| 纳入标准 | 与申报器械同类/同适应证、临床研究或系统评价 |
| 排除标准 | 动物实验（仅作背景）、综述（引原文）、无关适应证 |
| 记录方式 | 检索日期、检索式、命中数、筛选流程（PRISMA 风格） |

## 六、常见误区

- ❌ 免临床目录内就"什么都不交" → 须提交与目录描述的**对比说明**
- ❌ 同品种比对"长得像就行" → 差异必须逐项分析对安全有效性的影响，且用申报产品自身数据验证
- ❌ CER 凭经验写、无检索方案 → 文献检索方案先行，报告可追溯，否则审评不认
- ❌ 只写文献不评估 → 数据来源三角（文献+临床经验+试验）都要，逐项评估质量与关联度
- ❌ 临床评价与风险管理脱节 → 临床结论须支持获益-风险判定，两文件互相引用

## 七、边界与时效

- 本知识库提供框架与要点，不替代审评中心/公告机构的个案裁定；创新器械建议先咨询专业 RA 或走官方分类界定/预沟通。
- 免临床目录现行版本为 **2025 年版**；MDCG 指南以官方指南库最新版为准；FDA 指南改版频繁，用官方检索入口取最新版。
