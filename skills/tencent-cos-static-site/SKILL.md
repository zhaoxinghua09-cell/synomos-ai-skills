# 腾讯云 COS 静态网站托管上线 SOP（AI 防线版）

**一句话定位**：把纯静态前端（HTML/CSS/JS/图片）安全、合规地托管到腾讯云 COS 并绑定自定义域名、强制 HTTPS 的标准作业流程。

**何时用**：用户要「把网页挂到腾讯云」「用 COS 做静态站」「域名绑 COS」「查 COS 网站访问故障」「申请/配置 COS 证书」。
**何时不用**：需要后端逻辑（PHP/Node/Python 服务端脚本、数据库、API 动态渲染）、需要容器/VM 托管、或非腾讯云对象存储的场景——本技能不覆盖，应引导至对应服务，并提示凭据与边界。

> 治理视角（防线）：本技能遵循 SynomosAI XCGS 治理，强调「凭据不进对话、最小权限、强制 HTTPS、可追溯」。部署即布防。

## 一、能力边界

**支持（IN-SCOPE）**
- 纯静态资源托管：HTML/CSS/JS/图片/字体/媒体（无服务端执行）。
- 自定义源站域名 / CDN 加速域名绑定到 COS。
- 静态网站托管开关、索引页/错误页/重定向规则配置。
- DNSPod 或任意 DNS 服务商的 CNAME 解析指引。
- SSL 证书申请（免费 DV）、部署与强制 HTTPS（HTTP→HTTPS 跳转）。
- 国内地域上线的 ICP 备案前置检查。
- 访问故障排查（403/404/空白页/混合内容/缓存/回源）。

**不支持（OUT-OF-SCOPE / 明确拒答并引导）**
- 任何服务端代码执行：PHP、Node、Python、Java 后端、SSR 框架的服务端渲染（需用云函数 SCF / CVM / 容器，超出本技能）。
- 数据库、会话、登录后端、API 网关等动态能力。
- 非腾讯云对象存储（阿里 OSS、AWS S3 等）的操作细节。
- 域名注册/过户交易本身（仅含「确认已购+实名+备案」检查）。
- 付费代运维、密钥代管、绕过备案或安全策略的非常规操作——**一律拒绝并说明合规原因**。

## 四、常见错误与反模式（结构化 FAQ + 高频 Q&A）

**反模式（务必避免）**
- ❌ 把 `SecretId/SecretKey` 写进对话、日志、代码或提交。→ 一律从保险库读。
- ❌ 为图省事把私有桶直接设「公有读」且无防盗链。→ 按需最小权限 + 防盗链。
- ❌ 用 `*.cos.ap-xxx.myqcloud.com` 默认端点当生产域名。→ 必须绑自定义域名 + CDN。
- ❌ 跳过 ICP 备案直接解析到国内节点。→ 国内地域强制备案，否则阻断。
- ❌ 不上 HTTPS 或允许 HTTP 混合内容。→ 强制 HTTPS + 资源全 https。
- ❌ 把服务端脚本当静态站上传指望能跑。→ 静态托管不执行后端代码。

**高频 Q&A**
- Q：COS 能跑 WordPress / PHP 吗？
  A：不能。静态网站托管只服务静态文件，无服务端执行。需用 CVM/容器/云函数。
- Q：国内节点一定要备案吗？
  A：是。未备案域名无法在国内地域提供访问，需先完成 ICP 备案。
- Q：默认域名能当正式域名吗？
  A：不建议。默认 `*.cos-website.*` 仅测试用，应绑自定义域名并走 CDN + HTTPS。
- Q：403 怎么快速定位？
  A：先看桶权限与对象 ACL，再看静态网站托管的索引文档是否设置，最后查防盗链/Referer 规则。
- Q：证书收费吗？
  A：腾讯云提供免费 DV 证书（有张数与年限限制），也可上传自有证书；生产建议用正规 CA。

## 五、标准 SOP（步骤表）

| 步骤 | 动作 | 控制台/命令路径 | 完成判定 | 防线要点 |
|---|---|---|---|---|
| 1 | 备案与实名确认 | 域名控制台→实名认证；ICP 备案系统 | 域名已实名、国内节点已备案 | 未备案不得解析国内 |
| 2 | 创建存储桶 | COS 控制台→创建桶；名全局唯一、选近用户地域 | 桶创建成功 | 权限默认私有，按需开公有读 |
| 3 | 开启静态网站托管 | 桶→基础配置→静态网站托管；设 index.html/error.html | 托管状态「已开启」 | 索引/错误页必填 |
| 4 | 上传网站文件 | 桶→文件列表→上传；保持目录结构与 MIME | 资源可读、路径正确 | 不传密钥/敏感文件 |
| 5 | 绑定自定义域名 | 桶→域名管理→自定义源站/ CDN 加速域名 | 域名「已生效」 | 优先 CDN 加速 |
| 6 | DNS 解析 CNAME | DNSPod/服务商→添加 CNAME 指向 COS 访问域名 | `dig` 解析到目标 | 验证生效再继续 |
| 7 | 申请并部署证书 | SSL 证书控制台→免费 DV/自有证书→绑定域名 | HTTPS 可访问、小锁 | 开启强制 HTTPS |
| 8 | 访问策略加固 | 防盗链、CORS、ACL 按需 | 仅预期来源可访问 | 最小权限 |
| 9 | 验证上线 | 浏览器访问自定义域名 | 200 + HTTPS + 资源全载 | 查混合内容/缓存 |

> 需要写操作的步骤（建桶/上传/改权限）若涉及密钥，必须经保险库鉴权，AI 不在对话中持明文密钥。

## 六、关键事实速查

- **静态端点 vs 默认端点**：`*.cos-website.*` 支持索引/错误页/重定向；默认 `*.cos.*` 端点不支持网站路由。
- **地域与备案**：`ap-beijing/ap-guangzhou/ap-shanghai` 等国内地域需备案；`ap-hongkong/ap-singapore` 等海外无需大陆备案。
- **权限模型**：私有 / 公有读私有写 / 公有读写（慎用）。静态站通常「公有读私有写」+ 对象 ACL 继承。
- **计费**：存储容量 + 流量 + 请求次数按量计费；CDN 另计。
- **MIME**：上传后确认 `.js`/`.css`/`.json` 等 Content-Type 正确，否则浏览器拒执行。
- **缓存**：CDN 缓存策略与 COS 元数据 `Cache-Control` 共同决定；改版需刷新缓存。
- **混合内容**：页面内 `http://` 资源会导致 HTTPS 页面告警/拦截，必须全 https。

## 九、示例

**场景 A：纯静态官网首次上线（国内）**
1. 确认 `example.com` 已实名 + 已 ICP 备案。
2. 建桶 `example-com-125xxxxxxx`，地域 `ap-guangzhou`，权限「公有读私有写」。
3. 开静态网站托管，索引 `index.html`、错误 `error.html`。
4. 上传 `index.html`/`css/`/`js/`/`img/`，确认 MIME。
5. 域名管理绑 `www.example.com`（CDN 加速域名）。
6. DNSPod 添加 CNAME：`www → example-com-125xxxxxxx.cdn.dnsv1.com`。
7. 申请免费 DV 证书并绑定，开启强制 HTTPS。
8. 配防盗链（仅允许 example.com）。
9. 访问 `https://www.example.com` → 200 + 小锁。

**场景 B：打开是 404**
- 现象：自定义域名访问根路径 404。
- 原因：静态网站托管未设索引文档，或上传路径非桶根。
- 处置：确认托管索引页已填 `index.html`；文件在桶根或对应前缀；刷新 CDN。

## 十、错误处理

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 403 Forbidden | 桶/对象权限不足、ACL 未继承、防盗链拦截 | 调桶权限为公有读私有写；核对对象 ACL；放宽/修正 Referer 白名单 |
| 404 Not Found | 索引文档未设、路径错误、CNAME 未生效 | 设索引页；确认文件位置；`dig` 验证解析 |
| 空白页/JS 不执行 | MIME 错误（如 js 被当 text/plain） | 修正对象 Content-Type；重传 |
| 混合内容告警 | 页面含 http:// 资源 | 全部改为 https；更新引用 |
| HTTPS 小锁缺失 | 证书未部署/未强制跳转 | 部署证书；开启 HTTP→HTTPS 强制 |
| 国内访问被阻断 | 未备案 | 先完成 ICP 备案再解析 |
| 缓存未更新 | CDN/COS 缓存未刷 | 提交缓存刷新；设合理 Cache-Control |

**兜底原则**：任何无法在对话中安全判定的写操作，提示用户在保险库鉴权后的环境中执行，绝不索取或回显密钥；超出能力边界的请求，明确拒答并引导至正确服务。
