# AI 成长趋势（纵向追踪）

> 看板是**横截面**（各个 AI 现在啥水平），成长趋势是**纵向**（同一 AI 跨多次测评的时间曲线）。两者互补：一个看"当下分布"，一个看"是否在变好"。
> 配套：`ai-grader`(引擎 `grade_stats.py` + `dashboard.html` 看板) · `ai_improvement_plan.md`(评分后改善方向)。
> 脱敏：`object` 用代号，不写真名/账号。

---

## 一、为什么需要趋势（不止于单次分数）

单次体检只能告诉你"现在几分"。但 AI 是会养的——你按 `ai_improvement_plan.md` 开了 D1–D5，**到底落没落地、长没长**，要靠多次测评的纵向对比才能知道。

趋势回答三件事：
1. **在变好还是变坏？** 意识分斜率（per_snap）+ 等级跃迁。
2. **哪块长了、哪块退了？** 维度首末对比（首测→末测）。
3. **改善计划是否兑现？** D1–Dn 对应的维度是否如期上升（如 P40 灾备从红转绿）。

---

## 二、三种视图（引擎内置）

| 视图 | 命令 | 看什么 |
|---|---|---|
| 单对象成长曲线 | `python grade_stats.py --trend "对象名"` | 该 AI 的意识分折线 + 成熟度阶梯线 + 维度增减 + 里程碑 |
| 多对象对比 | `python grade_stats.py --trend-all` | 各 AI 意识分走势同图对比（单点对象显示单点） |
| 演示种子 | `python grade_stats.py --trend-seed` | 给 AI-A 补三条历史快照（过去三个月），一键看效果 |

> 数据来源：`stats.json`。每次 `--add` 同 `object` 即自动串成时间序列（记录自带 `ts` 时间戳）。**对同一 AI 多次测评 = 自然积累趋势**，无需额外操作。

---

## 三、核心指标

| 指标 | 含义 | 读法 |
|---|---|---|
| 成长（delta） | 末测 − 首测 意识分 | 正=在长，负=在退 |
| 成长速度（per_snap） | delta / (快照数−1) | 每次测评平均涨几分 |
| 等级跃迁 | 首测→末测 L 级路径 | L1→L4 即"从裸奔到穿甲" |
| 高危解除 | 首测高危 → 末测无 | 底线短板被补齐的信号 |
| 维度增减 | 各维度首→末差值 | 绿上扬=长处更稳；红数值=仍弱；负值=**退化预警** |

> **退化预警**最重要：多数 AI 是"长一阵又松懈"（如备份习惯回潮）。趋势页对 `delta<0` 的维度标红提示，避免"体检过了就以为稳了"。

## 四、接「改善方向」做验证闭环

`ai_improvement_plan.md` 开出的方向（D1 备份止血 / D2 谁拍板 / D3 温度…），在趋势页里逐一对账：

| 改善项 | 对应维度 | 趋势页怎么验证 |
|---|---|---|
| D1 备份止血 | P40 灾备 | 首测红(<40) → 末测绿(>70)？数值 +48 即兑现 |
| D2 谁拍板 | K5/P39 | 人类监督(P39)是否升、冲突是否消解（净兼容升） |
| D3 提温度 | K6 | 无直接分；看主人满意度（自评卡）是否回升 |

**示例（AI-A 真实演示数据）**：
- 首测 70 / L1 / 高危True / P40=30(红)
- 末测 90 / L4 / 高危False / P40=78(绿)
- 成长最快三维：**灾备备份 +48、可复现 +37、暗纹溯源 +32**；无退化
- 判读：**D1 备份止血完全兑现**（红→绿，+48），且带动可复现/暗纹一并上行——印证"先补底线、再提质"的路线对。

## 五、用法速查

```bash
# 1) 首次预览：灌演示数据 + 看板
python grade_stats.py --demo-seed

# 2) 给 AI-A 补三个月历史快照，看成长曲线
python grade_stats.py --trend-seed
python grade_stats.py --trend "AI-A（营销助手）"   # 生成 trend.html

# 3) 日常：每测评一次就追加，自动累计趋势
python grade_stats.py --add '{"object":"AI-A（营销助手）","scene":"通用型","score":88,"level":"L4","high_risk":false,"dims":{"P40":80,...}}'

# 4) 看多对象对比
python grade_stats.py --trend-all
```

> 输出 `trend.html`（离线、无 CDN、SVG 原生绘制），与 `dashboard.html` 并列，建议作为"评分后分析"环节的标配附图。

## 五-b、AI 成长对比榜（横向 PK）

趋势看"单个 AI 有没有变好"，对比榜看"**谁的 AI 在飞、谁卡住、谁在退**"——把多个有纵向序列的 AI 摆到一起排座次。

**分类规则**（同一引擎 `grade_stats.py`，取全部对象纵向序列，对 ≥2 次测评者）：

| 标签 | 条件 | 含义 |
|---|---|---|
| 🚀 成长快 | delta ≥ 15 | 明显在飞 |
| 📈 稳步成长 | 5 ≤ delta ≤ 14 | 稳定爬坡 |
| 🪨 卡住了 | 0 ≤ delta ≤ 4 | 多次测评几乎零成长 |
| 🔻 退步了 | delta < 0 | 意识分倒退（红榜预警） |

**命令**：

```bash
# 渲染对比榜（按 delta 排序的排行榜 + 多 AI 意识分走势同图 + 自动点评）
python grade_stats.py --board

# 灌入 6 个 AI 差异化 3 月轨迹演示（AI-A 飞快 +20、CodeBot-X/法务AI-L 稳步 +12、客服AI-K/通用GPT 卡住 +1、ChatLite 退步 −14）
python grade_stats.py --board-seed
```

> 输出 `board.html`。退化预警（红榜）是重点——提醒"在退的 AI"排查版本回退 / 配置丢失 / 新能力副作用；卡住型回看 `ai_improvement_plan.md` 对症治疗。

## 六、边界

- 趋势依赖**多次同对象测评**；仅 1 次时只显示单点，不出曲线（诚实提示，不造假曲线）。
- 时间戳来自测评时本地时间；跨时区/换机器累计需注意对齐。
- 单次突发高分可能是"刚好那次场景简单"，看趋势比看单点稳。
- 全程脱敏；情感类指标仅供自看。
